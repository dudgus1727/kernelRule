## 1. 적합기 — 16차원에서 버티지 못한다 (D-77)

**재현** `OMP_NUM_THREADS=1 python3 experiments/fitter_dim.py --jobs 16`
**전문** [artifacts/fitter-dim16.md](artifacts/fitter-dim16.md)

### 무엇이 문제인가

```python
start = best_w if r == 0 else best_w + rng.normal(
    0.0, 0.35 * np.maximum(np.abs(best_w), 1.0))
```

**(가) 재시작이 전부 국소다.** `n_restarts=4` 인데 넷 다 `best_w` 주변이다.
16차원 검사에서 이긴 출발점은 전부 **전역 무작위**(로그균등 0.05~50)였다.

**(다) 다듬기 예산이 차원에 안 맞는다.** 쌍좌표가 `n=8` 은 112회/델타인데
`n=16` 은 480회/델타다. 델타 6개면 2,880회라 예산 600 안에서 **한 바퀴도
못 돈다.**

측정값:

| | 도달률 | 재적합 도달률 | 재적합 격차 최대 |
|---|---:|---:|---:|
| 8차원 (A8) | 12/12 100% | 9/12 75% | 0.0110 |
| 16차원 (B16-lo) | 11/12 92% | 7/12 58% | 0.0462 |
| 16차원 + 예산 4배 | 11/12 92% | 5/12 42% | 0.0413 |

### 왜 지금 안 하는가

```
1  8차원은 멀쩡하다 — A8 도달률 100%. 지금까지의 결과가 전부 그 위에 있다
2  고치면 **전부 재채점**해야 한다. D-56 때 12실행을 버린 것과 같은 구조인데
   이번엔 얻는 것이 불확실하다
3  ★ 고쳐도 풀린다는 보장이 없다 — 예산 4배로도 재적합 도달률 42% 그대로였다
   "고치고 -> 전부 재채점하고 -> 또 못 가린다" 가 될 수 있다
```

### 언제 하는가

**8차원을 벗어날 필요가 생겼을 때.** 예산 8 vs 16 실험이 그것이고, 그
실험은 이 수정 없이는 **적합기의 출발점 민감도(0.04)를 재게 되므로**
성립하지 않는다. 순서는 고정이다:

```
적합기 (가)+(다) -> fitter_dim 재검사 -> 통과하면 재채점 비용 산정
-> 그 비용을 받아들일지 결정 -> 예산 실험
```

통과선: `B16-*` 두 팔 모두 도달률 90% + 재적합 도달률이 A8 수준(75%).

### ★ 2026-09-01 — **순위 손실 경로에서는 통과한다**

D-77 은 `regret` 경로의 측정이다. `regret` 은 계단이라 Nelder-Mead 가
평지에 갇히는데, **순위 손실은 미분 가능해 L-BFGS 를 쓴다.** 다시 쟀다.

```
                도달률      재적합 도달률   차원 손실
A8 (순위)      6/6 100%    4/6  67%          —
B16-lo         6/6 100%    6/6 100%        4/6
B16-one        6/6 100%    6/6 100%        6/6
C16-one        6/6 100%    6/6 100%        5/6
★ 통과선       90%         A8 수준(67%)
```

**`B16-*` 두 팔이 도달률 100% · 재적합 도달률 100% 로 통과한다.**
`regret` 경로(92% / 58%)와 대비된다.

⚠️ **차원 손실은 그대로 남는다** — `B16-one` 이 6/6 이고 격차가 최대
+0.2634 다. 즉 **"적합기가 16차원을 못 찾는다" 는 풀렸지만 "16차원이
더 나쁘다" 는 그대로다.** 그 둘은 다른 문제이고, 뒤엣것이 바로 예산
실험이 재려던 것이다.

★ 그래서 **순위 손실 경로에서는 예산 8 vs 16 실험이 성립한다.**
`regret` 경로의 이 항목은 미해결로 남는다.

⚠️ 재는 도중에 **탐침이 어긋나 있었다.** 무작위 4000점 탐침이
`prob.regret` 로 고정돼 있어서 rank 적합 결과를 regret 로 견줬고,
도달률이 0% 로 나왔다. **지표가 어긋난 것이지 적합기 얘기가
아니었다.** 탐침을 적합과 같은 목적함수로 맞췄다.

## 2. ~~`np.isfinite` 상수 우회~~ — **해결 (D-92, 2026-08-30)**

> **★ 아래 본문은 그대로 둔다** — 정정 이력이다. 당시 "먼저 세어 본다"
> 는 판단과 그 결과를 지워 버리면 왜 막았는지가 남지 않는다.
>
> **무엇을 했나** 예고한 대로 D-78 이후 실행에서 셌다. 실행 단위로
> `d75-run2` p = 0.50, `d75-run3` p = 0.24, `d75-run4` p = 0.57 —
> **줄었다고 말할 표본이 없었다** (원칙 27·28). 셋 다 방향은 감소였고
> 셋 다 유의하지 않다. 그래서 "줄지 않으면 막는다" 를 **"줄었다고
> 말할 수 없으면 막는다"** 로 읽고 D-92 에서
> `checks.identity_transform_message` 에 넣었다.
>
> **메시지** 예고대로 "언제나 1" 이 아니라 **"상수 취급 위험"** 이다 —
> 유한성은 표 의존 사실이고 5090 표에서는 다를 수 있다. 대안을 함께
> 적는다 ("리터럴은 예산에서 면제된다, D-78").
>
> **함께 막은 것** `np.sign(...)` 비교, `x < np.sqrt(x)`,
> `np.square(x) < x` — 셋 다 `x < 1` 과 같다.

**전문** [artifacts/f1k-stage1.md](artifacts/f1k-stage1.md)

`np.isfinite(x)` 는 이 표의 f 피처 19개 전부에서 **언제나 1** 이고, 한
규칙 안에서 아홉 번 상수 1 대신 쓰였다. `sqrt`/`square`/`sign` 과 달리
**정당한 용도가 없다.**

### 왜 지금 안 하는가

D-78(분기 비교 상수 예산 면제)로 **우회할 이유가 사라졌다.** 먼저 그것이
듣는지 본다 — 이유가 없어졌는데도 계속 쓰면 그때 막는다. 이유를 없애기
전에 막으면 모델은 또 다른 우회를 찾는다.

### 언제 하는가

D-78 이후 첫 실행의 아카이브에서 `np.isfinite` 사용을 센다. 줄지 않으면
검사기에 넣는다. ⚠️ 메시지는 **"언제나 1"** 이 아니라 **"상수 취급
위험"** 이어야 한다 — 유한성은 표 의존 사실이고 다른 표에서는 실제
판별 기능을 가질 수 있다.

## 5. `sm_idle_cost` 가 극을 담고 있다 — 그리고 검사로 못 막는다

**날짜** 2026-09-01 · **근거** [artifacts/refit-sample.md](artifacts/refit-sample.md)

```python
sm_idle_cost = 1.0 / max(1e-3, 1.0 - tail_waste) - 1.0
```

`tail_waste -> 1` 에서 발산한다. 물리적으로 그 자리는 **타일 수 < SM 수**
로 GPU 가 노는 작은 형상이고, 순위 학습이 어려운 쪽이다.

**선언 범위 정정이 이미 그 신호였다.**
```
expected_range   [0, 10]  ->  [0, 999]      (D-33 계열)
★ 그때는 "범위 선언이 틀렸다" 로 처리했다
```

### ⚠️ 다만 실측은 발산이 아니다 — 서술을 정확히 해 둔다

```
                   최대   99.9분위   중앙    > 10 인 행
A6000            20.00      4.25   0.039    20/980,915  = 0.002%
5090             20.25      9.62   0.062   250/1,262,825 = 0.020%
tail_waste 최대   0.952 / 0.953  (구현이 1e-3 로 자른다)
```

**999 는 구현 상한이지 관측값이 아니다.** 두 표 모두 `tail_waste` 가
0.953 을 안 넘어서 실제 최대는 20 근처다. 그래도 중앙 0.04 대비
**동적 범위가 500배**이고, **5090 에서 꼬리에 드는 비율이 10배**다
(SM 이 170개라 작은 형상이 더 자주 논다). 전이에서 이 항의 성격이
표마다 다르다는 뜻이다.

### 왜 지금 안 하나

**피처를 바꾸면 지금까지의 모든 결과가 무효다** — 라이브러리가 조건이고
(§3.4), 전 실행을 재채점해야 한다. 5090 전이 실험이 도는 중이다.

### ★ 검사만으로는 안 막힌다

```
s0 는 1/(1-tail_waste) 를 **직접 썼다**  -> D-92 가 거부 (isfinite 우회 때문)
★ f.sm_idle_cost 를 쓰면 같은 형태가 통과한다
```

**D-92 가 s0 를 거부한 것은 우회 때문이지 극 때문이 아니다.** 극 검사를
넣더라도 **등록 피처를 통한 경로는 안 막힌다.**

### 언제 / 무엇을

대안은 포화 형태다.
```
1 - 1/(1 + x)   또는   log1p(sm_idle_cost)
동적 범위가 유계가 되고 단조성은 유지된다
```
⚠️ `tail_waste <-> sm_idle_cost` 상관이 0.999 다 (§7.2 라이브러리 표) —
바꾸면 그 쌍의 성격도 바뀐다.

**전이 실험이 끝나고 라이브러리를 손댈 차례가 왔을 때 함께 본다.**
그전에는 **파국 진단에서 이 피처를 쓰는 항을 따로 표시만 한다.**

## 7. ★ D-42 의 셋째 후보 — 셀 축이 죽어 있었다

## 8. ~~두 목적함수를 **합치는** 것~~ — **해결 (D-109, 2026-09-03)**

> ★ λ 스윕을 했다. `regret` 을 직접 안 넣고 **참 1등이 낀 쌍만**
> 재가중하는 부드러운 대리(`rank_loss_top1`)를 썼다.
> **결과: 무릎이 없다.** λ 0->3 에 regret 5.7% 를 얻고 tau 를 잃는
> 얕은 직선이다. 아래 서술은 그대로 둔다 — 규율 정정도 그 안에 있다.

**날짜** 2026-09-01 · **근거** [artifacts/rank-evo.md](artifacts/rank-evo.md)

```
L = rank_loss + λ·(regret - 1)     ★ λ 가 새 조건
상위 100 + 나머지 소수를 섞는다      ★ 비율이 새 조건
```

⚠️ **2026-09-02 정정 — 규율이 바뀌었다.** 아래 문장은 그대로 두되,
금지의 범위가 좁아졌다.

```
옛 규율     "하이퍼파라미터를 하나도 안 만든다"
★ 원래 취지  결과를 보고 값을 고르는 것을 막으려던 것

-> 실험 계획서에 **값 목록을 박고 전부 돌리면** 튜닝이 아니다
-> 스윕은 허용. ★ 결과를 보고 목록 **밖의** 값을 고르는 것만 금지
-> 곡선을 보고하고, 그 값을 쓸지는 **별도 판단**이다
```

(옛 문장) **지금까지 이 실험에 하이퍼파라미터를 하나도 안 만들었다.**

```
k = 100        실험 계획서에 박았다
w = |Δt|/t_best  ★ 물리량이 정한다
T = 1          ★ s = Φw 라 w 크기와 분리 식별되지 않는다 — 정규화다
```

깨려면 **새 실험 계획서가 필요하다.** 그리고 두 단계 방식
([two-stage-prereg.md](two-stage-prereg.md))이 그것보다 싸고 조건이
하나뿐이다 — 먼저 그것을 본다.

**언제**: 두 단계 방식이 실패했을 때.

## 11. ★ 가중치를 형상마다 **하나**로 두는 것 — 마지막 후보

**날짜** 2026-09-03 · **근거** [D-111](../decisions.md) ·
[artifacts/wall.md](artifacts/wall.md) §6

벽의 원인을 다섯 갈래로 지웠다 (구조 / 예산 / 순서 / 표현력 / 목표
정의). 남은 것은 **가중치 벡터가 형상마다 하나**라는 것이다. 지금은
체제별로 둘이다.

```
(a) 체제를 셋 이상으로 나눈다        ★ 경계가 새 조건이 된다
(b) 가중치가 비선형 자리에 들어가게 한다
    np.power(f.a, w[0]) / np.where(f.x > w[1], ...)
    -> s = Φw 가 깨진다. T=1 논거도 다시 봐야 한다
```

⚠️ **(b) 는 2026-09-03 에 했다 — 음성이다** (D-112). 제안 18% 가
썼고, 학습 목적함수에서부터 더 나빴고(1.1814 vs 1.0333), 판정선
tau>=0.20 에 +0.055 로 미달했다. **"안 썼다" 가 아니라 "쓰고 졌다"** 다.

남은 것은 **(a) 뿐**이다. 형상마다 가중치 벡터가 하나라는 것 자체를
깨는 유일한 방향이고, 파라미터가 2배가 되므로 재적합 표본 요구가 커진다.

### ⚠️ 유보 — (a) 도 "형상마다 하나" 를 안 깬다 (2026-09-03)

```
체제를 셋으로 나눠도 여전히 **그 체제 안에서는 가중치가 하나**다
진짜로 깨려면 형상별 가중치인데 ★ 그것은 규칙이 아니라 룩업 테이블이다
(b) 지수 자리는 D-112 가 이미 했고 **겨뤄서 졌다**
-> 남은 후보가 사실상 없다
```

그래서 이것은 "다음에 할 일" 이 아니라 **"여기까지가 이 형태의 한계"**
로 읽는 편이 맞다. 하려면 파라미터가 2배가 되고 재적합 표본 요구가
커진다 (D-98).

**언제**: 지시가 있을 때. 새 실험 계획서가 필요하다.

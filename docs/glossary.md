## 규칙의 출처

두 규칙 **모두 LLM 이 썼다.** 사람은 방향을 정하고 물리 오류를 지적했지
규칙 코드를 쓰지 않았다.

| 이름 | 무엇 | 무엇에 맞췄나 |
|---|---|---|
| **`human_guided`** (개명 전 `physics_seeded`, D-128) | Claude Code 가 물리 문서를 읽고 **한 번에** 작성 (`rules/human_guided.py`). ★ 그 뒤 표 관측으로 **네 판** 고쳤다 (1.776 -> 1.192) | 물리 + 표 요약 |
| **`evolved`** | 그 파이프라인이 GPT 로 20라운드 진화 (`runs/*/archive.jsonl`) | 학습 분할 regret |

> ⛔ **`handwritten` / `손규칙` 은 쓰지 않는다.** "사람 대 LLM" 이라는 틀린
> 대비를 만든다. 차이는 **누가** 가 아니라 **무엇에 맞췄는가** 다.

두 규칙의 입력 차이가 결과 차이를 만들었다 — ★ 어느 쪽도 "표를 안 봤다" 가 아니다:

| | `human_guided` | `evolved` |
|---|---|---|
| 입력 | 물리 문서 + 요약 통계 | 사례 15개 + regret |
| 요구 | "물리를 코드로 옮겨라" | "이 가설을 반영해라" |
| 피드백 | 물리 오류 지적 3회 | 점수 |
| 목적함수 | 없음 (구조만) | 학습 분할 regret |

## 체제 (regime)

**성능을 지배하는 물리가 다른 형상 그룹.** 주 축은 커널 실행 시간이다.

> ⛔ **"짧은 형상 / 긴 형상" 은 쓰지 않는다.** 행렬 차원 크기로 읽힌다.
> `512x12288x4096` 은 차원이 크지만 **빠른 체제**다.

| 이름 | 정의 | A6000 (align 8/8/8 61형상) |
|---|---|---|
| **빠른 체제** (sub-ms) | `SOL < 0.5 ms` | 41형상 |
| **느린 체제** (supra-ms) | `SOL >= 0.5 ms` | 20형상 |

### ★ 판정은 반드시 대리 지표로 한다

```
SOL = max(2MNK / 실효피크연산,  움직인바이트 / 실효대역폭)
      형상 + 하드웨어 상수만. 배포 시점에 계산된다.
```

`t_best < 0.5 ms` 로 자르고 싶지만 `best_ms` 는 `ANSWER_COLS` 다. 분할
정의에 정답이 들어가면 그 홀드아웃은 오염되고, **새 GPU 에서는 전수
측정을 해야 체제를 알게 되어 전이의 의미가 사라진다** (§10.1, §29.5).

구현: `core/splits.py::regime_of(axis="size")` — `log_sol_ms` 를 쓴다.

**실측 (2026-08-21, `experiments/proxy_dispatch.py`):** 두 정의가 61형상
전부에서 일치한다 (100%, 오분류 0).

**★ 그러나 100% 를 안전으로 읽지 마라.** `t_best / SOL` 중앙값이 **1.140**
이므로 두 판정은 `SOL ∈ [438, 500] us` 인 띠에서 갈린다. **그 띠에 실제로
형상이 둘 있다:**

```
512x12288x4096   SOL 443.9us   t_best 497.7us   <- 500 에서 2.3us
1536x4096x4096   SOL 443.9us   t_best 496.6us   <- 500 에서 3.4us
```

0.5% 만 느렸어도 오분류였다. **일치율 100% 는 이 표의 운이고, 견고성의
증거가 아니다.** 새 표에서는 다시 재야 한다.

### 보조 축

| 이름 | 정의 | 쓰임 |
|---|---|---|
| roofline 체제 | `is_memory_bound` (mem / comp) | 규칙 안의 형상 분기 |

크기 축이 난이도 축보다 **5배 더 갈린다** (k=1: 1.021 vs 1.164). 층화
보고는 크기가 먼저다 (§30.5).

## 노이즈 바닥 (noise floor)

```
noise_floor(t) = max(sigma_rel(t), tick_pct(t))
```

형상마다 다르다. 통계적 흔들림은 평균으로 줄지만 **눈금 해상도는 줄지
않는다.** 이 값보다 작은 차이는 순위가 아니다 (§30).

## regret

```
regret@k = (규칙이 고른 상위 k 중 최선의 시간) / (그 형상의 최적 시간)
```

집계는 기하평균. **전체 geomean 하나만 보고하지 않는다** — 소수 형상의
큰 손실에 끌린다 (§30.4). 승패 카운트를 함께 낸다 (`core/scoring.compare`).

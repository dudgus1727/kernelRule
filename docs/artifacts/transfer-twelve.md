## 3. ★ H100 에서는 전이가 **기준선을 못 이긴다**

(c) 가 없어도 답할 수 있는 것이 있다. `human_guided` 를 그 표에서 재적합한
**기준선**과 대면 된다.

```
대상 4090    기준선 1.0761   (b) 1.0544 / 1.0628     ★ 전이가 이긴다
대상 5090    기준선 1.1401   (b) 1.0748 / 1.0746     ★ 전이가 이긴다
대상 a6000   기준선 1.1398   (b) 1.1313 / 1.1199     전이가 조금 이긴다
★ 대상 h100  기준선 1.0937   (b) 1.1752 / 1.1031 / 1.1420
                             ★ 셋 다 **진다**
```

판정선(사전 등록 §2)으로 읽으면:

```
a6000 -> h100   (b) - 기준선 = +0.0815   ★ 0.0589 초과 — 차이가 있다
4090  -> h100                 +0.0483     구분 불가
5090  -> h100                 +0.0094     구분 불가
```

**하나만 판정선을 넘지만 부호가 3/3 이다.** 다른 세 표에서는 (b) 가
기준선보다 **항상 좋았다** — H100 이 처음이다.

## 4. ★ 뒤집힘 0 이 (a) 를 보호하지 않는다

```
뒤집힘 0 인 방향 셋
  a6000 -> 4090   (a)-(c) +0.0116          잘 된다
  4090 -> a6000   (a)-(c) ★ +0.1478        안 된다
  5090 -> h100    (a) 1.2382, 기준선 대비 ★ +0.1445   안 된다
★ 1승 2패. "체제가 유지되면 이식된다" 는 더 약해진다
```

D-126 이 이미 한 방향에서 봤던 것이 **세 번째 사례로 확인된다.**

## 5. ★ 관대함 지표 둘이 **H100 에서 갈린다**

네 표에 다 있는 48형상:

| 표 | 정답 집합 (중앙) | 사분위 | 10등이 1등보다 | 100등이 1등보다 |
|---|---:|---|---:|---:|
| a6000 | 4.0 | [3, 8] | 1.2% | **6.6%** |
| 5090 | 10.0 | [4, 34] | 0.2% | 1.6% |
| ★ h100 | 15.0 | [10, 25] | 0.8% | **6.7%** |
| 4090 | 38.5 | [23, 100] | 0.5% | 1.6% |

```
정답 집합 순서    a6000 4  <  5090 10  <  ★ h100 15  <  4090 38.5
100등 순서       5090 1.6% = 4090 1.6%  <  a6000 6.6% ≈ ★ h100 6.7%
★ H100 은 정답 집합으로는 가운데, 100등 지표로는 **A6000 과 같은 자리**다
```

**실험 계획서 §4 가 "갈리면 그 자체가 결과다" 라고 미리 적었다. 갈렸다.**

그리고 **전이 결과는 100등 지표 쪽과 맞물린다** — A6000 과 H100 이
"실수를 크게 벌하는 표" 이고, 둘 다 전이가 어렵다. D-130 의 기전은
**정답 집합 크기가 아니라 상위권 간격** 쪽으로 좁혀진다.

### 5-1. 노이즈 계수 논란은 **결론을 안 바꾼다**

```
sigma_rel 2.0006e-03 (번들)      h100 정답 집합 중앙 15.0  [10, 25]
sigma_rel 8.158e-04 (제보)       h100 정답 집합 중앙 ★ 10.0  [4, 22]
★ 어느 쪽이든 5090(10) 과 4090(38.5) 사이다 — 순서가 안 바뀐다
★ 100등 지표는 계수와 무관하므로 6.7% 그대로다
```

### 5-2. ⚠️ 계수 제보를 **재현하지 못했다**

원자료 `results-raw-63684546.jsonl.zst` 를 직접 봤다.

```
번들 노트   앵커 12조합 x 454회 = 5,448줄
실측        ★ 반복 조합이 64개 x 227회다. 그리고 각 행이 이미 n_reps 평균이다
제 적합     sigma_abs 2.731e-04 / sigma_rel 1.844e-03
번들 값     sigma_abs 4.303e-04 / sigma_rel 2.001e-03
```

**제 앵커 집합이 그쪽 앵커 집합이 아니다** — 그래서 계수가 안 맞는 것이
당연하고, 이 재현 실패는 **제보를 반박하지 않는다** (원칙 4).

제보의 "2.63/2.88 ms 쌍봉 하나" 도 못 찾았다 — 그 시간대에 앵커가 없다
(1.85 -> 14.19 로 건너뛴다). 대신 **작은 커널(0.029~0.075 ms)에서 26/64 가
쌍봉**이고 모드 차가 1.2~2.7% 다. 그 26개를 빼면 `sigma_rel` 이 오히려
**커진다** (2.809e-03).

★ **번들 계수를 그대로 쓴다.** 필요한 것은 §5-1 의 괄호이고, 그것으로
결론이 안 바뀌는 것을 확인했다.

⚠️ kernelTab 에 물어볼 것: **앵커 12조합이 어느 것인가.**

## 6. (b) ≈ (c) — D-126 의 예외가 사라졌다

```
D-126    "대상이 a6000 이면 (b)-(c) 가 판정선 근처다" (+0.0551 / +0.0437)
★ 지금   +0.0427 / +0.0313   — 둘 다 판정선 0.0516 **안**
```

대표값이 `F3rw-p8-nan` r11 (1.0886) 로 바뀌면서 (c) a6000 이 나빠졌고,
그만큼 격차가 줄었다. **(b) ≈ (c) 가 세 대상 모두에서 유지된다.**

⚠️ 이것은 **(c) 가 나빠져서 생긴 유지**다. "재적합이 좋아졌다" 가 아니다.

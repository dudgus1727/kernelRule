# ★ 세 쌍 여섯 방향 — **전이 손해는 출처가 아니라 대상이 정한다**

> **재현**: `python3 experiments/transfer_29_5.py --pair <src> <dst>` (여섯 번)
> -> `python3 experiments/transfer_six.py`   (전부 **LLM 0회**)
> **사전 등록**: [transfer-4090-prereg.md](transfer-4090-prereg.md)
> **원자료**: `transfer-<src>-<dst>.json` 여섯 + `transfer-six.json`
> **(c) 4090**: LLM 약 470회 · 3시드 x 11라운드 (`f1pipe-F3-4090sigma`)
> **σ**: `sigma-4090.json`

## 0. 세 팔

```
(a) 완전 이식   출처의 구조 + 출처에서 맞춘 가중치를 **그대로** 대상에서 채점
(b) 재적합      구조 고정, 대상의 학습 분할로 가중치만 다시
(c) 재생성      대상 표에서 처음부터   ← 그 표의 "원주민"
```

## 2. 질문 1 — 뒤집힘 0 인 쌍에서 (a) 가 되나 → **된다. 한 방향만**

```
a6000 -> 4090   (a)-(c) = +0.0074   ★ 판정선 0.0516 의 14%
4090 -> a6000   (a)-(c) = +0.1602   ★ 판정선의 3.1배
```

**같은 쌍, 바운드 뒤집힘 0, ridge 비 1.00 인데 방향이 갈린다.**
"체제가 유지되면 이식된다" 는 **한 방향에서만** 참이다.

그리고 5090 → 4090 에서는 **(a) 가 (c) 보다 좋다** (−0.0052). 뒤집힘이
3개 있는 쌍인데도 그렇다.

## 3. 질문 2 — (b) ≈ (c) 가 유지되나 → **대상이 4090·5090 이면 유지, a6000 이면 아니다**

```
-> 4090   +0.0056 / +0.0135     유지
-> 5090   -0.0072 / +0.0135     유지
-> a6000  +0.0551 / +0.0437   ★ 판정선 근처. 한쪽은 넘는다
```

★ 뒤집힘을 빼면 `5090->a6000` 의 (b) 는 −0.0050 으로 **돌아온다**.
`4090->a6000` 은 뒤집힘이 0이라 뺄 것이 없고 +0.0551 그대로다.

## 4. 질문 3 — ridge 상관? **아니다**

```
쌍                |log(ridge비)|   뒤집힘   (a)-(c) 두 방향 평균
4090 + 5090            0.305         3            0.0175
4090 + a6000     ★     0.005         0            0.0838
5090 + a6000           0.300         4            0.1082
```

**ridge 가 거의 같은 쌍(4090+a6000)의 손해가 중간이다.** ridge 차이로도
뒤집힘 수로도 순서가 안 나온다 — 쌍 단위로는 설명이 안 된다.

## 5. ★ 그런데 **대상별로 자르면 깨끗하다** (사후 관측)

⚠️ **사전 등록에 없던 자름이다.** 판정이 아니라 관측이고, 다음 실험의
가설이다.

| 대상 표 | (c) 원주민 | 기준선 physics_seeded | (a)−(c) 출처별 | (b)−(c) 출처별 |
|---|---:|---:|---|---|
| **4090** | 1.0493 | 1.0761 | a6000 **+0.0074** / 5090 **−0.0052** | +0.0056 / +0.0135 |
| **5090** | 1.0611 | 1.1401 | a6000 +0.0465 / 4090 +0.0403 | −0.0072 / +0.0135 |
| **a6000** | 1.0762 | 1.1398 | 4090 **+0.1602** / 5090 **+0.1699** | +0.0551 / +0.0437 |

```
★ 두 출처가 같은 대상에서 거의 같은 손해를 낸다 (차이 0.0062~0.0126)
★ 대상이 바뀌면 손해가 15배 달라진다 (0.001 -> 0.165)
-> 손해는 **어디서 왔나**가 아니라 **어디로 가나**로 정해진다
```

### 손해 순서가 그 표의 **원주민 성적** 순서와 같다

```
대상    (c) 원주민   (a)-(c) 평균
4090     1.0493        +0.0011
5090     1.0611        +0.0434
a6000    1.0762        +0.1651
```

**원주민이 잘 하는 표일수록 남의 규칙을 잘 받아준다.** 뒤집어 말하면,
A6000 은 최적이 좁아서(원주민도 1.076 밖에 못 간다) **남의 가중치로는
그 좁은 곳을 못 맞춘다**.

⚠️ **인과가 아니다.** 표 셋, 방향 여섯이고 사전 등록에 없던 자름이다.
"규모" 도 "ridge" 도 아닌 **세 번째 축**이 있다는 신호까지다.

## 6. 판정선 — 사전 등록 §4 의 규칙대로

```
σ (구조 홀드아웃 시드 폭, 정준 절차)
  A6000   0.0124  (n=6)
  5090    0.0130  (n=3)   95% 상한 0.0319
  ★ 4090  0.0241  (n=3)   95% 상한 0.1514   ← 이번에 쟀다

delta = max(0.0516, σ상한으로 계산한 값)   (n=3, 양측 0.05, 검정력 0.8)
  -> 4090 이 대상이면 σ 상한 기준 delta = 0.35 (점추정 기준 0.055)
```

**4090 의 σ 가 넓다** — 세 시드가 1.0433 / 1.0493 / **1.0877** 이고
하나가 튄다. 사전 등록의 규칙대로 **더 큰 선**을 쓰면 4090 이 대상인
방향에서는 **아무것도 구분되지 않는다.** 그러므로:

```
말할 수 있는 것    a6000 을 대상으로 한 (a) 손해(+0.16)는 어떤 선으로도 크다
말할 수 없는 것    ★ "4090 으로는 완전 이식이 된다" — 이것은 **구분 불가**이지
                  "같다" 가 아니다 (σ 상한이 넓어서 못 가른다)
```

**(a) 가 4090 에서 작동한 것처럼 보이는 것을 "된다" 로 쓰지 않는다.**
시드 여섯으로 다시 재야 한다.

## 7. §29.5 의 결론은 어떻게 되나

```
전    "가중치는 하드웨어 상수다" (A6000 <-> 5090 한 쌍)
★ 후  대상에 따라 다르다.
      a6000 이 대상이면 그 진술이 강하게 선다 (+0.16)
      4090 이 대상이면 (a) 와 (c) 를 못 가른다
      -> "하드웨어 상수" 는 **대상 표의 성질**로 다시 써야 한다
```

`(b) ≈ (c)` 는 여섯 중 넷에서 유지되고, a6000 대상 둘에서 판정선 근처다.
**구조가 옮겨진다는 것은 여전히 서 있다.**

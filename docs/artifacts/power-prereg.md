# 사전 등록 — 가중치를 **지수 자리**에 (형태 (b))

**LLM 호출 0회 시점에 쓴다.** 근거: [D-111](../decisions.md) §셋을 합치면,
[wall.md](wall.md) §6, [pending_fixes 11](../pending_fixes.md).

## 1. 왜 이것만 남았나

```
구조가 아니다      축 자카드 1.000
예산이 아니다      8 vs 16 구분 불가 (D-108)
순서가 아니다      두 순서 다 (D-104)
표현력이 아니다    곱은 원래 됐고 명시해도 그대로 (D-110)
목표 정의도 아니다  k 10~100, λ 0~3 (D-109/D-111)

지금까지 넓힌 것   항 수 / 노드 수 / 곱
★ 안 건드린 것     ★ 가중치가 **선형 자리에만** 있다는 것
```

D-110 이 신호를 줬다 — 모델이 스스로 `f.reg_pressure ** 3` 을 만들었는데
**지수가 고정 상수였고 맞춰지지 않았다.**

★ (a)(체제를 셋 이상)보다 (b)를 먼저 한다: (a)는 파라미터가 2배가 되고
형상 41개에 가중치 32개면 비율이 나쁘다 (D-98 의 재적합 표본 요구도
커진다). **(b)는 파라미터가 안 는다 — 자리만 다르다.**

## 2. 형태

```python
s = s + np.power(f.<이름>, w[3]) * w[4]      # 예산 둘
```

## 3. 수치 가드 — **돌리기 전에 박는다**

```
np.power(x, w) 에서
  x < 0 이고 w 가 정수가 아니면   nan
  x = 0 이고 w < 0 이면           inf
  x 가 크고 w 가 크면             오버플로
```

앞의 둘은 **밑을 묶어서** 막는다:

```
1. 밑은 `f.<이름>` **하나**여야 한다 (식은 거부)
2. 그 축의 **선언 범위** 최소가 0 이상이어야 한다
   ★ 관측 범위가 아니다 — 이 표에서 우연히 양수였던 축이 다른 표에서
     음수일 수 있다
3. 지수는 `w[i]` **하나**여야 한다 (식은 거부 — 경계를 못 붙인다)
```

⚠️ **가드는 힌트와 무관하게 항상 걸린다.** 조건이 아니라 수치 안전이다.
정적 검사와 LLM 경계(pydantic) 양쪽에 있다 — 경계에 있어야 모델이
이유를 듣고 고쳐 낸다.

## 4. 지수 경계 — ★ 하이퍼파라미터가 아니라 **정규화**다

```
EXPONENT_BOUNDS = (0.0, 4.0)

하한 0   음수 지수는 f == 0 에서 inf 이고, 모든 피처가 "클수록 나쁨"
        이므로 방향을 뒤집는다 (§8.2)
상한 4   정규화된 피처의 4제곱보다 빠르게 자라는 벌은 매끄러운 물리
        반응이 아니라 사실상 **문턱**이고, 문턱은 `np.where` 가 이미
        한다 — 즉 표현력을 빼지 않는다
```

★ **이 값을 쓸어보지 않는다.** 쓸어보면 그때부터 하이퍼파라미터다
(스윕 규율은 값 목록을 미리 박을 때만 허용된다).

경계는 **접기(projection)로** 강제한다 — L-BFGS-B 에는 `bounds` 로,
Nelder-Mead 와 다듬기에는 목적함수 안에서 접어서. 한 곳에서만 강제된다.

⚠️ `weight_bounds` 는 **지수 자리가 없으면 `None`** 을 돌려준다. 경계를
항상 붙이면 지수를 안 쓰는 옛 실행까지 조용히 다른 조건이 된다 (원칙 36).

### 시작 전 1라운드 실측 (D-107 절차) — ★ 한 번 고쳤다

```
1차   제안 12개 중 지수 항 0개
```

네 면에는 다 실렸는데 안 썼다. 프롬프트 예시가
`np.power(f.a, w[3]) * w[4]` **하나뿐**이라 "예산 둘" 로 읽혔고, 부모가
이미 8항이라 `예산이 찼습니다` 와 정면으로 부딪혔다. **형태를 실어도
쓸 수 없게 틀을 짠 것**이다.

예시를 고쳤다 — `f.a * w[i]` 를 `np.power(f.a, w[i])` 로 **바꾸면 예산이
안 는다**를 앞세운다.

```
2차   제안 12개 중 지수 항 1개
```

**본 실행은 2차 프롬프트로 돈다.** 1차는 안 돌렸다.

## 7. 판정선

```
★ regret 재적합 상위100 tau >= 0.20  이면서  regret <= 1.15
   -> 벽이 낮아졌다
그 밖
   -> 벽은 형태의 문제가 아니다

★ 그리고 지수가 실제로 1 에서 벗어나는가
   적합된 지수 가중치의 분포를 낸다. |w - 1| 이 작으면 결론이 다르다 —
   "형태를 줬는데 안 썼다" 이지 "형태가 부족했다" 가 아니다
```

전부 홀드아웃 20형상 + 무작위 바닥 (원칙 7).

## 8. ★ 예상

**벽을 못 낮춘다.** 여섯 방향이 다 음성이었고, 지수는 각 항의 **모양**을
바꿀 뿐 여전히 형상마다 가중치 벡터가 하나다. 다만 지수가 1 에서
크게 벗어나면 "형태에 여지가 있었다" 는 별개의 관찰이 된다.

# 사전 등록 — (c) 재생성을 **맞는 하드웨어 사실로** 다시 돌린다

**LLM 호출 0회 시점에 쓴다.** 근거: [D-113](../decisions.md).

## 1. 왜

§29.5 의 (c) 재생성(`f1pipe-F3-5090sigma-s{0,1,2}`)이 **A6000 하드웨어
사실을 받고 돌았다.** 여섯 실행의 `config.json` 이 전부
`llm.arch_prompt == "hw/sm_86.md"` 다.

```
RuleWriter 가 받은 것   A6000 / SM 84 / L2 6 MB / ridge 159.1 / 눈금 1.024us
실제 5090              SM 170 / L2 96 MB / ridge 117.9 / 눈금 0.016us
```

숫자가 코드로 샌 흔적은 **없다** (씨앗 후보 10개의 리터럴은 전부 `w[i]`
첨자뿐). 그런데 **산문은 움직였다** — 측정 한계 절("짧은 형상용으로
정교하게 만들지 마라") 때문에 2/10 이 `p.log_sol_ms` 로 형상 길이를
가르고, **채택된 씨앗(try03)이 그 둘 중 하나다.** 5090 의 눈금은
A6000 의 1/64 라 그 조언 자체가 약하다.

## 2. 묻는 것

```
"(c) 재생성이 **맞는** 하드웨어 사실을 받으면 달라지나"
```

## 3. 조건

```
표        rtx-5090-sm_120-5bb6f403 · 공통 53형상 · 분할 nk11008
hw       ★ 번들 env.json 에서 생성 (D-113). check_hw_prompt 가 확인한다
씨앗      ★ 새로 만든다 — RuleWriter 10개 중 학습 regret 최소
          `--seed-from` 을 쓰지 않는다. 쓰면 (c) 가 아니다
진화      3시드 x 12라운드 x 12제안 · 예산 8 · 목적함수 regret
모델      DEFAULT_MODEL (gpt-5.6-luna) · responses · medium
태그      5090sigma-hw
```

```
python3 experiments/f1_pipeline.py F3 \
  --seed-source rule_writer --n-rule-writer 10 \
  --bundle datasets/rtx-5090-sm_120-5bb6f403 --env-hash 5bb6f403 \
  --n-seeds 3 --rounds 12 --workers 6 --tag 5090sigma-hw
```

⚠️ **정정 (돌리기 전, LLM 0회).** 처음에 `--stage 2` 와 기본
`--seed-source` 로 적었다. 둘 다 틀렸다:

```
--stage 2          ★ 2단계'만' 돈다 (stages = (a.stage,)). 3단계가 안 돈다
--seed-source      F3 의 기본은 `physics_seeded` — RuleWriter 를 아예 안 부른다
                   그러면 씨앗이 **손씨앗**이고 (c) 가 아니다
```

`--stage` 를 안 주면 F3 는 1단계를 자동으로 건너뛰고 (2, 3) 을 돈다.
그대로 돌렸다가 `n_tries: 0 / source: physics_seeded` 로 끝났고 **LLM
호출은 0회**였다 — 산출물을 지우고 다시 시작했다.

⚠️ **옛 (c) 결과를 지우지 않는다.** 조건 오류로 표시하고 남긴다.

## 4. 판정선 — ★ 이미 재 둔 σ 로 정한다

`sigma-5090.json` 에서 5090 의 시드 폭은 σ = 0.0130, 95% 상한 0.0319 다.
**상한 기준 판정선 delta = 0.0516** 을 쓴다 (원칙 7 — 이미 §29.5 가 쓴
선이고 여기서 새로 정하지 않는다).

```
새 (c) 가 옛 (c)(1.0485) 보다 0.0516 이상 좋다
  ★ hw 사실이 쓰인다. §29.5 의 (b) ≈ (c) 를 다시 쓴다
구분 불가
  ★ hw 산문은 결과에 안 쓰인다 — table_facts 가 지배한다
  §29.5 결론 유지. 다만 조건 오류는 기록으로 남는다
```

★ **어느 쪽이든 결과다.** 그리고 (b) 1.0539 와도 나란히 놓는다.

## 6. ★ 예상

**구분 불가일 것이다.** 숫자가 코드로 샌 흔적이 없었고, 진화 12라운드가
`table_facts`(그 표의 관측)를 매 라운드 본다 — hw 산문 한 절보다 그쪽이
훨씬 세게 규칙을 정한다. 다만 §5-1(씨앗의 형상 길이 분기)은 **바뀔 것**
으로 본다.

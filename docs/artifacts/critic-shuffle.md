## 방법

항 **순서만** 바꾸고 `w` 인덱스를 새 순서로 다시 매겼다. 식은 글자
하나 안 바꿨다. 시드 `20260828` 고정.

## ★ 결과 — 편향이 아니다

| 실행 | 원래 지목 | 섞은 뒤 | 공통 | 자카드 |
|---|---:|---:|---:|---:|
| s0 | 2 | 3 | 2 | 0.67 |
| s1 | 2 | 1 | 1 | 0.50 |
| s2 | 0 | 0 | — | (둘 다 없음) |
| s3 | 4 | 3 | 3 | 0.75 |
| s4 | 3 | 5 | 3 | 0.60 |
| s5 | 2 | 2 | 2 | **1.00** |

```
자카드 중앙  0.67 (빈 집합 제외 n=5)  /  0.71 (s2 를 1.0 으로 세면)
실험 계획서 기준: >= 0.60 이면 편향이 아니다   ★ 통과
```

⚠️ **s2 의 1.00 은 "둘 다 0건" 이다** — 완전 일치가 아니라 비교
대상이 없는 것이다. 그래서 두 값을 같이 적는다.

### 보조 지표도 같은 방향

```
실험 계획서: 섞은 뒤 마지막 두 자리(w6, w7) 지목률이 60% 이상이면 위치 편향

원래     w6+w7 자리에서 8/13 = 62%
섞은 뒤  w6+w7 **자리**에서 3/14 = 21%     ★ 위치를 안 따라간다
섞은 뒤 지목된 식의 **원래** 자리는 w6+w7 이 8/14 = 57%
```

**자리를 바꿔도 같은 식이 따라온다.** 뒤에 있던 식이 앞으로 가도 여전히
지목되고(s3, s5), 새 마지막 자리에 온 식은 대부분 안 지목된다.

## ★ 그러므로 D-85 의 "뒤쪽 편중" 은 편향이 아니라 **관찰**이다

```
w7 지목률 83%, w6 50% 였던 것은
"LLM 이 마지막 것을 찍는다" 가 아니라
★ "진화가 뒤에 붙인 항이 실제로 설명하기 어렵다" 였다
```

Optimizer 는 항을 **뒤에 덧붙인다**(교체 프레임은 예산이 찼을 때만
작동한다). 그렇게 나중에 붙은 항이 앞의 항보다 물리적 근거가 약하다.

**이것은 진화의 성질에 대한 관찰이고 Critic 의 결함이 아니다.**

## 판정 개수는 흔들린다

```
지목 수   2->3   2->1   0->0   4->3   3->5   2->2      합 13 -> 14
```

**총계는 안정적이지만 규칙마다 ±2 흔들린다.** 실험 계획서에 적은 대로
그 자체가 관찰이다 — **지목 여부는 재현되지만 지목 강도는 아니다.**
새 통과 조건에서 "몇 개를 지목했나" 를 지표로 쓰면 안 된다.

## 그러면 D-85 의 통과 조건 실패는 무엇이었나

도구는 안정적이다. 그러므로 **통과 조건의 정의가 틀렸다는 쪽**(D-85 3-가)이
남는다.

```
Critic 의 주장   "이 항을 물리로 설명 못 하겠다"
D-85 가 잰 것    "이 항을 빼도 학습 점수가 안 나빠진다"
★ 항 하나가 중요하면서 동시에 설명 불가일 수 있다
```

**다음 통과 조건은 "쓸모없음" 이 아니라 "일반화 안 됨" 을 재야 한다.**

```
설명 가능한 항   물리라서 다른 형상에도 적용된다
                -> 빼면 적합/검증이 비슷하게 나빠진다
설명 불가한 항   학습 형상에 맞춰진 것
                -> ★ 빼면 적합만 크게 나빠지고 검증은 덜 나빠진다

지표   각 항 제거 시 (적합 손상) - (검증 손상)
분할   ★ 학습 41 을 적합 30 / 내부검증 11 로 쪼갠다
       구조 홀드아웃 20 은 안 건드린다 — 이미 여러 번 봤다
비용   LLM 0회. 절제 데이터가 있으니 내부검증 채점만 더한다
```

**아직 안 했다.**

# Cascade — 2단계가 **해를 끼친다**

실험 계획서 [cascade-prereg.md](cascade-prereg.md). **LLM 0회.**

```
python3 experiments/cascade.py      # -> docs/artifacts/cascade.json
```

```
1단계   regret 규칙으로 상위 k 를 추린다      (영역 선택)
2단계   순위 규칙으로 그 안에서 1등을 고른다   (순서)
```

A6000 홀드아웃 20형상 · regret 팔 6구조 x 순위 팔 3구조 = **18 조합**.
가중치는 둘 다 체제별로 학습 분할에서 재적합 (최종 채점 §10).

---

## 1. 결과

```
기준선  regret 단독 regret@1   중앙 1.0762   시드 범위 1.0566~1.0919

   k   ★ cascade 중앙        범위        천장 oracle@k   바닥 무작위in-k   hit@k
  10       1.1145   1.0578~1.1649        1.0535        1.0832    2.5%
  20       1.1222   1.0495~1.1615        1.0404        1.0872   12.5%
  50       1.1342   1.0708~1.4241        1.0276        1.1215   30.0%
```

## 2. 판정 — **2단계가 해를 끼친다**

세 k 전부 기준선 범위(1.0566~1.0919) **위**다.

★ **그리고 무작위보다 나쁘다.** 1단계의 상위 k 안에서 **아무렇게나
고르는 것**보다 순위 규칙으로 고르는 쪽이 더 나쁘다:

```
k=10   무작위 in top-10  1.0832   ->  순위 규칙 1.1145   (+0.0313)
k=20   무작위 in top-20  1.0872   ->  순위 규칙 1.1222   (+0.0350)
k=50   무작위 in top-50  1.1215   ->  순위 규칙 1.1342   (+0.0127)
```

실험 계획서의 보조 판정("바닥과 구분 불가면 2단계가 아무것도 안 더한다")
보다 **한 칸 더 나쁜 쪽**이다.

## 3. 그래서 벽의 진술이 더 좁아진다

앞서 이렇게 적었다:

```
순위 규칙   순서는 매긴다.  ★ 어느 영역이 좋은지 모른다
```

**"영역을 몰라서" 만이 아니었다.**

```
★ 좋은 영역을 **줘도** 그 안에서 무작위보다 못 고른다
```

`regret@k`(D-118)와 이어 보면:

```
참 상위 100 을 주면       노이즈 인식 tau 0.410   ★ 순서를 매긴다
regret 규칙의 상위 10 을 주면  무작위보다 나쁘다      ★ 못 매긴다
```

두 집합이 다르다. **순위 규칙의 순서 능력은 "참 상위 100" 이라는
집합에 붙어 있고, 다른 집합으로 옮기면 사라진다.** D-100 의 "순위
능력이 전이 안 된다" 와 같은 모양이 **표 안에서** 나타난다.

## 4. 곁가지 — `hit@k` 가 낮다

```
k=10   2.5%     k=20  12.5%     k=50  30.0%
```

1단계의 상위 10 안에 **참 1등이 들어 있는 형상이 20개 중 0.5개**다.
그런데 천장(oracle@10)은 1.0535 로 나쁘지 않다 — **참 1등은 거의 못
잡지만 그 근처는 잡는다.** 이 표에서 "1등" 이 얼마나 좁은 표적인지
보여준다 (동률 구조, §2 의 tie-break).

★ **cascade 가 좋아졌더라도 천장이 1.0276~1.0535 다.** 1단계를 안
고치면 그 아래로 못 간다.

## 5. 예상과 대조

```
실험 계획서 §6   "범위 안일 것 (= 우회 안 된다)"       ✗ **더 나빴다**
              "바닥과의 거리는 볼 만하다"           ✓ 바닥보다 나쁘다
```

예상이 방향은 맞고 **정도를 틀렸다.** "순서 능력이 갑자기 생길 이유가
없다" 고 적었는데, 실제로는 **있던 것도 없어진다.**

## 6. 유보

```

k 는 실험 계획서의 셋뿐이다
"짝" 이 임의라 분포로만 읽는다 — k=50 의 상단 1.4241 이 한 조합이다
```

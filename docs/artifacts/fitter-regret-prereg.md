# 사전 등록 — regret 경로에서 **적합기가 16차원을 버티는가** (§2 관문)

**LLM 호출 0회.** 계산 전에 쓴다.

## 0. 왜 이것이 관문인가

표현력 셋(예산·곱·지수)이 **전부 순위 손실 경로에서만** 돌았다
(D-108·D-110·D-112). 순위 손실은 틀린 목적함수였으므로(D-118·D-121)
"표현력을 넓혀도 안 된다" 를 **regret@1 경로에서 다시 재야** 한다.

그런데 예산 16 은 D-77 에서 막혀 있다.

```
D-77   regret 경로, 16항, 도달률 83~92% -> 사전 등록 기준 90% **미달**
       재적합 도달률 42~58% (A8 은 75%)
       원인 후보 (가) 재시작이 전부 국소 (나) 예산 부족 (다) 다듬기 쌍좌표
```

**적합기를 먼저 풀어야 "예산 16 이 나쁘다" 를 잴 수 있다** (원칙 1).
못 풀면 §3-1(예산 8 vs 16)은 접고 §3-2·3-3 만 예산 8 로 돈다.

## 1. 재는 것 — D-77 과 **같은 방법**

새 지표를 만들지 않는다 (원칙 2). `experiments/fitter_dim.py` 의
절차를 그대로 쓴다.

```
대상      regret 진화 6실행(`f1pipe-F3-arch24-s0..s5`)의 최종 규칙
          x 체제 short/long = 12칸/팔
확장      안 쓰인 피처를 선형 항으로 붙여 16항.
          ★ 새 항의 초기 가중치 0.01 — 지시문의 "작은 가중치로"
          모자라면 이미 쓴 피처의 제곱 -> 두 피처의 곱 (이진 피처 제외)
목적함수  ★ regret (k=1). 체제별 학습 형상만 본다 (§29.7)

도달률       무작위 4000점(로그균등 0.05~50)이 적합 결과를 못 이긴 비율
재적합 도달률 무작위 출발점에서 다시 적합한 것 3회가 못 이긴 비율
이동률       `FittedRule.moved` — 초기값에서 실제로 움직인 칸의 비율
```

⚠️ **도달률을 8차원과 16차원 사이에서 비교하지 않는다** — 무작위
4000점이 16차원에서 훨씬 성기다 (D-77 의 유보 그대로).

## 2. 팔 다섯 — ★ evals 예산을 같게 준다

지시문은 세 팔(지금 / CMA-ES / 대리+다듬기)이다. CMA 를 **둘로 나눈다**:
재시작·다듬기 일정이 Nelder-Mead 에 맞춰져 있어, 한 팔만 두면 "CMA 가
졌다" 와 "CMA 에게 맞지 않는 일정을 줬다" 가 갈리지 않는다.

```
팔           항  최적화기      적합예산  재시작  다듬기  대리초기점   총 evals
A8            8  Nelder-Mead      300      4     600       —        900
NM16         16  Nelder-Mead      300      4     600       —        900   <- 지금 (D-77 B16-lo)
CMA16        16  CMA-ES           300      1     600       —        900
CMA16-full   16  CMA-ES           900      1       0       —        900
SURR16       16  Nelder-Mead      150      2     600      150       900   <- (나)
```

```
★ 총 evals 900 을 다섯 팔에 똑같이 준다. 예산을 늘려서 이기는 것은
  의미가 없다 (지시문 §6).
★ 실제 평가 수를 보고한다 — 같았다고 가정하지 않는다 (원칙 38).
  CMA 는 세대 단위로 끝나 몇 회 넘고(16차원 popsize 12), Nelder-Mead 도
  재시작 진입 검사 때문에 300 -> 305 가 된다.
CMA16 은 재시작 1회다 — 300 을 4로 쪼개면 세대가 6번뿐이라 CMA 가 아니다.
CMA 의 초기 스텝은 `CMA_stds` 로 심플렉스 스텝과 같게 준다 (교락 제거).
```

`A8` 은 피험자가 아니라 **장치 점검**이다 — D-77 에서 100% 였고 여기서도
100% 여야 한다. 안 나오면 이 실행 전체를 믿지 않는다 (원칙 1).

### ⚠️ SURR16 은 regret 경로에 순위 손실 조각이 섞인다

```
1단계  rank_loss_top1 (참 1등 대 나머지, 미분 가능) 로 L-BFGS-B 150회
2단계  ★ 그 점에서 **regret 으로** Nelder-Mead 150회 + 다듬기 600회
```

**초기점 생성에만 쓰고 채택은 regret@1 이다.** 1단계 값은 반환값에
남지 않고, `fit`·다듬기·보고 전부 참 목적함수로 다시 잰다
(`fit_weights(init_objective="rank_top1")`). 이 팔이 이겨서 §3 에 쓰이면
**§3 의 조건에 "초기점은 순위 손실 대리" 를 적는다.**

## 3. 판정선 — 지시문 그대로

```
16항 팔 중 어느 하나라도 도달률 90% 이상   ★ 통과. 그 팔로 §3 (예산 8 vs 16 포함)
전부 90% 미만                            ★ D-77 이 regret 경로의 성질이다
                                          §3-1 을 접고 3-2·3-3 만 예산 8 로
```

**동점이면 재적합 도달률로 고른다** (D-77 에서 더 결정적이었던 지표).
그것도 같으면 `NM16` 을 쓴다 — 옛 실행과 조건이 같은 쪽이다.

## 4. ★ 도달한 점이 같은가

지시문의 요구다. 도달률이 같아도 다른 국소해면 그것도 기록할 사실이다.

```
칸마다 팔 사이 |fit_i - fit_j| 와 가중치 벡터의 코사인 유사도
16항 팔 셋(NM16 / CMA16 / CMA16-full / SURR16) 의 쌍 전부
```

**같은 점 판정**: `|fit_i - fit_j| < 1e-9` 를 "같은 값", 코사인 0.999
이상을 "같은 방향" 으로 부른다. 이것은 판정선이 아니라 **기술**이다 —
여기서 무엇이 나와도 §3 을 돌릴지는 §3 이 정한다.

## 5. 의존성 추가 — 기록한다

```
cma 4.4.4   pyproject 의 `fit` 추가 그룹. 핵심 경로는 없어도 돈다
            (`method="cma"` 일 때만 import 하고, 없으면 FitError)
```

`method="cma"` 는 **기본이 아니다** (`nelder-mead` 그대로). 기본을
바꾸면 모든 부르는 자리가 바뀐다 (원칙 36).

## 6. 예상 — 미리 적는다

```
A8 도달률 100%              D-77 재현. 안 나오면 장치 문제
NM16 도달률 92% 근처         D-77 B16-lo 와 같은 조건이라 재현돼야 한다
CMA16-full 이 CMA16 보다 낫다  D-77 C16-one 이 B16-one 보다 나았던 이유와 같다
SURR16 이 이동률은 가장 높다   대리가 미분 가능해 첫 발이 확실히 움직인다

```

⚠️ **적합기를 바꾸면 지금까지의 점수가 그 적합기의 산물이 아니게 된다**
(D-77 의 유보). §3 은 새 적합기로 **기준선도 다시 뽑는다** — 기준선
1.0762 은 Nelder-Mead 300/600 의 값이고, 팔이 바뀌면 나란히 놓을 수
없다 (원칙 4).

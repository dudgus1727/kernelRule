## 지표 — 부호를 다시 적는다

```
(적합 손상) - (검증 손상)
★ 양수가 클수록 "학습에만 기여" = 과적합 서명
   설명 불가 항이 여기 몰려야 Critic 판정이 맞는 것이다
```

4-fold (SOL 오름차순 라운드로빈, 각 fold 에 느린 형상 3개).
구조 홀드아웃 20 은 안 건드렸다.

## ★ 목 기준선이 먼저 — 통과 조건은 해석 가능하다

```
목 A  마지막 항 하나        0.36
목 B  마지막 k개 (수 일치)   0.43     ★ 주 대조군
무작위 k개 (200회 중앙)      0.50
```

**목 B 가 0.65 를 안 넘었다** — 실험 계획서의 중단 조건에 안 걸린다.
이 통과 조건은 읽을 수 있다.

## 결과 — 0.36

| 실행 | 지목 | 지목 중앙 순위 | 나머지 | 양수 항 |
|---|---|---:|---:|---:|
| s0 | [3, 7] | 0.36 | 0.50 | 4/8 |
| s1 | [1, 7] | **0.93** | 0.36 | 3/8 |
| s2 | [] | — | 0.50 | 1/8 |
| s3 | [2, 5, 6, 7] | 0.36 | 0.71 | 7/8 |
| s4 | [3, 6, 7] | 0.43 | 0.71 | 5/8 |
| s5 | [6, 7] | 0.29 | 0.57 | 6/8 |

```
실제 Critic  0.36   (규칙별 0.36 0.93 0.36 0.43 0.29)
나머지 항    0.57
쌍대 검정 (n=5규칙)  p = 0.625
```

**실험 계획서 판정선으로는 `0.35 < 0.36 < 0.65` = 구분 불가다.** 다만
0.36 은 구간의 **아래쪽 끝**이고, 무작위(0.50)보다도 낮으며 목
B(0.43)보다도 낮다.

## ★ 방향이 가설과 반대다

```
가설   설명 불가 항 = 학습에 맞춘 항 -> (적합-검증)이 양수 쪽
관측   설명 불가 항이 오히려 **음수 쪽**에 있다 (0.36 < 0.50)
       나머지 항이 0.57 로 더 양수 쪽이다
```

즉 **Critic 이 지목한 항이 검증에 상대적으로 더 기여한다.** 5규칙
중 4규칙에서 지목 중앙이 나머지보다 낮다.

⚠️ **p = 0.625 다.** n=5 규칙이라 "반대다" 를 주장할 근거도 없다.
말할 수 있는 것은 **"가설 방향의 신호가 없다"** 까지다.

## 무엇이 남았나 — 두 통과 조건이 다 안 맞았다

```
통과 조건 1 (D-85)  "빼도 학습이 안 나빠진다"        0.50 (우연)
통과 조건 2 (이번)   "빼면 학습만 나빠진다"          0.36 (가설과 반대 방향)
도구 자체       순서를 섞어도 같은 식을 지목    0.67 (D-86, 안정적)
```

**도구는 안정적인데 두 가지 정량 서명 어느 쪽과도 안 맞는다.**

세 가지 읽기가 가능하고 이 자료로는 못 가른다.

```
1  "물리로 설명 가능한가" 는 **regret 으로 검증되지 않는 축**이다
   이 표 하나로는 원리상 못 잰다 — 검증은 전이(다른 GPU)로만 가능하다
2  Critic 이 틀렸다 — 같은 모델이라 "설명" 이 그 모델의 일관성일 뿐이다
3  6규칙 x 8항으로는 어떤 서명도 못 잡는다 (표본)
```

```

             틀린 설명을 붙이는 것이 안 붙이는 것보다 나쁘다
```

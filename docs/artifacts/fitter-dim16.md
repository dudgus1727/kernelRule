# ★ 16차원에서 적합기가 버티지 못한다 — 예산 실험을 멈춘다 (2026-08-28)

> **상태**: 선행 검사 완료. **예산 8 vs 16 실험은 아직 시작하지 않았다**
> **재현**: `OMP_NUM_THREADS=1 python3 experiments/fitter_dim.py --jobs 16`
> (약 20분, LLM 호출 0회)
> **원자료**: `docs/artifacts/fitter-dim16.json` — 48칸 전부
> **표**: `datasets/rtx-a6000-sm_86-c63710df` (dev)
> **대상**: 사람 24개 팔 6실행(`f1pipe-F3-arch24-s0..s5`)의 최종 규칙,
> 체제 short/long 각각 = 12칸

## 왜 먼저 했나

예산을 8 -> 16 으로 늘리고 결과가 나빠지면 두 해석이 나뉜다.

```
"예산 16 이 나쁘다"              <- 재고 싶은 것
"적합기가 16차원에서 못 찾는다"   <- 먼저 배제해야 하는 것
```

원칙 1(인프라 -> 검사기 -> 피험자) 그대로다.

## 어떻게 16항으로 늘렸나

저장된 8항 규칙에 **안 쓰인 피처를 선형 항으로** 8개 붙였다. 새 항의
초기 가중치가 결과를 좌우할 수 있어 **두 값으로 따로 쟀다** — 이것은
내가 고른 값이므로 하나만 쓰면 그 선택이 결론이 된다.

```
f 이름 공간에 19개, p(형상 수준)에 5개.
모자라면 이미 쓴 피처의 제곱 -> 두 피처의 곱 순으로 채운다.
★ 이진 피처(has_/is_/can_)의 제곱은 자기 자신이라 제외했다 —
  붙이면 완전 중복 항이 되어 "차원이 늘었다" 가 거짓이 된다.
```

## 팔 넷

```
A8        원본 8항                                   예산 300 / 다듬기 600
B16-lo    16항, 새 항 초기 가중치 0.01                 예산 그대로
B16-one   16항, 새 항 초기 가중치 1.0                  예산 그대로
C16-one   16항, 새 항 초기 가중치 1.0    ★ 예산 600 / 다듬기 4000
```

`B16-lo` 의 출발점은 원본과 **거의 같은 함수**다(새 항의 가중치가 작다).
그리고 16차원 공간은 8차원 최적점을 **포함한다** — 새 항을 0 으로 두면
원본과 정확히 같은 함수다. 그러므로 완벽한 적합기라면 `B16-lo` 가
`A8` 보다 나쁘게 끝날 수 없다.

## ★ 결과

| 팔 | 도달률 | 재적합 도달률 | A8 보다 나쁜 칸 | 최대 손실 |
|---|---:|---:|---:|---:|
| **A8** | **12/12 100%** | 9/12 75% | — | — |
| B16-lo | 11/12 92% | 7/12 58% | 5/12 | +0.0208 |
| B16-one | **10/12 83%** | 5/12 42% | 10/12 | +0.0554 |
| C16-one | 11/12 92% | 5/12 42% | 6/12 | +0.0111 |

```
도달률       무작위 4000점(로그균등 0.05~50, 양수)이 적합 결과를 못 이긴 비율
재적합 도달률 같은 분포에서 뽑은 출발점으로 다시 적합한 것 3회 중
             어느 것도 못 이긴 비율
```

### 실험 계획서 기준으로는 — **미달이다**

기준은 "도달률 90% 이상이면 진행" 이었다.

```
A8       100%   통과 — 8차원 적합기는 D-56 때와 같다
B16-one   83%   ★ 미달
B16-lo    92%   통과
C16-one   92%   통과
```

**세 팔 중 하나가 미달이고, 그 팔이 통과냐 미달이냐를 가르는 것은
새 항의 초기 가중치 — 내가 고른 값이다.** 통과한 팔만 골라 "통과" 라고
쓰면 그것은 기준을 고른 것이다. **미달로 읽는다.**

### ⚠️ 도달률은 8차원과 16차원 사이에서 비교하면 안 된다

무작위 4000점은 16차원에서 훨씬 성기다 — 차원이 오르면 이 지표는
**저절로 올라간다**. 그런데도 `B16-one` 은 **내려갔다**. 지표가
쉬워지는 방향인데 성적이 나빠진 것이라, 이 미달은 약한 신호가 아니다.

## ★ 더 결정적인 것 — 재적합 도달률

무작위 '점' 대신 무작위 '적합' 과 견주면 차원에 공평하다. 같은 3-대-1
비교를 모든 팔에 똑같이 적용했으므로 **팔 사이 비교가 성립한다.**

| 팔 | 진 칸 | 격차 중앙값 | 격차 최대 |
|---|---:|---:|---:|
| A8 | 3/12 | 0.0070 | 0.0110 |
| B16-lo | 5/12 | 0.0177 | **0.0462** |
| B16-one | 7/12 | 0.0183 | 0.0361 |
| C16-one | 7/12 | 0.0275 | 0.0413 |

**16차원에서 적합 결과가 출발점에 따라 0.04 씩 달라진다.**

```
시드 폭 σ (단일 조건)        0.0124      <- 0.0462 는 3.7σ
GBDT 와의 격차               0.0572      <- 같은 자릿수다
```

**재려는 효과보다 측정 잡음이 크다.** 지금 8 vs 16 을 돌리면 예산이
아니라 **적합기의 출발점 민감도**를 재게 된다.

## 예산을 늘리면 절반쯤 낫는다 — 그러나 안 풀린다

```
C16-one 이 B16-one 보다 나은 칸   11/12   최대 -0.0444
```

**같은 16항인데 예산만 늘려 11/12 가 좋아졌다.** 즉 지금 예산(300/600)은
16차원에서 **명백히 모자란다** — 이 상태로 실험했으면 "예산 16 이 나쁘다"
가 아니라 "적합 예산이 모자랐다" 를 재는 것이었다.

그런데 예산 4배로도 재적합 도달률은 42% 그대로다(7/12, 중앙 0.0275).
**모자란 것은 예산만이 아니다.**

## 원인 — 재시작이 전부 국소다

```python
start = best_w if r == 0 else best_w + rng.normal(
    0.0, 0.35 * np.maximum(np.abs(best_w), 1.0))
```

`n_restarts=4` 지만 **넷 다 `best_w` 주변**이다. 이 검사에서 이긴
출발점들은 전부 **전역 무작위**(로그균등 0.05~50)였다. 8차원에서는
국소 재시작으로 충분했고(A8 3/12, 최대 0.011), 16차원에서는 아니다.

### 부수 발견 — 상한 경고가 두 겹으로 무의미했다 (D-76)

48칸 전부 적합 평가가 305/300, 605/600 이다. **재시작 일정이 예산을
설계상 전부 쓴다.** 거기에 다듬기 평가까지 더해서 상한과 견주고 있었다.
둘 다 고쳤다 — 자세한 것은 D-76.

## ★ 판정

**예산 8 vs 16 실험을 시작하지 않는다.** 적합기를 먼저 고친다.

```
(가) 전역 다중 출발  재시작 넷 중 둘을 전역 무작위로
     -> 이 검사에서 이긴 것이 바로 그 출발점들이다
     -> 비용 그대로 (재시작 수를 안 늘린다)
(나) 예산을 차원 비례로  max_evals ∝ n, 다듬기 ∝ n^2
     -> 11/12 가 좋아진 것이 근거. 다만 (가) 없이는 부족하다
     -> ★ 진화 한 라운드의 비용이 오른다 (후보 12개 x 라운드 12)
(다) 다듬기 쌍좌표가 16차원에서 예산을 다 먹는다
     n=8 은 112회/델타, n=16 은 480회/델타.
     델타 6개면 2,880회라 예산 600 안에서 한 바퀴도 못 돈다
```

**셋 다 아직 안 했다.** 고친 뒤 이 검사를 다시 돌려 `B16-*` 두 팔이
모두 90% 를 넘고 재적합 도달률이 A8 수준(75%)에 닿는지 본다.

⚠️ **적합기를 고치면 지금까지의 모든 점수가 그 적합기의 산물이 아니게
된다.** D-56 재실행 때와 같은 문제다 — 고친 뒤에는 비교하려는 값들을
**같은 적합기로 다시 뽑아야** 한다. 그 비용을 먼저 계산하고 결정한다.

## 이 검사가 D-56 을 어떻게 바꾸나

D-56 은 8차원 도달률 100% 로 "적합기가 제 일을 한다" 를 세웠고, 이번에
`A8` 이 다시 100% 를 냈다 — **그 값은 재현된다.**

다만 **재적합 도달률 75%** 는 그때 재지 않은 것이다. 무작위 4000'점'
보다 무작위 '적합' 이 훨씬 센 상대이고, 8차원에서도 3/12 는 진다
(최대 0.0110). **D-56 의 100% 를 "적합기가 최적을 찾는다" 로 읽으면
안 된다** 는 그때의 유보가 옳았고, 이번에 그 크기가 나왔다.

**LLM 호출 0회 시점에 쓴다.** 근거: [D-113](../decisions.md),

## 1. 사다리 — 각 단계가 **하나씩만** 다르다

```
옛 (c)    숫자 A6000 · 경고 A6000    1.0485   runs/f1pipe-F3-5090sigma-s{0,1,2}
중간 (c)  숫자 5090  · 경고 A6000    ?        runs/f1pipe-F3-5090sigma-hw-s{0,1,2}
새 (c)    숫자 5090  · 경고 5090     ?        runs/f1pipe-F3-5090sigma-hw2-s{0,1,2}
```

```
옛 -> 중간   ★ 숫자(SM / L2 / ridge / 눈금 값)의 효과
중간 -> 새   ★ 측정 한계 절의 **결론 문장**의 효과
```

**"hw 가 쓰이나" 가 아니라 "hw 의 어느 부분이 쓰이나" 가 된다.**

⚠️ 중간 (c) 를 중단하지 않는다 — 중단하면 그 분리를 잃는다.

## 2. 조건 — 중간 (c) 와 **한 절만** 다르다

프롬프트를 실제로 diff 해서 확인했다. 다른 줄은 **25줄, 전부
`## 측정의 한계` 절 안**이다. 나머지는 바이트까지 같다.

```diff
-짧은 커널일수록 그 눈금이 상대적으로 크다:
-     14 us 커널   한 눈금이  0.114%
+노이즈 바닥은 두 항 중 **큰 쪽**이다:
+  눈금   tick/t          반복 측정해도 안 줄어든다 (분해 한계)
+  통계   sigma_abs/t + sigma_rel   반복하면 평균으로 줄어든다
+    28.7 us 커널   눈금  0.056%   통계  0.104%   ← 이 표의 최솟값
...
-**눈금 안의 차이는 존재하지 않는 것과 같습니다.** 그 아래를 겨냥해
-규칙을 정교하게 만드는 것은 노이즈를 배우는 일입니다.
+★ **이 표에서는 눈금이 한계가 아닙니다.** ... 짧은 형상이라고 해서
+특별히 못 맞추는 것이 아닙니다.
```

⚠️ **갱신 (시작 전).** D-117 로 판정점이 바뀌었다 — 눈금이 한계인지를
**표에 없는 14us** 가 아니라 **그 표의 실제 최소 `best_ms`** 에서
판정한다 (5090 은 28.67us, A6000 은 11.26us). 결론은 안 바뀌었고
(5090 은 여전히 `tick_binds=False`) **다른 줄은 그대로 25줄, 전부
`## 측정의 한계` 절 안**이다. 사다리의 단은 "그 절 전체" 이므로 유지된다.
전체 diff: `docs/artifacts/ladder-diff.txt`.

`tick_binds=False` 는 코드가 판정한다 (D-116) — 손으로 켜는 스위치가
아니다. 그래서 **명령이 중간 (c) 와 완전히 같다.**

```
python3 experiments/f1_pipeline.py F3 \
  --seed-source rule_writer --n-rule-writer 10 \
  --bundle datasets/rtx-5090-sm_120-5bb6f403 --env-hash 5bb6f403 \
  --n-seeds 3 --rounds 12 --workers 6 --tag 5090sigma-hw2
```

★ 시작 전 `_system-rule_writer.md` 에 **"이 표에서는 눈금이 한계가
아닙니다"** 가 있는지 확인한다. 없으면 D-116 이 안 걸린 것이다.

## 3. 판정선 — §29.5 가 이미 쓴 σ 상한

`sigma-5090.json` 의 5090 시드 폭 σ = 0.0130, 95% 상한 0.0319.
**delta = 0.0516** (원칙 7). 여기서 새로 정하지 않는다.

```
중간 -> 새 가 0.0516 이상 좋다
  ★ 경고 절이 쓰인다. hw 산문이 구조 선택에 닿는다
구분 불가
  ★ 경고 절은 안 쓰인다. 그러면 옛 -> 중간 이 남은 것을 가른다
      옛 -> 중간 이 좋아졌다   -> 숫자가 쓰인다
      옛 -> 중간 도 구분 불가  -> hw 산문 전체가 안 쓰인다.
                               table_facts 가 지배한다
```

⚠️ **세 팔을 나란히 놓을 수 있다** — 같은 표, 같은 분할, 같은 절차,
같은 모델. 원칙 4 의 다섯 조건이 다 같다.

## 5. ★ 예상

**중간 -> 새는 구분 불가일 것이다.** 경고 절은 12라운드 진화에서
RuleEditor 가 **아예 안 받는다** (hw 는 RuleWriter 뿐 — §16.2). 즉
씨앗 하나에만 닿고, 그 뒤 144개 제안은 `table_facts` 를 본다.

**다만 §4-2(씨앗의 형상 길이 분기)는 볼 만하다** — 거기서는 경고가
직접 닿는다. 그리고 §4-1(tau)이 오르면 그것은 예상 밖이고 **D-100 을
다시 봐야 하는 신호**다.

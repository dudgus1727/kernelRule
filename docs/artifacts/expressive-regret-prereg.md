# 사전 등록 — regret 경로에서 **표현력 셋** (§3)

**계산·호출 전에 쓴다.** §2 관문의 결과를 §7 에 적고 시작한다.

## 0. 왜 다시 하나

표현력 셋이 **전부 순위 손실 경로에서만** 돌았다.

```
                 regret 경로        순위 손실 경로
예산 8 vs 16     ✗ D-77 로 막힘      ✓ D-108  구분 불가
곱 항            ✗                   ✓ D-110  구분 불가
지수 자리        ✗                   ✓ D-112  겨뤄서 졌다
```

순위 손실 규칙은 **특정 집합의 조건부 순서만** 배운다 (D-118·D-121) —
표현력을 줘도 쓸 데가 없었을 수 있다. regret 규칙은 좋은 영역을
가리키고, **더 정밀하게 가리키려면 표현력이 필요할 수 있다.**
GBDT 격차 0.057 이 그 여지다.

## 3. 판정선 — 미리 박는다

```
기준선   regret 진화 예산 8, 힌트 없음   ★ 1.0762 (홀드아웃 중앙)
         시드 범위 1.0566~1.0919 (6실행)
판정선   delta = 0.0516 — 두 팔 n=6, 양측 0.05, 검정력 0.8, 비대응,
         σ 95% 상한 0.0319 로 계산한 값 (`transfer-29-5.md` §2).
         ★ 여기서 새로 정하지 않는다 (원칙 7)
⚠️ 그 delta 는 **n=6** 짜리다. §3 은 팔마다 3시드이므로 검정력이 더
   낮다 — 그래서 **시드 범위**가 주 판정이고 delta 는 크기 기준이다

각 팔   regret@1 이 0.0516 이상 좋아지면   ★ 표현력이 벽이었다
        그 미만                          구분 불가 = 표현력이 아니다
        ★ 3시드는 유의성이 안 나온다 — **시드 범위로** 판정한다
```

⚠️ **1.0762 은 `max_evals=200` 짜리 값이다.** §7 의 적합기가 그것과
다르면 3-1 은 **자기 안의 예산 8 팔**을 기준선으로 쓰고, 1.0762 은
참고로만 적는다 (원칙 4 — 절차가 다르면 나란히 놓지 않는다).

```

  ★ 벽은 피처 공간의 성질이다. 선형/비선형/예산이 아니다
  ★ 그러면 GBDT 모순을 풀어야 한다 — **같은 피처**로 1.019 를 낸다

     GBDT 는 config 수준 피처(`f.*`)의 문턱으로도 갈린다
     ★ 이것을 후보로 등록한다 (다음 실험의 씨앗)

하나라도 좋아진다
  ★ regret 경로에서는 표현력이 걸렸다
  -> 순위 손실에서 안 됐던 것은 그 목적함수의 성질이었다
  -> "벽" 절을 다시 쓴다: 순위 손실의 벽과 regret 의 여지를 분리
```

## 7. §2 관문의 결과 — ★ 통과. 적합기는 CMA16

전문 [fitter-regret.md](fitter-regret.md), D-123.

```
A8 (장치점검)  100% / 75%   ← D-77 을 정확히 재현
NM16            92% / 58%   ← D-77 B16-lo 와 소수 셋째 자리까지 같다
★ CMA16        100% / 67%   ← 고른 팔
CMA16-full     100% / 67%
SURR16          58% / 33%   ← (나) 대리 초기점은 **해롭다**
```

**§3-1(예산 8 vs 16)을 돈다.** 적합기 조건:

```
fit_method   cma       (CMA-ES, `cma` 4.4.4)
fit_restarts 1         (예산을 넷으로 쪼개면 CMA 가 아니다)
max_evals    300       ★ 옛 실행은 200 이다
다듬기        600       (fit_weights 기본, 좌표 하강)
-> config.json 의 `loop.fit_method` / `loop.fit_restarts` 에 남고
   `runset.assert_same_condition` 이 본다 (원칙 39, KEYS 에 추가)
```

### ⚠️ 그래서 기준선을 **다시 뽑는다**

`1.0762` 은 **Nelder-Mead 200/600** 의 값이다. 적합기가 다르므로 나란히
놓지 않는다 (원칙 4). §3-1 의 **예산 8 팔이 네 판 전부의 기준선**이고,
그래서 네 판이 모두 같은 적합기·같은 씨앗으로 돈다.

```
3-1  rb08  예산 8            ★ 내부 기준선 (3-2·3-3 도 이것과 견준다)
3-1  rb16  예산 16
3-2  rprod 예산 8 + 곱 힌트
3-3  rpow  예산 8 + 지수 힌트
```

`1.0762` 은 **참고로만** 적는다 — 옛 적합기에서 같은 조건이 얼마였는지.

### ⚠️ 유보 — D-77 의 둘째 선은 못 넘었다

```
재적합 도달률   CMA16 67%  <  A8 75%       ← D-77 이 적어 둔 둘째 통과선
재적합 격차 최대 0.0317                     ← 판정선 0.0516 의 61%, σ 의 2.6배
```

**16항 팔의 적합 결과는 여전히 출발점에 따라 최대 0.032 움직인다.**
3-1 에서 예산 16 이 나빠 보이면 그 크기를 함께 봐야 하고, 0.0516 을
넘지 못하는 차이는 **적합기 산포와 구분되지 않는다.**

### 그리고 §2 가 하나 더 말해 준다

도달한 점이 팔마다 다르다 (같은 값인 칸 0~2/12, cos 최소 0.160).
**적합된 가중치 벡터를 해석 대상으로 쓰지 않는다** — 어느 항이
살아남았는지는 적합기가 고른 국소해의 성질이다. §3 의 항 수 분포는
**LLM 이 쓴 항의 수**로 세고, 적합 후 죽은 항으로 세지 않는다.

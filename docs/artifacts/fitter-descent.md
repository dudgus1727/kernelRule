# 적합기 (가) 좌표 하강 강화 — ★ 판정 기준 (실험 **전**에 박는다)

> **상태**: 기준 등록 (2026-08-26). 구현·측정 전
> **재현**: `python3 experiments/fitter_movement.py`
> **모델**: LLM 0회
> **표**: `datasets/rtx-a6000-sm_86-c63710df` (dev, 수치 대외 보고 금지)

**결과를 보고 기준을 정하면 오염이다** (D-50). 여기 먼저 적는다.

---

## 왜 (가) 가 먼저인가

```
(가)  같은 목적함수(regret@1)에서 탐색만 넓힌다
      실패해도 잃는 것이 없다 — 도달률만 다시 재면 된다

(나)  regret@3 대리 손실로 적합
      ★ k=3 에서 좋은 것이 k=1 에서도 좋다는 보장이 없다
      "최적화는 잘 되는데 목표에서는 나빠지는" 대리 손실의 전형적 실패
```

그리고 **도달률 측정 자체가 (가)의 검증 도구다.** 무작위 4000점과
regret@1 로 비교하는 것인데, (나)로 가면 다른 목적함수로 적합한 결과를
그 기준으로 재게 된다.

## 지금 상태

```
도달률 (4000점)   75.0%  (18/24)     ★ 통과선 90% 미달
도달 실패 6건 격차 0.0308 0.0171 0.0169 0.0148 0.0130 0.0085
이동률 (진단용)    45.8% 끔 / 62.5% 켬
```

지금 다듬기는 **단일 좌표를 세 단계 delta(x0.5, x0.25, x0.1)로 ± 흔드는
것**이다. 격차가 0.0085~0.0308 이면 **한 좌표를 크게 흔들면 넘어갈
가능성**이 있다.

## 시도할 세 방향

```
1. delta 를 로그 스케일로 넓힌다   x10 / x2 / x0.5 / x0.1  ★ 가장 싸다
2. 쌍좌표                        w[i], w[j] 를 동시에
                                 단일 좌표로 못 넘는 계단이 있을 수 있다
3. 반복                          한 바퀴 돌아 개선되면 다시 (지금도 한다)
```

## ★ 판정 기준

```
목표       도달률(무작위 4000점, regret@1) 90% 이상
비용 상한   추가 evals 가 적합 305 의 2배(610)를 넘지 않을 것
악화       기존 적합보다 나빠지는 실행이 2건 이상이면 개별 조사
표본       ★ 4000 으로 고정 — 400 에서 90% 였다가 4000 에서 75% 로
           떨어진 것이 이번 교훈이다 (D-56)
실패 시     (나) regret@3 대리 손실로 넘어간다
```

**도달률을 "적합기가 최적을 찾는다" 로 읽지 않는다.** 8차원에 4000점은
성기다. 정확한 서술은 **"무작위 4000점 탐색보다 나쁜 곳에서 끝나는
경우가 x% 다"** 이다.

## 결과 (2026-08-26)

재현: `python3 experiments/fitter_movement.py` — LLM 0회.

세 방향을 전부 넣었다.

```
1  delta 로그 스케일   (0.5, 0.25, 0.1) -> (10, 3, 1, 0.5, 0.25, 0.1)
                      ★ 전에는 전부 1보다 작아서 한 좌표를 크게 흔드는
                        시도가 아예 없었다
2  쌍좌표             w[i], w[j] 동시에 x 부호 4조합
                      단일 좌표가 그 delta 에서 막혔을 때만 (비싸다)
3  반복               개선되면 그 delta 로 다시 한 바퀴 (원래도 했다)
```

| | 전 | **후** |
|---|---:|---:|
| 도달률 (4000점) | 75.0% (18/24) | **83.3% (20/24)** |
| 도달 실패 | 6건 | **4건** |
| 최대 격차 | 0.0308 | **0.0171** |
| 이동률 (진단용) | 62.5% | 66.7% |
| 다듬기 evals | 48~96 | 600 (상한) |

### 사전 기준에 대조한 판정

```
목표 도달률 90%      ★ 미달 (83.3%)          -> (나)로 넘어간다
비용 상한 610        통과 (600)
악화 2건 이상        없음 — 새로 실패한 건이 하나도 없다
```

**개선은 실재한다** — 실패 6→4, 최대 격차가 절반 아래로. 그러나
**통과선에 못 미친다.**

### 예산이 자른 것이 아니다 (정정)

실패 4건의 다듬기가 전부 예산 600 에서 잘렸고, 상한을 풀면 768~800 에서
끝난다. 그래서 "비용 상한이 (가)를 잘랐다" 고 적었다. **틀렸다.**

상한을 3000 으로 놓고 다시 쟀더니 **결과가 완전히 같다** — 도달률 83.3%,
같은 4건, 격차까지 `0.0171 / 0.0161 / 0.0130 / 0.0085` 로 동일하다.
추가 200 evals 에서 더 나은 점이 하나도 없었다.

```
예산은 탐색을 잘랐지만 결과는 안 잘랐다.
"잘렸다" 와 "잘려서 손해를 봤다" 는 다른 말이다.
```

**좌표 + 쌍좌표 하강은 소진됐다.** 남은 4건은 축 방향으로도, 축 두 개를
동시에 흔들어도 못 넘는 자리에 있다.

### 남은 4건

```
lunaNAMES-s0 short   0.0085
lunaNAMES-s1 long    0.0130
lunaNAMES-s3 short   0.0161
lunaNAMES-s3 long    0.0171
```

넷 다 `lunaNAMES`(피처 설명 없음) 쪽이고 셋이 **정지**(w == w0) 상태다.
설명 없는 조건에서 `w0` 가 나쁜 평지에 앉는 경향과 맞물린다 (D-54, D-56).

### ★ 실패가 한 조건에 몰려 있다 — (나) 보류 (D-60)

```
A 설명 있음 (luna)        12/12 = 100.0%     ★ 전부 도달
B 이름만 (lunaNAMES)       8/12 =  66.7%
```

**재실행을 단일 조건(설명 있음)으로 설계하면 실패가 0/12 다.** A/B 는
이미 결론이 났고 (시드 폭 안, 구분 불가), 피처 설명은 기본으로 반영됐다.
재실행의 목적은 "오염 없는 상태의 값" 이지 A/B 재확인이 아니다.

그리고 실패 4건의 격차(0.0085~0.0171)가 **시드 폭 σ=0.0274 보다 작다.**
넷을 다 고쳐도 최종 결과는 시드 폭 안에서 움직인다. 대리 손실이 목표와
어긋날 위험을 감안하면 (나)는 수지가 안 맞는다.

```
기준 판정   미달 (83.3% < 90%)          ★ 그대로 기록한다
판단        그 조건을 안 쓰면 회피된다   "통과" 가 아니라 "우회 가능"
```

**(나) 는 보류이지 폐기가 아니다.** 단일 조건 검증 실행에서 실패가 나오면
실험 계획서부터 다시 시작한다. 그때의 판정은 **반드시 regret@1 도달률로**
한다 — 대리 손실로 적합하고 목표 손실로 잰다.

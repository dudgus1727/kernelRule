# luna 기준선 3시드 — 거부율만 확인되고 나머지는 못 잰다

**측정일** 2026-08-25 · **재현** `python3 experiments/seed_selection.py 3 20260825 luna`
**설정** `gpt-5.6-luna` / Responses / `reasoning_effort=medium` /
`temperature=None` / `seed=None`
**조건** 씨앗 없음 + 피처 설명 + 기본 24피처 · 3시드 × 12라운드

> ⚠️ 이 실행의 `runs/luna-s*/` 에는 **`config.json` 이 없다.** `dump()` 가
> 설정을 쓰기 시작한 것이 이 실행 **도중**이다 (D-51). 위 설정은 실행을
> 띄운 명령에서 온 것이고, `llm_calls` 에는 모델만 남아 있다.

**중앙값이 벤더보다 나쁘다.** s0 의 1.0573 은 앞서지만 **3개 중 최소**라

## ★ 3시드로는 폭을 못 잰다 — 이번에 실증됐다

| 묶음 | 구조 HO | 폭 |
|---|---|---:|
| luna | 1.0573 / 1.1018 / 1.1137 | 0.0564 |
| gpt-5.4 desc | 1.0714 / 1.0757 / 1.1093 | **0.0379** |
| gpt-5.4 A-base | 1.0518 / 1.0877 / 1.1496 | **0.0978** |

**같은 모델·같은 조건의 두 묶음이 0.0379 와 0.0978 로 2.6배 차이난다.**
luna 의 0.0564 는 그 사이이고, **"luna 가 폭을 줄였다" 고 말할 수 없다.**

D-40 이 "3개로는 부족하다" 고 했는데, **그 부족함이 이렇게 보인다** —
3시드 폭 자체가 3배 가까이 흔들린다.

## 확인된 것 — 거부율과 비용

| | 거부 | 라운드당 시간 | 라운드당 입력 | 라운드당 출력 |
|---|---|---:|---:|---:|
| **luna** (responses/medium) | **3/432 (0.7%)** | 103.3s | 105,161 | **19,430** |
| gpt-5.4 desc (chat) | 11/432 (2.5%) | 45.2s | 118,457 | 5,790 |
| gpt-5.4 A-base (chat) | 8/432 (1.9%) | 48.0s | 119,932 | 5,964 |

**거부율 0.7% 가 가장 낮다** — 세 시드 전부. 스키마·정적 검사를 거의
다 통과한다. 이것은 시드 폭과 무관한 **결정론적 집계**라 3시드로도 말할
수 있다.

**대신 2.3배 느리고 출력 토큰이 3.3배다.** 입력은 오히려 조금 적다.
추론 모델의 비용 구조다 (`cost.md`).

## 말할 수 있는 것과 없는 것

```
✅  거부율 0.7%로 가장 낮다              집계라 폭과 무관
✅  2.3배 느리고 출력 3.3배              집계라 폭과 무관
❌  "luna 가 낫다"                      중앙 1.1018 > 벤더 1.0737
❌  "luna 가 폭을 줄였다"                3시드 폭이 묶음마다 2.6배 흔들린다
❌  "s0 의 1.0573 이 실력"               3개 중 최소 (D-50)
```

**모델 간 값 비교는 하지 않았다** (D-31 의 다섯 번째 축). 폭끼리만 봤고
그마저도 3시드라 결론이 안 난다.

## 채점기에서 고친 것 둘

이 결과를 내면서 채점기가 두 가지를 잘못하고 있었다.

```
1. 자동 판정 "실력 — 절차로 확정"
   임계값(<1.065)이 **다른 모델(gpt-5.4)** 데이터에서 온 것이었고,
   값 자체가 3개 중 최소였다 -> 판정을 없애고 경고로 바꿨다

2. 묶음 합산이 gpt-5.4 실행과 luna 를 섞었다 (n=9)
   -> config.json(없으면 llm_calls)에서 조건을 읽어 같은 것끼리만 합친다

   ★ 그 폴백이 엔드포인트를 `/chat` 으로 **단정**해서 responses 실행이
     chat 으로 라벨링됐다. **D-31 을 어기면서 어긴 줄도 모르게 된다.**
     `엔드포인트미상` 으로 고쳤다 — 모르면 모른다고 적는다 (§26.4).
```

## ★ 판정선 — σ 를 재고 정했다

실험 계획서: *"5090 에서 (c) 3시드를 돌려 σ 를 재고, 그 값으로 판정선을
정한다. 그 전에는 (a)(b) 의 차이에 유의성을 붙이지 않는다."*

3시드로는 신뢰구간이 너무 넓어 (`[0.0082, 0.0994]`) 3시드를 더 돌렸다.

```
같은 스크립트 · 같은 절차 · 같은 n=6
표       σ        95% 신뢰구간         중앙      폭
A6000  0.0124  [0.0078, 0.0305]    1.0762   0.0354
5090   0.0130  [0.0081, 0.0319]    1.0485   0.0348
```

**5090 의 시드 폭은 A6000 과 사실상 같다.** n=3 때 0.0158 로 넓어
보이던 것은 표본 수의 그림자였다. 검정력 계산이 그대로 넘어간다.

```
판정선 (두 팔 n=6, 양측 0.05, 검정력 0.8, 비대응)
  σ 점추정 0.0130  ->  delta = 0.0210
  ★ σ 상한 0.0319  ->  delta = 0.0516      ← 이것을 쓴다 (원칙 7)
```

⚠️ (c) 6실행은 **같은 2단계 씨앗**을 쓴다 (`--seed-from`). 안 그러면
RuleWriter 가 다른 씨앗 규칙을 만들어 조건이 달라진다 (D-84). 앞 3개와
뒤 3개가 섞여 있다 — 뒤 3개가 따로 놀지 않는다.

## ★ 판정 — 실험 계획서의 두 번째 줄이다

| 미리 적은 것 | 결과 |
|---|---|
| (a) 완전 이식이 기준선을 이긴다 | ❌ **4/6, 부호검정 p = 0.69** |
| **(a) 는 지고 (b) 재적합이 이긴다 → §29 의 가설** | ✅ **이쪽** |
| (b) 도 지고 (c) 만 이긴다 → 구조도 하드웨어 의존 | — |
| 셋 다 진다 | — |

### (a) → (b) — 판정된다

```
6/6 구조 전부 (b) 가 좋다     ★ 대응 Wilcoxon 단측 p = 0.0156
중앙 차 +0.0538 (뒤집힘 제외 +0.0368)
비대응 판정선(σ 상한) 0.0516 — ★ 상한 기준으로도 넘는다
```

**가중치는 하드웨어 상수다.** A6000 가중치를 들고 가면 중앙이 0.054
나빠지고, **폭이 3.3배 넓어진다** (0.0363 → 0.1216). (a) 를 실무에서
쓰면 안 되는 이유가 둘이다 — 중앙이 나쁜 것과, 어느 시드에서 나왔느냐에
운이 걸리는 것.

### ★ (b) ≈ (c) — 구별되지 않는다. 그리고 (b) 는 LLM 0회다

```
(b) 1.0539  vs  (c) 1.0485    차이 +0.0054   MWU 양측 p = 0.485
뒤집힘 제외    +0.0125   p = 0.310
★ 차이가 판정선 0.0516 의 1/10 ~ 1/4 이다
```

⚠️ **"구별 안 된다" 는 "같다" 가 아니다.** 다만 관측 차이가 판정선보다
훨씬 작다는 것은 말할 수 있고, **그것이 §29 의 주장이 요구하는 전부**다
— 구조를 옮기고 가중치만 다시 맞추면 **처음부터 다시 배운 것에 닿는다.**

```
(c) 재생성   RuleWriter + 12라운드 진화   ★ 실행당 약 500 LLM 호출
(b) 재적합   구조 고정 + fit_weights 1회  ★ LLM 0회, 수 초
```

### 기준선 대비

```
(a)  4/6 이 이긴다   부호검정 p = 0.69     중앙 차 -0.0325
(b)  6/6 이 이긴다   부호검정 p = 0.0312   중앙 차 -0.0862
(c)  6/6 이 이긴다   부호검정 p = 0.0312   중앙 차 -0.0916
```

6/6 은 n=6 에서 나올 수 있는 **가장 강한 결과**다 (p = 2/2⁶ = 0.031).

⚠️ **정정** n=3 중간 보고에서 "(a) 가 중앙에서 기준선을 이긴다" 고
썼다. 6실행에서 부호검정으로 보면 **4/6, p = 0.69 로 이겼다고 말할 수
없다.** 중앙값만 보고 말한 것이 잘못이었다.

⚠️ 기준선은 `nvMatmulHeuristics` 가 이 환경에 없어서(import 실패)
실험 계획서의 대체안인 **5090 재적합 `physics_seeded`** 다. 결과를 보고
고른 것이 아니다. 그리고 구조가 고정이라 **점 하나**이고 시드 폭이
없다 — (a)(b)(c) 의 분포와 나란히 놓을 때 그 비대칭을 감안해야 한다.

## 규칙을 하나 고르지 않았다 (원칙 5)

"A6000 에서 진화한 규칙" 을 하나 고르면 그 선택이 낙관 편향이 된다.
**A6000 F3 캠페인 6시드 전부**의 학습 최고 규칙을 옮겨 분포를 냈다.
(a) 와 (b) 는 **같은 6구조**를 쓰므로 대응 표본이다.

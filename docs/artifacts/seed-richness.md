# 씨앗이 쓰는 피처 수가 하류 전체와 붙어 있다 (2026-08-28)

> **상태**: ★ **한 방향으로는 인과다** (D-84). 씨앗을 기준선 것으로
> 바꾸자 평균 f 피처 수와 요구율이 **함께** 기준선 범위로 돌아왔다
> **재현** `python3 -c` 로 `runs/*/hypotheses.jsonl` + `archive.jsonl` 집계.
> **LLM 호출 0회**
> **표** dev-cu124. 성능 수치는 인용하지 않는다

## 무엇을 봤나

D-82 에서 요구율 비교가 씨앗 규칙에 교락돼 있다는 것이 드러났다.
그 교락을 재려고 44실행 전부를 봤더니 **상관 자체가 관찰거리**였다.

```
x = 그 실행 아카이브 규칙들이 쓰는 **f 피처 수의 평균**
y = 그 실행의 새 축 요구율 (1차 Analyst, needs_new_feature 채워진 비율)

스피어만 rho = +0.566   p = 0.0001   n = 44실행
```

**규칙이 피처를 많이 쓸수록 새 축을 더 요구한다.**

## 캠페인이 그 축의 양 끝에 몰려 있다

| 캠페인 | 실행 | 평균 f 피처 수 | 요구율 |
|---|---:|---|---|
| `d75run2` / `d75run3` (같은 씨앗) | 9 | 7.5 ~ 9.1 | 0 ~ 5.9% |
| `f1pipe-F3-arch24` | 6 | 12.0 ~ 13.6 | 6.4 ~ 28.0% |
| `luna` (사람24) | 6 | 11.2 ~ 13.6 | 4.2 ~ 42.6% |
| `f1pipe-F1-K` | 6 | 9.3 ~ 10.8 | 7.7 ~ 34.6% |

**범위가 겹치지 않는다** — 새 캠페인 9실행 전부가 9.1 이하, 사람24
캠페인 12실행 중 11개가 11.2 이상.

## 씨앗이 그 차이를 만든다

```
arch24 캠페인 씨앗    8항, f 피처 12/19 사용 (미사용  7)
d75run2/3 캠페인 씨앗 7항, f 피처  6/19 사용 (미사용 13)
★ run2 와 run3 의 씨앗은 코드가 완전히 같다 (해시 동일)
```

**한 캠페인의 6실행은 2단계 씨앗 하나를 공유한다.** `stage3` 이 같은
씨앗으로 6번 시작하므로, 씨앗에서 오는 성질은 **캠페인당 한 번만
뽑힌다** (원칙 28).

## 왜 그럴듯한가

**많이 써 본 쪽이 무엇이 부족한지 안다.** 12개를 쓰는 규칙을 가진
Analyst 는 남은 7개로 설명이 안 되는 구간을 자주 만나고, 6개만 쓰는
규칙을 가진 Analyst 는 아직 안 쓴 13개를 먼저 권한다 — 진단 리포트가
**"★ 미사용" 열을 내주기 때문**에 그쪽이 더 싼 제안이다.

## ⚠️ 무엇을 아직 못 말하나

```
상관이지 인과가 아니다.
  씨앗이 빈약해서 요구가 준 것인가
  요구가 적은 실행이라 규칙이 빈약해진 것인가
  둘 다 세 번째 것(모델의 그날 상태 등)의 결과인가
```

**되먹임 고리라서 방향을 못 정한다** — 요구가 축을 만들고, 축이 규칙을
살찌우고, 살찐 규칙이 다시 요구를 부른다.

**4차 실험이 한쪽을 고정했다** (D-84): 기준선 캠페인의 씨앗을 그대로
쓰고 3단계만 다시 돌렸다.

```
평균 f 피처 수   기준선 12.0~13.6 / 4차 10.6~13.2 (겹침) / 3차 7.6~8.8 (분리)
요구율 중앙      기준선 20.5%     / 4차 17.0% (p=0.87) / 3차 0.0% (p=0.02)
```

**개입이 두 축을 함께 되돌렸다 — `씨앗 -> 요구` 방향이 산다.**
반대 방향(요구가 규칙을 살찌운다)도 여전히 있을 수 있다. 되먹임
고리의 **한 팔만** 확인한 것이다.

## 이것이 왜 중요한가

**2단계가 하류 전체를 좌우한다는 뜻이다.** 지금 2단계는 Architect
10회 중 학습 점수 최고 하나를 고른다 — 그 한 번의 뽑기가 12라운드 x
6시드를 규정한다.

```
지금   Architect 10회 -> 학습 최소 하나  ->  6시드가 그것을 공유
```

**"씨앗이 좋아야 한다" 는 이 저장소가 이미 아는 것이지만, 얼마나
좌우하는지는 재 본 적이 없다.** 이 상관이 그 크기의 첫 실측이다.

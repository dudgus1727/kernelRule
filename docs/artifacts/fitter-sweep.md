## 배경 정정 — "5%" 가 아니었다

D-54 를 쓸 때 "초기 심플렉스가 초기값의 5% 라 지배적 항에서 무력하다" 고
적었다. **코드를 보니 이미 60% 다.**

```python
step = 0.6 * (0.5 ** r) * np.maximum(np.abs(start), 1.0)
```

재시작마다 절반으로 줄어 60% → 30% → 15% → 7.5% 다. `w0` 최대가 21.6
이면 첫 재시작의 스텝은 약 13 이다 — **작지 않다.**

**따라서 "안 움직임" 의 정확한 뜻은 이렇다.**

```
305회 평가한 후보 중 초기값보다 **엄격히 나은** 것이 하나도 없었다
```

`v < best_v` 가 엄격 비교이고 regret 은 계단 함수라, **같은 값이 나오면
갱신하지 않는다.** 최적화기가 고장난 것이 아니라 **목적함수가 그 근방에서
평평하다.**

## 그래서 무엇을 쓸어보나

```
심플렉스 배율   0.6 (지금) / 1.5 / 4.0 / 상대가 아닌 절대 스텝
```

★ **상대 배율이 지배적 항을 덜 흔든다** — `step ∝ |w0|` 이므로 큰 항은
큰 스텝을 받지만, 그 항이 **이미 순위를 포화**시켰다면 더 흔들어도 순위가
안 바뀐다. 오히려 **작은 항**을 크게 흔들어야 순위가 뒤집힌다. 절대 스텝은
그것을 시험한다.

## ★ 판정 기준

```
움직인 비율    54% -> 90% 이상이면 성공
              70~90% 면 부분 성공. (b) 좌표 하강을 검토
              70% 미만이면 심플렉스 문제가 아니다

regret 변화    12규칙 x 2체제 = 24개 각각
              ★ 악화가 하나라도 있으면 그 규칙을 들여다본다
                (초기값이 이미 좋았는데 최적화기가 나쁜 데로 갔는가)
              전체 중앙 개선폭이 0.01 미만이면 고칠 값어치가 낮다

n_evals       비용. 2배를 넘으면 그만큼 실행이 느려진다
```

## 재실행 여부는 그 뒤에 정한다

```
구조 홀드아웃 중앙이 0.01 이상 달라진다  ->  기존 12실행을 다시 돌린다
거의 같다                              ->  적합기만 고치고 기존 결과 유지
```

⚠️ 어느 쪽이든 **지금 값들은 절반이 적합 없이 나온 것**이므로, 고친 뒤가
정본에 가깝다.

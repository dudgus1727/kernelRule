## 배경 정정 — "5%" 가 아니었다

D-54 를 쓸 때 "초기 심플렉스가 초기값의 5% 라 지배적 항에서 무력하다" 고
적었다. **코드를 보니 이미 60% 다.**

```python
step = 0.6 * (0.5 ** r) * np.maximum(np.abs(start), 1.0)
```

재시작마다 절반으로 줄어 60% → 30% → 15% → 7.5% 다. `w0` 최대가 21.6
이면 첫 재시작의 스텝은 약 13 이다 — **작지 않다.**

**따라서 "안 움직임" 의 정확한 뜻은 이렇다.**

```
305회 평가한 후보 중 초기값보다 **엄격히 나은** 것이 하나도 없었다
```

`v < best_v` 가 엄격 비교이고 regret 은 계단 함수라, **같은 값이 나오면
갱신하지 않는다.** 최적화기가 고장난 것이 아니라 **목적함수가 그 근방에서
평평하다.**

## 그래서 무엇을 쓸어보나

```
심플렉스 배율   0.6 (지금) / 1.5 / 4.0 / 상대가 아닌 절대 스텝
```

★ **상대 배율이 지배적 항을 덜 흔든다** — `step ∝ |w0|` 이므로 큰 항은
큰 스텝을 받지만, 그 항이 **이미 순위를 포화**시켰다면 더 흔들어도 순위가
안 바뀐다. 오히려 **작은 항**을 크게 흔들어야 순위가 뒤집힌다. 절대 스텝은
그것을 시험한다.

## ★ 판정 기준

```
움직인 비율    54% -> 90% 이상이면 성공
              70~90% 면 부분 성공. (b) 좌표 하강을 검토
              70% 미만이면 심플렉스 문제가 아니다

regret 변화    12규칙 x 2체제 = 24개 각각
              ★ 악화가 하나라도 있으면 그 규칙을 들여다본다
                (초기값이 이미 좋았는데 최적화기가 나쁜 데로 갔는가)
              전체 중앙 개선폭이 0.01 미만이면 고칠 값어치가 낮다

n_evals       비용. 2배를 넘으면 그만큼 실행이 느려진다
```

## 재실행 여부는 그 뒤에 정한다

```
구조 홀드아웃 중앙이 0.01 이상 달라진다  ->  기존 12실행을 다시 돌린다
거의 같다                              ->  적합기만 고치고 기존 결과 유지
```

⚠️ 어느 쪽이든 **지금 값들은 절반이 적합 없이 나온 것**이므로, 고친 뒤가
대표값에 가깝다.

## 결과 (2026-08-26 실행)

재현: `python3 experiments/fitter_sweep.py` — LLM 0회, 커밋된 12규칙 x 2체제.

| 설정 | 움직임 | 구조 홀드아웃 중앙 | 개선 | 악화 | evals 중앙 |
|---|---:|---:|---:|---:|---:|
| 상대 0.6 (지금) | 11/24 (46%) | 1.1063 | — | 0 | 305 |
| 상대 1.5 | 14/24 (58%) | 1.1048 | +0.0015 | 3 | 305 |
| 상대 4.0 | 12/24 (50%) | 1.0970 | +0.0094 | 1 | 305 |
| 절대 1.0 | 10/24 (42%) | 1.1074 | −0.0011 | 4 | 305 |
| 절대 5.0 | 13/24 (54%) | 1.1091 | −0.0027 | 5 | 305 |

### 사전 기준에 대조한 판정

- **움직인 비율: 최고 58% < 70% → "심플렉스 문제가 아니다".** 배율을 7배로 키워도,
  상대를 절대로 바꿔도 절반 언저리다. 기준대로 심플렉스 배율은 **바꾸지 않는다**.
- **개선폭 최대 +0.0094 < 0.01 → 값어치 낮음, 재실행 임계 미달.**
  12실행을 다시 돌릴 사유가 없다.
- **evals 중앙이 다섯 설정 모두 305 — 상한을 항상 친다.** 따라서 "안 움직임" 은
  "일찍 수렴" 이 아니라 **305번 시도해서 엄격히 나은 것이 하나도 없었다** 이다.
  **수렴하지 못한 채 예산을 다 쓴다는 것 자체가 목적함수 평지의 직접 증거다** —
  경고로는 못 쓰지만(24회 전부에서 뜬다) 증거로는 유효하다.

### 그러면 왜 안 움직이나 — 목적함수가 평평하다

`obj` 호출 305개를 시작값과 비교했다 (재현: 위 스크립트와 같은 계측).

- 안 움직인 13건 중 12건은 **본 것 중 최소 = 시작값**. 나머지 1건은 0.0005 차.
- 동점(정확히 같은 regret)이 **20~167건**. `lunaNAMES-s4 long` 은 305 중 156 이 동점.
- 나머지는 전부 더 나쁨.

계단 함수의 넓은 평지 위에 초기값이 놓여 있다. 스텝 크기로 풀 문제가 아니다.

### 정정 — "더 나은 점을 보고도 버린다 5/24" 는 틀렸다

처음에 `_Problem.regret` 을 감싸 모든 호출을 기록했더니 24회 중 5회에서 "탐색 중
본 최소 < 최종값" 이 나왔고, 최대 0.0277 이었다. **계측 결함이었다.** 그 기록에는
적합이 끝난 뒤 `_sensitivity` 가 각 `w[i]` 를 ±흔든 탐침까지 섞여 있었다. 적합기가
본 적 없는 점이다. `obj` 호출인 앞 `n_evals` 개로만 다시 재니 **0/24** 다.

`res.x` 대신 '본 것 중 최선' 을 붙드는 방벽을 `fit_weights` 에 넣었지만, 이 24건에서
**결과를 하나도 바꾸지 않는다** (검증: 방벽 있음/없음 표가 동일). 관측된 결함을 고친
것이 아니라 계단 함수에서의 위험을 막는 것이므로 그렇게 표시해 둔다.

**틀린 값을 지우지 않고 남긴다:** 5/24, 최대 0.0277 — 이것이 무엇이었는지가 아래
발견이다.

### 진짜 발견 — 최종점은 좌표 방향으로도 국소 최적이 아니다

민감도 탐침이 최종점을 이겼다는 사실 자체가 신호였다. 좌표 하강으로 다듬어 봤다
(재현: `python3 experiments/fitter_polish.py`, 다듬기는 **훈련 형상만** 본다).

- 훈련 regret: 24건 중 **9건 개선**, 최대 **+0.0513** (`luna-s5 long` 1.1194 → 1.0681)
- 구조 홀드아웃 중앙: 1.1063 → **1.0959 (+0.0105)** — 재실행 임계 0.01 **초과**
- 실행별: 6 개선 / 1 악화 / 5 동일. 악화는 `lunaNAMES-s0` **+0.0008** 한 건.
  개선은 최대 −0.0485 (`luna-s5`). 부호검정 (동점 제외 n=7) **p=0.125 — 유의하지 않다.**
- 비용: 추가 48~96 evals (적합 305 대비)

### A/B 해석은 뒤집히지 않는다

| | 다듬기 끔 | 다듬기 켬 | 변화 |
|---|---:|---:|---:|
| A 설명 (luna) | 1.1019 | 1.0915 | −0.0104 |
| B 이름만 (lunaNAMES) | 1.1178 | 1.1115 | −0.0063 |
| **B − A** | **+0.0158** (p=0.589) | **+0.0200** (p=0.310) | |

다듬기가 양쪽을 함께 끌어내리고 차이는 조금 벌어지지만, 여전히 시드 폭
(σ=0.0274, D-53) 안이고 유의하지 않다. **적합기 품질은 A/B 결론의 교락 요인이
아니었다** — D-54 의 층화 결론이 다듬기 아래에서도 유지된다.

### 남은 판단 — 다듬기를 켤 것인가

**결정 (2026-08-26): 기본으로 켠다.** `fit_weights(polish=True)` 가 기본값이다.
그리고 재적합으로 산출물만 고치는 것으로는 부족하다 — 12실행 전체가 오염된
채점 위에서 진화했으므로 **궤적 자체가 무효다** (원칙 13, D-56). 재실행한다.

이 문서의 위 표들에 있는 regret 값은 **폐기 대상**이다. 재실행 전
"고침이 듣는가" 를 확인하는 1단계에서만 쓰이고, 그 뒤 지워진다.

### 사전 기준의 결함 — 재적합과 재진화를 구분하지 못했다

```
재실행 판정  구조 홀드아웃 중앙이 0.01 이상 달라지면 12실행 재실행
```

이 기준은 **점수가 얼마나 달라지는가**만 본다. 그런데 재실행이 필요한 진짜
이유는 점수 차이가 아니라 **선택이 틀린 점수로 이뤄졌다**는 것이다. 차이가
0 이어도 궤적은 무효일 수 있다. 조용히 재해석하지 않고 결함으로 남긴다 (D-56).

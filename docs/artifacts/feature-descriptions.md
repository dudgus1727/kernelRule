# 피처 설명 효과 — 폐기

> **상태**: 폐기
> **후속**: `conclusion.md` 의 luna A/B

## 무엇을 주장했나

피처 목록에 "왜 성능을 좌우하는가" 를 넣으면 규칙이 좋아진다. `gpt-5.4`
3시드에서 **0.058** 개선으로 보였고, 한동안 **"시드 폭을 넘은 유일한
결과"** 로 인용됐다.

## 왜 폐기했나

두 가지가 겹쳤다.

```
1. 모델을 지시 없이 바꾼 것이었다 (D-52)
2. 지시된 모델(gpt-5.6-luna) 6시드 x 2조건에서 재현되지 않았다
   중앙값 차이가 시드 폭의 20% 이고, 형상별 부호 검정이 p = 1.000
```

**수치는 여기 남기지 않는다** — 배지만 보고 본문의 숫자를 인용하는 일이
반복됐다. 재현 값은 `conclusion.md` 에 있다.

## 남은 관찰 (수치와 무관)

기전 가설이 하나 나왔었다. **"쓰느냐" 가 아니라 "얼마나 무겁게 보느냐"** —
`has_spill` 사용률은 두 조건 모두 100% 였고 초기 가중치만 갈렸다.
`luna` 에서 이것이 성립하는지는 **확인하지 않았다** (`conclusion.md` 의
다음 단계 (3)).

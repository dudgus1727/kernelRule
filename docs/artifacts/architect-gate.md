# Architect A/B — 표 없이 구조를 만들 수 있다. 다만 관문은 못 넘는다

**측정일** 2026-08-21 · **재현** `python3 experiments/architect_gate.py {A|B} 10 {model}`

**분할** align 8/8/8 61형상을 `nk11008` 구조 분할 — 학습 41 / 검증 20
(N 또는 K 가 11008 인 MLP intermediate 레이어를 통째로 홀드아웃)
**절차** 각 시도마다 가중치를 학습 41형상에 재적합(Nelder-Mead, 300 evals)
**관문** 벤더 nearest 학습 1.0827 / 검증 1.0737

---

## 무엇을 물었나

전이가 성립하려면 새 아키텍처에서 **표 없이 구조가 나와야** 한다.

| | 표 요구량 | 무엇을 |
|---|---|---|
| 완전 이식 §29.5(a) | 0 | 구조 + 가중치 그대로 |
| **재적합 §29.5(b)** | 표본 5% | 구조 고정, 가중치만 |
| 재생성 §29.5(c) | 전수 | 구조부터 새로 |

표를 봐야 구조가 나오면 그것은 (c) 이고, 전수를 잴 거면 표를 직접 쓰면
되므로 이 시스템을 쓸 이유가 없다. 그래서 **A 가 관문**이다.

```
A 조건   하드웨어 사실 + 실행 모델 + 피처의 물리적 정의(+범위)
         ★ 부모 없음. 사례 없음. 점수 없음. 표에서 나온 문장 0개
B 조건   거기에 학습 분할의 집계만 (형상 식별 불가)
```

## 결과

### 모델이 결정적이다

| A 조건 | 유효 | train 최고 | train 중앙 | val 최고 |
|---|---:|---:|---:|---:|
| `gpt-5.4-mini` | 10/10 | 1.7828 | 2.0441 | 1.7744 |
| **`gpt-5.4`** | 8/10 | **1.1942** | 1.4826 | **1.1871** |
| `physics_seeded` (참고) | — | 1.1878 | — | 1.1386 |

**`gpt-5.4` 의 A 조건 최고가 `physics_seeded` 와 사실상 같다** (1.1942 vs
1.1878). `physics_seeded` 는 Claude Code 가 설계 문서를 통째로 읽고
**물리 오류 지적을 세 번** 받아 만든 것인데, 그것을 **표 없이 한 번에**
재현했다.

즉 "표 없이는 구조가 안 나온다" 는 성립하지 않는다. 앞선 `mini` 결과
(1.78)는 **조건의 한계가 아니라 모델의 한계**였다.

### A 와 B 의 격차 = 표의 값어치 (`gpt-5.4`)

| | 유효 | train 최고 | train 중앙 | train 최악 | val 최고 |
|---|---:|---:|---:|---:|---:|
| A (물리만) | 8/10 | 1.1942 | 1.4826 | 1.8477 | 1.1871 |
| B (물리+집계) | 10/10 | 1.1656 | **1.1809** | 1.2493 | 1.1289 |

**표가 사는 것은 "최고" 가 아니라 "실패하지 않음" 이다.**

```
최고    1.1942 -> 1.1656   0.029 개선
중앙    1.4826 -> 1.1809   0.302 개선   ★
최악    1.8477 -> 1.2493   0.598 개선   ★
```

집계를 주면 **분산이 줄어든다.** 새 아키텍처로 갈 때 포기해야 하는 것은
도달 가능한 최고점이 아니라 **시도 낭비**다 — A 조건에서는 좋은 구조를
얻으려면 여러 번 뽑아야 한다.

### ★ 그러나 관문은 넘지 못한다

| | 학습 41 | 검증 20 | 검증 유의성 vs 벤더 |
|---|---:|---:|---|
| Architect A 최고 | 1.1942 | 1.1871 | 8승 **12패** 0무 |
| Architect B 최고 | 1.1656 | 1.1542 | 7승 **13패** 0무 |
| `physics_seeded` | 1.1878 | 1.1386 | 6승 **14패** 0무 |
| **벤더 nearest** | **1.0827** | **1.0737** | ★ 관문 |

셋 다 벤더에 유의하게 진다. **"구분 불가" 가 0개**라 흐려진 결과가 아니다.

판정 기준은 "train 최고 1.07 근처면 통과" 였다. **1.194 는 미달이다.**

## 무엇이 확인되고 무엇이 안 됐나

**확인됨 — 표 없이 물리만으로 구조가 나온다.** A 조건이 손으로 만든 최고
구조를 재현했다. §29.5(b) 의 앞쪽 절반("구조는 표 없이 만든다")은 성립한다.

**미확인 — 그 구조가 관문을 넘는가.** A 도 B 도 `physics_seeded` 도
1.15~1.19 에서 멈추고, 벤더 1.074 에 유의하게 진다. 진화 규칙(`evolved`)만
이 벽을 넘었다 (전체 61 기준 1.0850, 빠른 체제 24승 3패).

→ **한 번에 쓰는 것과 반복해서 고치는 것 사이에 실제 격차가 있다.**
Architect 를 아카이브의 씨앗으로 넣고 진화시키는 것이 다음 단계다
(§11.8 — 라운드당 1개, 부모 없음).

## 부수적으로 드러난 것

**1. 제약을 하나씩 배우면 재시도가 끝난다.** `mini` A 조건 첫 실행은
10회 중 8회가 재시도 소진이었다. `capture_run_messages` 로 회차를 보니
가중치 재사용 → 무효항 → 리터럴 예산을 **순서대로** 하나씩 맞다 끝났다.
셋을 체크리스트로 앞세우자 재시도 0 이 됐다. 132/240 과 같은 병이다.

**2. 검사가 정적 단계에만 있으면 모델이 배우지 못한다.** 세 검사를
Pydantic validator 로 올려야 되먹임이 걸린다. 그 전에는 제안이 조용히
폐기되고 같은 실수가 반복됐다.

**3. 피처 범위 없이는 규칙을 못 쓴다.** `f.edge_waste [0,300]` 과
`f.tail_waste [0,1]` 을 같은 가중치로 더해 **regret 8.4** 가 나왔다.
범위는 표가 아니라 피처의 물리적 정의이므로 A 조건에 넣는 것이 맞다.

**4. 가중치 적합은 병목이 아니다.** 300 / 1500 / 4000 evals 가 같은 값을
낸다 (`physics_seeded` 1.1878 고정, arch #0 2.0348 고정). 나쁜 점수는
적합 실패가 아니라 구조 때문이다.

## 0. ⚠️ 먼저 — 곡선의 출처가 틀렸다 (D-139)

`round_curve.py` 가 `archive.jsonl` 을 읽고 있었다. 그것은 **마지막
아카이브 상태**다 (`loop.py:1351`, `archive.dump`). 거기서 "round <= r
중 최고" 를 고르면 **끝까지 살아남은 elite 만** 보게 된다.

```
F3rw-p8-nan-s3 의 옛 곡선   ★ nan nan nan 1.0811 …
그런데 rounds.jsonl r0      채점 12 채택 4 셀 3   ← 아카이브는 비어 있지 않았다
```

라운드마다의 최고는 **`bests.jsonl`** 이 갖는다 (`loop.py:1364`, 라운드당
한 줄, 코드·가중치까지). 그것으로 다시 만들었다.

```
편향의 방향   앞 라운드가 실제보다 **나쁘게** 나온다
정확한 지점   ★ 마지막 라운드 (그때는 살아남은 것이 곧 최고다)
```

⚠️ `F3rw-p8-old` 에는 `bests.jsonl` 이 **없다** (그 산출물 이전 실행).
**그 캠페인은 마지막 라운드 r11 만 쓸 수 있다** — 마침 비교에 필요한
값이 거기다.

## 2. 사전 등록 §5-2 — **"새 프롬프트가 느리다" 는 재현되지 않았다**

```
문턱 (사전 등록)   nan r11 - 옛 r11 >= +0.0180 이면 재현

옛 r11    1.0762   ★ 그 캠페인의 마지막 라운드 — 편향 없음

**그리고 이 질문을 만든 `+0.0359` 자체가 틀린 곡선에서 나왔다.**
바로잡으면 `+0.0138` 이다. 부호는 세 캠페인 다 같지만(새 프롬프트가
조금 나쁨) 크기가 사전 등록한 문턱 아래다.

```

## 3. `__import__` 수정 효과 — 구분 불가, 새 값이 대표값

```
nan 끝값 1.0903  -  새24 끝값 1.0787  =  +0.0116   <  판정선 0.0516
-> 구분 불가. 실험 계획서 §4 대로 **새 값을 대표값으로 삼는다**
```

```
★ 새 대표값   1.0903   (F3rw-p8-nan, 6시드, 라운드 24, __import__ 수정)
              시드별 1.0461 1.0789 1.0855 1.0951 1.1145 1.1448
```

### ⚠️ 시드 폭이 판정선의 가정을 넘는다

```
이 캠페인 σ = 0.0335
판정선을 만든 σ 95% 상한 = 0.0319
★ 넘는다
```

원칙 7 의 "팔마다 산포를 재라" 가 걸리는 자리다. **판정선을 여기서
바꾸지 않는다** (결과를 보고 바꾸면 안 된다). 다음 사전 등록에서 이
사실을 근거로 다룬다.

## 4. 거부 — `run` 34 -> 0 (제안 수가 정확히 같다)

```
              제안   run  fit  static  sandbox   합계    비율
옛 F3rw-p8    1728    34    0     26       3      63   3.65%
★ nan         1728  ★ 0   10     14       1      26   1.50%
```

**`__import__` 결함이 사라졌다** (사전 등록 §5-1 통과).

`fit` 이 0 -> 10 으로 늘었다. 전부 같은 문구다 — *"모든 가중치에서 규칙이
유효한 점수를 내지 못했다 (205/205). 구조를 기각한다."* 옛 캠페인은
**항상 무효인 규칙조차 적합기 판정에 도달하지 못하고 터졌다.**

```
터지던 34건  ->  10건은 205번 다 무효라 어차피 기각
                 ★ 나머지 약 24건이 이제 점수를 받는다
```

⚠️ **정적 거부는 0 이 아니다.** 26 -> 14 (그중 AST 노드 21 -> 11) 로 줄었지만
남아 있고, n 이 작아 우연과 구분되지 않는다. **관측으로만 둔다.**

## 5. ★ D-134 의 "24 가 12 보다 좋다" 도 약해진다

그 값도 틀린 곡선에서 나왔다. `bests.jsonl` 로 다시 재면:

```
                    r11 -> r23 개선     좋아진 시드   부호검정
D-134/135 가 적은 값   +0.0395            6/6         p=0.0156
★ 새24               +0.0074 (중앙 +0.0047)  5/6      p=0.219
★ nan                +0.0102 (중앙 +0.0122)  4/6      p=0.688
★ 합계 12시드          +0.0088            9/12        p=0.146
```

**크기가 시드 σ(0.0124) 보다 작고 부호검정도 유의하지 않다.**

```
말할 수 있는 것   12시드 중 9시드가 r23 에서 r11 보다 낫다 (평균 +0.0088)
말할 수 없는 것   ★ "24 가 12 보다 낫다" 를 판정으로
비용             라운드 12 -> 24 = LLM 2,800 -> 5,600 호출
```

**라운드 24 를 유지할지는 다시 볼 자리다** — 이 문서는 그것을 정하지
않는다 (결과를 보고 조건을 바꾸지 않는다). 다음 실험 계획서의 몫이다.

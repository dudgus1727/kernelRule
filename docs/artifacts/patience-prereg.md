# 사전 등록 — `patience` 를 정한다 (LLM 0회)

**계산 전에 쓴다.** 기준을 먼저 박고, 결과를 보고 바꾸지 않는다.

## 0. 확인한 것 — 새 셀 조건은 **이미 들어가 있었다**

D-127 의 "patience=3 이었다면" 계산이 루프의 두 조건을 다 쓴다.

```python
improved  = vals[end - n] - vals[end]                    # 루프와 같은 창
new_cell  = any(cells[i] > cells[i-1] for i in 최근 n 라운드)
if abs(improved) > thr or new_cell:  continue            # 안 멈춘다
```

루프의 `last_new_cell_round > len(rounds) - 1 - n` 과 같은 창이다
(`n_cells` 는 줄지 않으므로 증가 = 새 셀).

## 1. 재는 것

```
대상    F3rw-p8 6시드 (주) · F1rw-p8 · F2rw-p8 각 6시드
patience  3 / 5 / 7   (그리고 참고로 10 = 지금 값)
문턱    `is_significant` 가 쓰는 값 그대로 — F3 6시드 전부 0.0047
```

시드마다:

```
가정 종료 라운드     루프 공식 그대로 (★ 새 셀 조건 포함)
★ 놓칠 개선         (종료 시점 best_val_regret) - (r11 의 best_val_regret)
                    = 그때 멈췄으면 **잃었을** 양. 음수면 잃는 것이 없다
12 전에 멈춘 시드 수
```

함께:

```
★ r6 -> r11 누적 개선   vals[6] - vals[11]
   0.01 이하면   24 로 늘려도 얻는 것이 σ(0.0124) 아래다
   0.03 이상이면 아직 크게 오르고 있다
```

## 2. 고르는 기준 — ★ 미리 정한다

```
★ "놓칠 개선" 의 **6시드 중앙값**이 σ(0.0124) 미만인 **가장 작은** patience
   동률이면 작은 쪽 (라운드가 적게 든다)
   어느 값에서도 σ 를 넘으면 → 그 사실을 적고 **patience 를 크게** 간다
```

**중앙값을 쓰는 이유**: 보고하는 통계가 시드 중앙값이므로, 캠페인 수준에서
잃는 양이 곧 중앙값의 이동이다. **최대값도 함께 적는다** — 한 시드가 크게
잃으면 그것은 시드 폭 이야기이지 patience 이야기가 아니다.

⚠️ 판정은 F3rw-p8 로 한다. F1/F2 는 문턱이 근사다 (D-127 §4).

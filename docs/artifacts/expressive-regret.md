## 0. 조건 — 팔마다 하나, 팔 사이에 **하나만** 다르다

`runset.assert_same_condition` 이 팔 안을 검사하고, 기준선과 다른 키가
예상과 어긋나면 거기서 멈춘다 (원칙 39, D-120).

```
            예산  목적함수  적합기   곱     지수    씨앗
예산 8       8   regret  cma/1  False False  d5ee6da8
예산 16     16   regret  cma/1  False False  d5ee6da8   다른 키 ['rule_budget'] ✅
곱 힌트      8   regret  cma/1  True  False  d5ee6da8   다른 키 ['product_hint'] ✅
지수 힌트     8   regret  cma/1  False True   d5ee6da8   다른 키 ['power_hint'] ✅
```

## 1. 예산이 구속했나 — **네 번째 만에 조건이 산다**

D-105·106·107 에서 세 번 무효였던 자리다.

| 팔 | 예산 소비 (리터럴+가중치) | 아카이브 항 수 | ★ 1라운드 **제안**의 항 수 |
|---|---|---|---|
| 예산 8 | 중앙 8.0 / 상한 8 (16/16 상한) | 8.0 (7~8) | 8.0 (7~8) |
| 예산 16 | 중앙 14.0 / 상한 16 (3/10 상한) | **11.0 (9~12)** | **9.0 (8~10)** |
| 곱 힌트 | 8.0 / 8 (18/18) | 8.0 (7~8) | 8.0 (7~8) |
| 지수 힌트 | 8.0 / 8 (32/32) | 8.0 (7~8) | 8.0 (8~8) |

**첫 라운드부터 8항을 넘는다** — D-107 은 여기서 전부 8 이었다.

⚠️ 1라운드 항 수는 **제안**에서 센다. 아카이브에서 세면 안 된다 —
MAP-Elites 가 뒤 라운드로 갈아치워 `round==0` 항목이 남지 않는다
(예산 16 팔에서 실제로 0개였다). 처음에 아카이브로 세서 `nan` 이
나왔고, 그것이 이 주의를 만들었다.

## 2. ★ 주 지표 — regret@1, 홀드아웃 20형상, 3시드

| 팔 | 중앙 | 시드 범위 | 시드별 | 기준선 대비 | 판정 (delta 0.0516) |
|---|---:|---|---|---:|---|
| **예산 8 (기준선)** | 1.0987 | 1.0926~1.1186 | 1.0926 / 1.1186 / 1.0987 | — | — |
| 예산 16 | 1.0906 | 1.0764~1.0964 | 1.0906 / 1.0964 / 1.0764 | +0.0081 | **구분 불가** |
| 곱 힌트 | 1.0840 | 1.0794~1.0944 | 1.0944 / 1.0840 / 1.0794 | +0.0147 | **구분 불가** |
| 지수 힌트 | 1.0839 | 1.0319~1.1063 | 1.0839 / 1.1063 / 1.0319 | +0.0148 | **구분 불가** |

**셋 다 판정선을 못 넘는다.** 가장 큰 것이 +0.0148 로 선(0.0516)의
29% 다.

### 그런데 방향은 셋 다 같다 — 시드를 짝지어 보면

```
예산 16    +0.0020  +0.0222  +0.0223   ★ 3/3 시드가 좋아진다
곱 힌트     -0.0019  +0.0347  +0.0193     2/3
지수 힌트    +0.0087  +0.0123  +0.0668   ★ 3/3
```

**같은 씨앗에서 출발한 같은 시드끼리 견주면 방향이 고르다.** 다만
크기가 판정선의 1/3 이고 3시드다 — 3대3 에서 3/3 이 같은 방향일 확률은
귀무가설에서도 1/4 다 (부호검정 단측 p=0.125). **말할 수 있는 것은
"방향이 고르다" 까지다.**

⚠️ 옛 기준선 `1.0762` 은 **Nelder-Mead 200/600** 짜리다 (6시드). 이번
기준선은 CMA 300/600 의 3시드로 1.0987 이다 — 나란히 놓지 않는다
(원칙 4). §7 에 그 차이를 따로 적었다.

## 3. ★ regret@k — 1등이 아니라 **영역**에서 달라진다

실험 계획서가 "함께 보라" 고 한 지표다. **판정선은 없다** — 아래는 관측이다.

| 팔 | k=1 | k=10 | k=50 | k=100 |
|---|---|---|---|---|
| 예산 8 | 1.099 (1.093-1.119) | 1.125 (1.123-1.140) | 1.173 (1.154-1.174) | 1.180 (1.169-1.197) |
| 예산 16 | 1.091 (1.076-1.096) | **1.091 (1.088-1.121)** ★ | **1.133 (1.125-1.154)** ★ | 1.151 (1.144-1.231) |
| 곱 힌트 | 1.084 (1.079-1.094) | 1.108 (1.062-1.124) | 1.116 (1.109-1.174) | 1.141 (1.134-1.203) |
| 지수 힌트 | 1.084 (1.032-1.106) | **1.109 (1.049-1.109)** ★ | **1.111 (1.081-1.129)** ★ | **1.114 (1.101-1.127)** ★ |

★ = 3시드 범위가 기준선 범위와 **겹치지 않는다**.

```
k=1     넷 다 겹친다               ← 주 지표. 실험 계획서의 판정선이 걸린 곳
k=10    예산 16 · 지수 힌트 안 겹침
k=50    예산 16 · 지수 힌트 안 겹침
k=100   ★ 지수 힌트만 안 겹침 (1.101-1.127  vs  1.169-1.197)

지수 힌트 k=100 짝지어   +0.0422  +0.0662  +0.0965   3/3
```

### ⚠️ 이것을 판정으로 쓰지 않는다 — 세 가지 이유

```
1  실험 계획서에 regret@k 의 **판정선이 없다.** 결과를 보고 선을 만들면
   그것은 선을 고르는 것이다 (지시문 §6)
2  3대3 에서 "안 겹친다" 는 단측 p=0.05 다 (1/20). 약한 증거다
3  ★ 팔 3 x k 4 = **12칸을 봤다.** k 끼리 강하게 상관돼 독립 12번은
   아니지만, 다중성이 있는 것은 사실이다 (원칙 33)
```

**그러나 방향은 적어 둔다**: 표현력을 넓힌 팔들은 **1등이 아니라
상위 영역에서** 좋아진다. 이것은 실험 계획서 §3-4 가 물은 것
("영역을 더 정밀하게 가리키는가, 1등만 좋아지는가")에 대한 답이
**"영역 쪽"** 이라는 뜻이고, 다음 실험의 씨앗이다.

### tau 는 여전히 0 근처다

```
              상위100 tau   노이즈 인식
예산 8            0.075      -0.082
예산 16           0.001      -0.017
곱 힌트            0.075      -0.061
지수 힌트           0.116       0.024
```

regret 경로 규칙은 **상위권 순서를 못 맞춘다** — D-104 의 벽 그대로다.
지수 팔이 유일하게 노이즈 인식 tau 가 양수(0.024)지만 0 근처다.

## 4. 학습-홀드아웃 격차 / 적합기 / 비용

| 팔 | 학습 | 홀드아웃 | 격차 | 적합 이동 | 거부율 | 분 |
|---|---:|---:|---:|---:|---:|---:|
| 예산 8 | 1.0916 | 1.1136 | +0.0259 | 96.7% | 0.9% | 76.7 |
| 예산 16 | 1.0757 | 1.0964 | +0.0141 | **79.9%** | 2.5% | 80.7 |
| 곱 힌트 | 1.0843 | 1.0816 | +0.0029 | 97.7% | 0.7% | 70.0 |
| 지수 힌트 | **1.0459** | 1.0839 | +0.0013 | 98.5% | 2.1% | 77.2 |

```
★ 예산 16 의 적합 이동이 79.9% 다 — 나머지는 97~99%.
  16차원에서 CMA 도 다섯 번에 한 번은 초기값에서 못 움직인다.
  §2 통과 조건의 유보(재적합 도달률 67%)와 같은 방향이다
★ 격차가 벌어지는 팔은 없다. 표현력을 넓혀도 과적합이 아니다
```

고른 config 종류 (3시드 x 홀드아웃 20형상): 예산 8 **15** / 예산 16 25 /
곱 21 / 지수 22. **표현력을 넓히면 더 다양한 config 를 고른다.**

## 5. 형태를 실제로 썼나 — ★ 제곱과 교차곱을 따로 센다

| 팔 | 제안: 곱 쓴 규칙 / 제곱 / 교차 | 아카이브: 곱 쓴 규칙 / 제곱 / 교차 |
|---|---|---|
| 예산 8 | 286/432 (66%) / 15 / 504 | 7/16 / 0 / 14 |
| 예산 16 | 338/432 (78%) / **143** / **951** | 10/10 / 4 / 30 |
| 곱 힌트 | 331/432 (77%) / 43 / 632 | 12/18 / 0 / 31 |
| 지수 힌트 | 179/432 (41%) / 3 / 449 | 10/32 / 0 / 29 |

**곱은 힌트 없이도 66% 가 쓴다** — D-110 의 "검사기가 원래 안 막았다"
가 regret 경로에서도 그대로다. 힌트는 66% -> 77% 로 올린다.

★ 제곱과 교차곱을 따로 세니 **제곱은 드물다** (예산 8 에서 15 대 504).
합집합으로 접었으면 "곱 쌍" 의 최빈이 제곱으로 보였을 것이다 (D-110 의 정정).

### ★ 지수는 regret 경로에서 **살아남는다**

```
                          제안              아카이브
D-112 (순위 손실 경로)      78/432 (18.1%)    1/26 ( 3.8%)
★ 이번 (regret 경로)      190/432 (44.0%)   20/32 (62.5%)
힌트 없는 세 팔             0/432 ( 0.0%)     0/44 ( 0.0%)
```

**말 안 하면 아무도 안 쓴다** (0/1,296). 말해 주면 regret 경로에서는
44% 가 쓰고 **아카이브의 62.5% 가 그것을 지킨다** — 순위 손실 경로에서는
3.8% 만 남았다. D-112 의 "겨뤄서 졌다" 는 **그 목적함수에서의 결론**이었다.

## 6. ★ 판정 — 실험 계획서 §3 그대로

```
regret@1 이 delta 0.0516 이상 좋아진 팔   없음
-> 셋 다 **구분 불가**
```

실험 계획서 §4 의 첫째 갈래다:

```
★ 벽은 피처 공간의 성질이다. 선형/비선형/예산이 아니다
   -> GBDT 가 **같은 피처**로 1.019 를 낸다. 그 모순을 풀어야 한다
   -> 남는 후보: **트리의 조건부 분기**
      우리 `np.where` 는 형상 수준(`p.*`)으로만 달라진다
      GBDT 는 config 수준 피처(`f.*`)의 문턱으로도 달라진다
```

⚠️ **다만 §3 의 관측이 이 결론을 좁힌다.** "표현력이 아무것도 안 한다"
가 아니라 **"1등 고르기에서 판정선만큼 안 한다"** 이다. 상위 영역
(k=10~100)에서는 지수 팔과 예산 16 팔의 시드 범위가 기준선과 안 겹친다.

## 7. 곁가지 — **적합기를 세게 해도 홀드아웃은 안 좋아진다**

```
옛 기준선 (Nelder-Mead 200/600, 6시드)   1.0762
새 기준선 (CMA-ES 300/600, 3시드)        1.0987   ★ 0.0225 나쁘다
```

⚠️ 절차가 셋 다르다 (적합기·예산·시드 수). 판정에 쓰지 않는다. 그러나
**적합기를 16차원까지 버티게 고쳤는데 예산 8 홀드아웃이 좋아지지
않았다** — 방향은 오히려 반대다. §2 통과 조건이 잰 것(도달률)과 여기서
재는 것(홀드아웃 일반화)은 다른 것이고, **더 잘 맞추는 것이 더 잘
일반화하는 것이 아니다.**

이것은 D-56 의 유보("도달률 100% 를 '적합기가 최적을 찾는다' 로 읽지
마라")의 한 칸 더 나아간 형태다.

### ★ 뒤에 확인했다 — **적합기 탓이 아니다** (D-125)

같은 6구조를 두 적합기로 다시 맞춰 봤다 (변수는 적합기 하나).

```
arch24 6구조 + NM    홀드아웃 1.0762   ← 발표된 최종 점수를 정확히 재현
arch24 6구조 + CMA   홀드아웃 1.0753
짝지은 차이 중앙 -0.0010, Wilcoxon p = 0.9375   ★ 구분 불가
```

**어느 적합기로 재도 `rb08` 구조가 `arch24` 구조보다 나쁘다**
(rb08 세 시드가 arch24 여섯 시드 전부보다 나쁘다). 차이는 측정이 아니라
**진화가 만든 구조**에 있고, 두 캠페인은 적합기 말고도 적합 예산과
**그 사이에 바뀐 프롬프트 전부**가 다르다. 위 문단의 "방향이 반대다" 는
사실이지만 **적합기의 성질로 읽으면 안 된다.** 전문은
[fitter-regress.md](fitter-regress.md).

# ★ regret 경로 16차원 — **CMA-ES 로 관문을 넘었다.** 대리 초기점은 해롭다

> **상태**: §2 관문 **통과**. §3(표현력 셋)을 예산 16 까지 돌릴 수 있다
> **재현**: `OMP_NUM_THREADS=1 python3 -m experiments.fitter_regret --jobs 20`
> (약 50분, **LLM 호출 0회**)
> **사전 등록**: [fitter-regret-prereg.md](fitter-regret-prereg.md)
> **원자료**: `docs/artifacts/fitter-regret.json` — 60칸 전부 + 가중치 벡터
> **표**: `datasets/rtx-a6000-sm_86-c63710df` (dev)
> **대상**: regret 진화 6실행(`f1pipe-F3-arch24-s0..s5`)의 최종 규칙,
> 체제 short/long 각각 = 팔마다 12칸

## 0. 왜 관문인가

표현력 셋(예산·곱·지수)이 **전부 순위 손실 경로에서만** 돌았다
(D-108·D-110·D-112). 순위 손실이 틀린 목적함수였으니(D-118·D-121)
regret 경로에서 다시 재야 하는데, 예산 16 은 D-77 에서 막혀 있었다 —
"예산 16 이 나쁘다" 와 "적합기가 16차원에서 못 찾는다" 가 안 갈린다.

## 1. 팔 다섯 — evals 예산을 같게 줬다

```
팔           항  최적화기      적합  재시작 다듬기 대리  실제 총 evals (중앙/최대)
A8            8  Nelder-Mead  300     4    600   —      905 / 905
NM16         16  Nelder-Mead  300     4    600   —      905 / 913   <- D-77 B16-lo
CMA16        16  CMA-ES       300     1    600   —      914 / 922
CMA16-full   16  CMA-ES       900     1      0   —      914 / 914
SURR16       16  Nelder-Mead  150     2    600  150     910 / 914   <- (나)
```

**예산은 실제로 같았다** — 가정이 아니라 실측이다 (원칙 38). CMA 가
세대 단위로 끝나 몇 회 넘고(16차원 popsize 12), Nelder-Mead 도 재시작
진입 검사 때문에 905 가 된다. 최대 편차 2%.

새 항은 안 쓰인 피처의 **선형 항**이고 초기 가중치 0.01 이다 (지시문의
"작은 가중치로"). 모자라면 제곱 -> 두 피처의 곱으로 채운다. 이진 피처의
제곱은 자기 자신이라 제외한다 (D-77 과 같은 절차).

## 2. ★ 결과

| 팔 | 도달률 | 재적합 도달률 | 이동 | A8 보다 나쁜 칸 | 최대 손실 | 재적합 격차 중앙/최대 |
|---|---:|---:|---:|---:|---:|---:|
| **A8** (장치 점검) | **12/12 100%** | 9/12 75% | 8/12 | — | — | 0.0070 / 0.0110 |
| NM16 | 11/12 **92%** | 7/12 58% | 10/12 | 5/12 | +0.0208 | 0.0177 / 0.0462 |
| **CMA16** | **12/12 100%** | 8/12 67% | **12/12** | 4/12 | +0.0179 | **0.0125 / 0.0317** |
| CMA16-full | 12/12 **100%** | 8/12 67% | 12/12 | 4/12 | +0.0200 | 0.0230 / 0.0351 |
| SURR16 | 7/12 **58%** | 4/12 33% | 12/12 | 9/12 | **+0.2932** | 0.0295 / 0.3278 |

```
도달률       무작위 4000점(로그균등 0.05~50)이 적합 결과를 못 이긴 비율
재적합 도달률 그 분포의 출발점으로 다시 적합한 것 3회가 못 이긴 비율
재적합 격차   진 칸에서 (적합 - 재적합 최선)
```

### 장치 점검이 D-77 을 **정확히** 재현했다

```
        이번        D-77
A8      100% / 75%  100% / 75%
NM16     92% / 58%   92% / 58%   격차 최대 0.0462 = 0.0462
```

같은 절차·같은 대상이므로 재현돼야 하고, **소수 셋째 자리까지 같다.**
이 실행을 믿을 근거다 (원칙 1).

### ★ 판정 — 통과. 사전 등록의 선은 "어느 팔이든 도달률 90%"

```
NM16        92%   통과
CMA16      100%   통과
CMA16-full 100%   통과
SURR16      58%   미달
```

**세 팔이 통과했다.** 사전 등록 §3 의 고르는 순서대로:

```
1  도달률 최대        CMA16 · CMA16-full 이 100% 로 동점
2  재적합 도달률      둘 다 8/12 로 또 동점
3  ★ 같은 지표의 크기  CMA16 0.0125/0.0317  <  CMA16-full 0.0230/0.0351
   -> CMA16
```

⚠️ **사전 등록의 마지막 조항이 애매했다.** "그것도 같으면 NM16" 이라고
적었는데, 동점인 두 팔은 CMA 둘이고 NM16 은 그 밖에 있다 — 문자 그대로
읽으면 **더 나쁜 팔을 고르게 된다.** 새 기준을 들이지 않고 같은 지표의
**연속형**(격차 크기, D-77 이 "더 결정적" 이라고 쓴 그 값)으로 깼다.
그 사실을 여기 적는다.

### ⚠️ 통과했지만 D-77 의 **둘째 선**은 못 넘었다

D-77 은 통과선을 둘로 적었다 — 도달률 90% **그리고** 재적합 도달률이
A8 수준(75%).

```
              도달률   재적합 도달률   재적합 격차 최대
A8             100%        75%           0.0110
CMA16          100%        67%   ★       0.0317
```

**출발점 민감도가 줄었지만 사라지지 않았다** (NM16 0.0462 -> 0.0317,
58% -> 67%). 지시문의 §2 판정선은 도달률 하나이므로 **통과**이지만,
16항 팔의 적합 결과는 여전히 출발점에 따라 최대 0.032 움직인다.

```
판정선 delta          0.0516
CMA16 재적합 격차 최대 0.0317   ← 판정선 아래지만 같은 자릿수다
시드 폭 σ             0.0124   ← 2.6σ
```

§3-1 을 읽을 때 이 크기를 함께 봐야 한다. **사전 등록에 적는다.**

## 3. ★ (나) 대리 초기점은 **해롭다** — 58%

가장 뚜렷한 결과다. `rank_loss_top1` 로 L-BFGS-B 를 돌려 초기점을 만들고
거기서 regret 으로 다듬으면:

```
도달률          58%   (무작위 4000점이 12칸 중 5칸에서 이긴다)
A8 보다 나쁜 칸  9/12   최대 +0.2932
이동            12/12  ★ 움직이기는 확실히 움직인다
```

**미분 가능한 대리가 확실히 움직여서, 확실히 나쁜 곳으로 데려간다.**

```
NM16   적합 중앙 1.0601   무작위 4000점 중앙 1.0866
SURR16 적합 중앙 1.0811   무작위 4000점 중앙 1.0866   ← 무작위와 거의 같다
```

D-118·D-121 과 같은 방향이다 — 순위 손실의 최적점은 regret 의 최적점
근처가 **아니다**. D-121 은 "좋은 영역을 줘도 순위 규칙이 무작위보다
못 고른다" 였고, 여기서는 **거꾸로** 나온다: 순위 손실이 고른 점에서
출발하면 regret 최적화가 무작위 출발보다 못한 곳에서 끝난다.

⚠️ 채택은 regret 이었다 (사전 등록 §2). 대리 손실 값은 판정에 안 썼다.

## 4. 도달한 점은 **같지 않다**

지시문의 요구다. 도달률이 같아도 다른 국소해면 그것도 사실이다.

| 짝 | 같은 값 | \|Δfit\| 중앙 / 최대 | cos 중앙 / 최소 | 같은 방향 |
|---|---:|---:|---:|---:|
| NM16 vs CMA16 | 0/12 | 0.0108 / 0.0243 | 0.830 / 0.192 | 2/12 |
| NM16 vs CMA16-full | 0/12 | 0.0120 / 0.0206 | 0.939 / 0.423 | 2/12 |
| NM16 vs SURR16 | 0/12 | 0.0175 / 0.2932 | 0.913 / 0.210 | 0/12 |
| CMA16 vs CMA16-full | 2/12 | 0.0025 / 0.0217 | 0.971 / 0.160 | 4/12 |
| CMA16 vs SURR16 | 0/12 | 0.0208 / 0.3171 | 0.843 / 0.405 | 0/12 |
| CMA16-full vs SURR16 | 0/12 | 0.0249 / 0.2954 | 0.729 / 0.179 | 0/12 |

**같은 점에 도달하는 칸이 거의 없다.** 같은 CMA 두 팔조차 12칸 중 2칸만
값이 같고, 방향이 같은 칸은 4칸이다 (cos 최소 0.160).

```
★ 16차원 regret 표면에는 값이 비슷한 국소해가 여러 개 있고,
   적합기마다 다른 곳에 앉는다
```

값 차이(중앙 0.003~0.025)는 판정선 0.0516 보다 작다 — 그래서 §3 의
판정은 성립한다. 그러나 **"적합된 가중치 벡터" 를 해석 대상으로 쓰면
안 된다**: 어느 항이 살아남았는지는 적합기가 고른 국소해의 성질이다.

## 5. 곁가지 — 예산을 CMA 에 몰아줘도 안 낫다

```
CMA16       적합 300 + 다듬기 600   재적합 격차 중앙 0.0125
CMA16-full  적합 900 + 다듬기   0   재적합 격차 중앙 0.0230
```

D-77 은 "예산이 절반쯤 원인" 이라고 봤는데(`C16-one` 이 `B16-one` 보다
11/12 나았다), 그것은 **다듬기 예산까지 4배**로 늘린 팔이었다. 같은 총
evals 안에서는 **좌표 다듬기 쪽에 쓰는 것이 낫다.** 다듬기는 계단
함수에서 축 방향 계단을 하나씩 넘는 장치다 (D-55·D-59).

## 6. 이 관문이 D-77 을 어떻게 바꾸나

```
D-77   (가) 재시작을 전역으로  (나) 예산을 차원 비례로  (다) 다듬기 쌍좌표
       -> 셋 다 안 했다
이번   (가)를 **CMA-ES 로** 했다. 전역 탐색이 공분산을 학습한다
       -> 도달률 92% -> 100%, 재적합 58% -> 67%
       (나)는 위 §5 대로 이득이 없다
```

**D-77 의 "미달" 은 유지된다** — 그때 쓴 적합기(국소 재시작 Nelder-Mead)로는
92% 였고, 이번에도 92% 다. 바뀐 것은 적합기다.

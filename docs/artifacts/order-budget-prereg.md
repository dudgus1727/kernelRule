## 예산 8 vs 16 — 순위 손실 단독

**왜 지금 되나:** D-77(적합기가 16차원을 못 버틴다)이 `regret` 경로의
얘기였고, **순위 손실 경로에서는 도달률 100% / 재적합 도달률 100%** 로
통과한다. 적합기 탓으로 돌릴 수 없게 됐다.

```
BUDGET 8 vs 16,  순위 손실 단독 진화,  3시드씩 x 12라운드
검사기와 프롬프트가 ★ 같은 값을 본다 (`--rule-budget`)
```

### 주 지표 — ★ 학습 vs 홀드아웃 격차

```
예산을 늘리면 학습은 **반드시** 좋아진다. 그것은 지표가 아니다.
★ 격차(학습 - 홀드아웃)가 벌어지는가 = 과적합의 직접 지표

보조: 홀드아웃 상위100 tau / 최종 규칙의 항 수(16 을 다 채우나) /
적합기 도달률 / 셀 점유.

```

## 왜 관문을 다시 짜나

D-85 의 관문은 **"빼도 학습 점수가 안 나빠지면 판정이 맞다"** 였다.
**정의가 틀렸다.**

```
Critic 의 주장   "이 항을 물리로 설명 못 하겠다"
D-85 가 잰 것    "이 항을 빼도 학습 점수가 안 나빠진다"
★ 항 하나가 **중요하면서 동시에 설명 불가**일 수 있다
   — 그것이야말로 우리가 걱정하는 상황이다 (GBDT 처럼 잘 맞지만 설명 없음)
```

도구 자체는 안정적이다 — 순서를 섞어도 같은 식을 지목한다 (D-86,
자카드 0.67).

## ★ 새 지표 — 부호를 먼저 못 박는다

```
설명 가능한 항   물리라서 다른 형상에도 적용된다
                -> 빼면 적합/검증이 **비슷하게** 나빠진다
설명 불가한 항   학습 형상에 맞춰진 것
                -> 빼면 **적합만** 크게 나빠지고 검증은 덜 나빠진다

지표 = (적합 손상) - (검증 손상)

★ 양수 크다   학습에만 기여 = 과적합 서명   <- 설명 불가 항이 여기 몰려야 한다
   0 근처     양쪽에 고르게 기여
   음수       검증에 더 기여 = 물리적인 항
```

**D-85 와 부호가 반대다.** 그때는 "덜 아픔" 이 맞는 것이었고, 이번엔
**"학습에만 기여"** 가 맞는 것이다.

## 분할 — 4-fold, SOL 오름차순 라운드로빈

```
학습 41 (빠른 29 / 느린 12) 을 SOL 오름차순 정렬
fold 0,1,2,3,0,1,2,3,... 로 배분
-> [11, 10, 10, 10] 형상, ★ 느린 형상이 fold 마다 정확히 3개
```

**단일 30/11 분할은 검증에 느린 형상이 3개뿐이라 얇다.** 4-fold 면 같은
형상이 네 번 중 한 번은 검증에 오고, 검증 표본이 4배가 된다.

⚠️ **구조 홀드아웃 20 은 안 건드린다.** 이미 여러 번 봤다 — 안 건드리면
오염이 안 쌓인다 (§30.15).

체제별로 따로 적합하고(정준 절차와 같은 축) 형상 수로 가중 결합한다.

## 판정 — 미리 적는다

```
지표    설명 불가 항의 (적합-검증) **상대 순위** (1 = 가장 양수)
표본    ★ 규칙 단위. 규칙마다 지목 항의 중앙 순위를 내고 그 중앙값 (원칙 28)

중앙 >= 0.65   ★ 판정이 맞다 — 정성 산출물로 쓸 근거가 된다
중앙 <= 0.35   틀렸다 — 설명 불가 항이 오히려 일반화에 기여한다
그 사이        구분 불가
```

**지목 개수는 지표로 쓰지 않는다** — D-86 에서 규칙마다 ±2 로 흔들렸다.
**지목 여부만 재현된다.**

## ★ 목 기준선 — 세 개를 함께 잰다

D-86 이 보인 것은 **"진화가 뒤에 붙인 항이 실제로 설명하기 어렵다"** 였다.
그렇다면 **위치만 보고 찍어도 이 지표에서 높게 나올 수 있다.**

```
목 A   마지막 항 하나
목 B   ★ 마지막 k개 — k 는 그 규칙에서 실제 Critic 이 지목한 수와 **같게**
       (개수 효과를 뺀다. 이것이 주 대조군이다)
무작위  k개를 무작위로 (시드 고정, 200회 중앙값). 우연 기준선
```

```
★ 목 B 가 0.65 를 넘으면 실제 Critic 이 얼마가 나오든 **판정 불가**다.
  "Critic 이 위치 이상의 정보를 준다" 를 못 보이기 때문이다.
  그때는 멈추고 보고한다 — 관문을 또 다시 짜야 한다.
```

⚠️ **항별 지표는 지목과 무관하게 한 번만 계산한다.** 목이든 실제든
같은 숫자 위에서 순위만 다르게 읽는다 — 계산을 두 번 하지 않으므로
**"목을 보고 실제를 맞출" 여지가 없다.** 보고 순서는 목 -> 실제다.

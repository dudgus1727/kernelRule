## 1. ★ 주 지표(중복률) — C 는 B 다

```
사전 등록:  C >= 80% -> 다양성만으로 충분하다
관측:       C 85~92%,  중앙 89%   (B 84~92% 중앙 90%,  A 28~53% 중앙 47%)
★ B 범위와 완전히 겹치고 A 와는 분리된다
```

**중복은 다양성만으로 풀린다.** 가설이 이 라운드의 상태에 맞을 필요가
없다 — 매 라운드 다른 문장이 들어오는 것만으로 Optimizer 가 같은
자리를 다시 파지 않는다.

### 조기 정체도 같은 방향이다

```
정체 라운드   B r7~r9   C r5~r10   A r2~r4
```

**C 는 B 범위다.** 사전 등록의 "중복률과 같은 방향이면 결론이
단단해진다" 에 걸린다 — **조기 정체의 원인은 중복이었다.**

정적 거부도 같다 (C 7~10, B 6~10, A 0~1). 원칙 29 의 짝 지표가
셋 다 같은 쪽을 가리킨다.

## 2. ★ 그런데 성능은 절반도 못 회복한다

```
B 1.0704   C 1.0972   A 1.1163      (중앙)
C 가 회복한 격차 42% — 58% 가 남는다

C - B  +0.0268 = 시드 폭의 2.2배     ★ 범위 안 겹침
A - C  +0.0191 = 시드 폭의 1.5배     ★ 범위 안 겹침
```

**C 는 B 와도 A 와도 범위가 겹치지 않는다.** 셋이 각각 다른 자리에 있다.

## 3. ★ 사전 등록의 이분법이 너무 거칠었다

등록에는 이렇게 적었다.

```
C 가 B 에 가까우면   진단의 기여가 **다양성 주입**이다
C 가 A 에 가까우면   내용이 맞아야 한다 (§16.1 의 강한 형태)
```

**둘 다 맞고 둘 다 틀렸다.** 지표마다 답이 다르다.

```
중복률 · 정체 · 거부   C = B    ->  다양성이 푼다
성능                   C 는 중간 ->  내용이 필요하다
```

**두 기전이 따로 있다.**

```
다양성 주입   Optimizer 가 같은 자리를 다시 파는 것을 막는다
              -> 탐색 **폭**을 만든다
내용의 적합성  이 라운드에 무엇이 문제인지 지목한다
              -> 탐색 **방향**을 만든다
```

D-89 는 "Analyst 가 기여한다" 를 보였고, C 는 **그 기여가 둘로 쪼개진다**
는 것을 보인다. 그리고 **성능 기여의 58% 가 방향 쪽**이다.

⚠️ 이 42/58 배분은 **한 캠페인·3시드·12라운드에서의 값**이다. 씨앗을
바꾸면 달라질 수 있다 (D-82).

있고 표본이 작아 안 갈리는 것일 수도 있다. **이 자료로는 못 정한다.**

## 이 결과가 바꾸는 것

**§16.1 의 서술이 "진단 리포트가 기여한다" 에서 두 줄이 된다.**

```
탐색 폭    다양성 주입만으로 얻는다. 값싼 대체재가 있을 수 있다
탐색 방향  ★ 이 라운드의 진단이 필요하다. 대체재가 없다
```

**값싼 대체재 쪽은 실용적 함의가 있다** — 진단 리포트를 매 라운드
만드는 대신 **가설 은행을 돌려 쓰는 것**만으로 중복 문제는 사라진다.
다만 성능의 58% 를 포기하는 것이므로 지금은 권하지 않는다.

# 상위 100 안에 무엇이 남아 있나 — 순위 학습의 상한 (2026-09-01)

> **재현** `python3 experiments/top100_ceiling.py` · LLM 0회
> **원자료** [top100-ceiling.json](top100-ceiling.json)
> **쓰임** [rank-evo-prereg.md](rank-evo-prereg.md) 의 판정을 읽는 근거

## 1. 상금 — 그리고 GBDT 격차와 거의 같다

```
                         A6000 학습41   A6000 홀드20   5090 학습41
상위 100 의 시간 폭 (중앙)     6.6%          4.8%         1.2%
                (기하평균)     7.0%          5.2%          —
고유 시간값 (중앙)               24            34            5
```

★ **§9.2 의 GBDT 격차와 나란히 놓으면:**

```
우리(A6000 홀드아웃 중앙)  1.0762
GBDT                      1.019     ★ 학습이 도달 가능한 상한
로그 격차                  0.0546 = 5.6%

같은 홀드아웃의 상위 100 시간 폭   ★ 5.2% (기하평균)
```

**GBDT 가 가져간 이득이 상위 100 안의 순서로 설명될 수 있는 크기다.**
거의 같고, 격차 쪽이 **아주 조금 크다**(5.6% 대 5.2%) — 즉 대부분은
상위 100 안의 순서이고 **나머지 일부는 상위 100 밖까지 맞혀야 한다.**

⚠️ 두 숫자의 절차가 다르다. 격차는 **체제별 재적합 후 홀드아웃
geomean**, 폭은 **형상별 상위 100 의 최악/최적**이다. 크기 비교는
되지만 뺄셈은 안 된다 (원칙 4).

## 2. ★ 문제의 성격 — 타일이 아니라 stages / split_k / swizzle 이다

```
상위 100 안의 값 종류 (형상별 중앙)
  tile_m 2종   tile_n 2종   tile_k 2종      ★ 타일은 이미 정해져 있다
  ext_stages 5종   split_k 5종   ext_swizzle_n 4종
  split_k_mode 1종
```

**타일을 고르는 문제가 아니다.** 상위 100 에 오르면 타일은 두 가지로
좁혀져 있고, 남은 선택은 파이프라인 단계 · split-k · 스위즐이다.

## 3. 그래서 우리 피처가 불리하다

```
config 수준 피처 19개 중
  ★ 상위 100 안에서 상수인 것 4개
     edge_waste / has_spill / spill_magnitude / log_workspace_bytes
  변동계수 1% 미만 5개
```

**전부 타일 기하 또는 스필에서 나온 값들이다.** 상위 100 에 오르면
타일이 두 가지뿐이라 `edge_waste` 가 안 변하고, 스필 커널은 상위에
아예 못 온다.

**크게 변하는 것들은 반대로 stages / split_k 계열이다:**

```
split_k_cost          CV 0.70
sm_idle_cost          CV 0.54
pipeline_warmup_frac  CV 0.45
tail_waste            CV 0.39
waves                 CV 0.39
```

★ **이것이 상위권 tau 가 낮았던 이유를 설명한다** (D-100, top-tau.md).
규칙이 쓸 수 있는 축이 상위권에서 대부분 얼어 있다.

**그리고 순위 손실 진화의 결과를 읽는 근거가 된다** — 위 다섯이 실제로
쓰이는지가 "손실이 목표를 옮겼는가" 의 직접 증거다.

## 4. 배울 수 없는 몫

```
최적과 2~10등이 몇 축 다른가   중앙 2축 (10축 중)
★ 축이 전부 같은 쌍             4/369
```

**축이 같은데 시간이 다른 쌍은 어떤 손실로도 못 배운다** — 측정
비결정성이다. 4/369 = 1.1% 이고 작지만 0 이 아니다.

## 5. 5090 은 상금이 5분의 1이다

```
A6000 학습41  6.6%      5090 학습41  ★ 1.2%
```

같은 손실을 5090 에서 돌려도 얻을 수 있는 최대가 훨씬 작다.
**전이 실험에서 순위 능력을 볼 때 이것을 감안해야 한다.**

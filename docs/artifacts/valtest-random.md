# val/test 를 ★ 무작위로 쪼개 다시 (D-185)

> **재현** `python3 -m experiments.valtest_split --random --splits 40 --gpu <g>` · `--merge`
> ⛔ LLM 0회 · 적합 0회 — `bests.jsonl` 의 저장된 code·w 를 그대로 쓴다

## 왜

```
D-184 는 M 3분위로 ★ 층화해 쪼갰고 ★ 안 쓴다 로 판정했다
★ 그런데 층화가 그 판정을 만들었는지는 모른다 -> 무작위로 다시 잰다
⛔ 쪼개기 함수만 바꿨다. 다른 것이 같아야 비교가 된다
```

## 판정선 (⛔ 무작위 결과를 보기 전에 박았다)

```
(A) − (B) 의 ★ 전체 test 기하평균 차 > 쪼개기 폭 중앙   -> 쓸 만하다
그보다 작거나 (B) 가 나쁘다                            -> ★ 안 쓴다
```

⚠️ 이 판정선을 ★ 층화 대조군에 먼저 걸어 봤고 거기서도 **안 쓴다** 가 나온다 — 판정선 자체가 D-184 와 모순되지 않는다.

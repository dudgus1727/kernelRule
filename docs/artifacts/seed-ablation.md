# 씨앗 절제 — 폐기

> **상태**: 폐기
> **후속**: 없음. 재현하지 않았다

## 무엇을 주장했나

진화의 씨앗을 바꿔 셋을 비교했다 — Architect 산출물 / `physics_seeded` /
씨앗 없음. **"좋아 보이는 씨앗이 오히려 해롭다"** 는 결론이었다.

## 왜 폐기했나

```
1. 모델을 지시 없이 바꾼 것이었다 (D-52)
2. 시드 3개다. 조건 간 차이가 시드 폭의 1/4 였다 (D-40)
3. ★ "씨앗 없음" 조건에 씨앗이 있었다 (D-35) —
   optimize.md 의 출력 형식 예시가 physics_seeded 의 축약판이다
```

세 번째가 설계 결함이라 **모델을 맞춰 다시 돌려도 그대로 못 쓴다.**
예시를 중립화한 뒤에야 의미가 있다.

**수치는 여기 남기지 않는다.**

## 살아남은 것

**D-35 자체**가 결과다 — *형식 예시에 실제 이름을 쓰면 그것이 씨앗이 된다.*
`feature.md` 는 그래서 무관한 예시를 쓰고, 테스트가 그것을 고정한다.

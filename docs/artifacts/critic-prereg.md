# 사전 등록 — Critic (2026-08-28)

> **★ LLM 호출 0회 상태에서 작성했다.**
> **모델** `gpt-5.6-luna` medium (`DEFAULT_MODEL` 고정 — D-45, 원칙 25)
> **표** dev-cu124. **성능 수치를 인용하지 않는다**

## 무엇을 묻는가

**"규칙의 각 항이 물리로 설명되는가, 그리고 그 판정이 맞는가."**

"해석 가능한 규칙" 이 이 연구의 주장인데 지금은 **사람이 코드를 직접
읽어야** 확인된다. 항별 물리 설명이 GBDT 와의 차이를 눈에 보이게
만든다. **성능 개선이 목적이 아니다.**

## 설계

```
입력   규칙 코드 + **그 규칙이 쓰는** 피처 설명. 그것이 전부다
안 줌  점수 / 사례 / 부모 규칙 / 가중치 값 / 하드웨어 상수
출력   항마다 physics / explainable / why_not / regime_dependent
       + overall + defects
호출   아카이브 갱신 시에만 (비용). 지금은 루프 밖에서만 부른다
```

### 안 주는 이유

```
점수·사례·부모   만든 맥락을 알면 판단이 그쪽으로 끌린다 (§11.5)
가중치 값        표에 맞춘 값이라 "표가 골랐으니 맞겠지" 가 된다.
                부호·크기 이상은 FittedRule.invariants() 가 이미 본다
하드웨어 상수     "물리적 의미가 있나" 를 묻지 "A6000 에 맞나" 를 안 묻는다
```

## ★ 한계 — 같은 모델이 쓰고 심사한다

§11.5 원안은 **다른 모델**을 쓰라고 했다. 그런데 모델이
`DEFAULT_MODEL` 하나로 고정돼 있다 (D-45, 원칙 25).

```
같은 모델이므로 만든 쪽과 심사하는 쪽의 오류가 **상관될 수 있다**.
"설명 가능하다" 는 판정이 실제 물리적 타당성이 아니라
**그 모델의 일관성**일 수 있다.
★ 모델 간 대조는 별도 실험으로 사전 등록해야 한다.
```

**이 한계를 산출물에도 적는다** (`critic.json` 의 `_note`).

## ★ 관문 — 판정의 정확도를 정량으로 잰다 (LLM 0회)

`experiments/critic.py ablate`.

```
Critic 이 "설명 못 하겠다" 고 한 항을 **빼고 다시 적합**한다.
  빼도 regret 이 안 나빠진다   ★ 판정이 맞았다
  크게 나빠진다               틀렸거나, 설명 못 해도 유용한 항이다
```

**★ 대조가 반드시 필요하다.** "설명 불가 항을 빼도 멀쩡하다" 는
**모든 항이 그렇다면** 아무 말도 아니다. 그래서 **모든 항을 하나씩**
빼서 손상을 재고 순위를 매긴다.

```
주 지표   설명 불가 항의 **상대 손상 순위** (0 = 가장 덜 아픔)
         정확하면 아래쪽에 몰려야 한다
검정      Mann-Whitney (설명불가 < 나머지)
```

⚠️ **표본 단위는 '항' 이고 한 규칙의 항들은 독립이 아니다** (원칙 28).
규칙 6개면 유효 표본은 사실상 6이다. **p 를 주 근거로 쓰지 않고
순위 분포를 본다.**

⚠️ **가중치를 0 으로 두는 것이 아니라 항을 지운다.** 0 으로 두면
적합기가 도로 키운다 (`kernelrule/rules/ablate.py`).

⚠️ **못 지우는 항이 있다** — 한 줄에 여러 항이 있거나 분기 안에 항이
하나뿐인 경우. **조용히 건너뛰지 않고 "제거 불가" 로 따로 센다.**
"못 지웠다" 와 "지웠는데 영향 없음" 은 완전히 다르다.

## 판정 — 미리 적는다

```
설명 불가 항이 0개
  ★ Critic 이 전부 설명해 냈다 = **관대하다는 신호**다.
    프롬프트가 "설명 못 하는 것을 설명하지 마라" 를 이미 말한다.
    그래도 0 이면 그 사실을 결과로 적는다 — 프롬프트를 고쳐 다시
    돌리지 않는다 (§12.3d)

설명 불가 항의 손상 순위 중앙 <= 0.35
  ★ 판정이 맞는 쪽. 정성 산출물로 쓸 근거가 된다

중앙 >= 0.65
  ★ 판정이 틀린 쪽. **정성 산출물로도 쓰지 않는다** —
    틀린 설명을 붙이는 것이 안 붙이는 것보다 나쁘다

그 사이
  구분 불가. 규칙 수를 늘릴지 판단한다
```

## 벌점(정량)은 **지금 안 한다**

Critic 판정을 진화의 목적함수에 넣지 않는다. **판정이 맞는지 모르는
상태에서 진화 방향을 바꾸면 위험하다.** 관문을 통과한 뒤에 검토한다.

씨앗 선택은 학습 regret 하나로 한다. Critic 으로 바꾸면 §13.4 를
건드린다.

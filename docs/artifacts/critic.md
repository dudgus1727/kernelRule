> **재현**

> python3 experiments/critic.py ablate          # LLM 0회, 약 25분
> ```

## 1. 심사는 나온다 — 48항 중 13항(27%)을 "설명 불가" 로

**전부 설명해 내지는 않았다.** 프롬프트가 "설명 못 하는 것을 설명하지
마라" 를 말하고, 실제로 27% 를 지목했다.

지목 사유가 프롬프트가 지목한 결함 유형과 맞아떨어진다.

```
"split-K 비용과 반복 수, workspace, wave 수, tail, 파이프라인 warmup을
 한 곱셈식으로 결합해…"                     여러 물리량을 그냥 섞음
"…나누어 보정하려는 항이지만, 이 나눗셈 전체에 대한 근거가…"   근거 없는 나눗셈
"레지스터 압력과 smem 압력 중 큰 수치를 사용해…"      max 의 의미가 불명
"…트래픽 증폭을 제곱근으로 변환한 값이다"            제곱근의 근거 없음
```

실행별 편차가 크다: s2 는 0/8, s3 는 4/8.

## 2. ★ 통과 조건 — 통과하지 못했다

Critic 이 지목한 항을 빼고 재적합한 뒤, **모든 항을 하나씩 빼서** 손상
순위를 견줬다 (0 = 가장 덜 아픔).

### 규칙 단위 (표본 = 규칙, 원칙 28)

| 실행 | 지목 항의 중앙 순위 | 나머지 | 지목 수 |
|---|---:|---:|---:|
| s0 | 0.36 | 0.50 | 2 |
| s1 | 0.43 | 0.50 | 2 |
| s3 | 0.50 | 0.43 | 4 |
| s4 | **0.86** | 0.29 | 3 |
| s5 | 0.57 | 0.50 | 2 |

```
지목 중앙들의 중앙값 = 0.50   ★ 정확히 우연 수준
규칙 단위 p = 0.775
항 단위(참고)  지목 0.57 / 나머지 0.43,  p = 0.783
```

**실험 계획서 판정선으로는 "그 사이 = 구분 불가" 다.** 다만 0.50 은
구간 한가운데가 아니라 **우연의 정확한 값**이다 — 관계가 없다는
쪽의 증거다.

## 3. ★ 왜 안 맞았나 — 두 가지가 보인다

### (가) 통과 조건의 정의가 두 주장을 섞었다 — 내 잘못이다

```
Critic 의 주장    "이 항을 물리로 설명 못 하겠다"
통과 조건이 잰 것       "이 항을 빼도 학습 점수가 안 나빠진다"
```

**둘은 다른 주장이다.** 항 하나가 **중요하면서 동시에 설명 불가**일 수
있고, 그것이야말로 우리가 걱정하는 상황이다 — GBDT 처럼 잘 맞지만
설명이 없는 항. 실험 계획서에 "빼도 안 나빠지면 판정이 맞았다" 고 쓴 것은
**그 경우를 판정 실패로 세도록 만든 것**이다.

**통과 조건 자체를 다시 설계해야 한다.** 지금 자료로 말할 수 있는 것은
**"Critic 은 중복·무용 항 탐지기가 아니다"** 까지다. 그것은 Critic 이
한 적 없는 주장이다.

### (나) ★ 지목이 **위치**를 따라간다

```
인덱스별 지목률   w0 0%  w1 17%  w2 17%  w3 33%  w4 0%  w5 17%  w6 50%  w7 83%
인덱스별 손상 순위 w0 0.90 w1 0.29 w2 0.55 w3 0.60 w4 0.29 w5 0.19 w6 0.38 w7 0.81
```

**마지막 두 항(w6, w7)이 지목의 8/13 을 차지한다.** 그런데 `w[7]` 은
손상 순위가 0.81 로 **오히려 중요한 축**이다.

두 해석이 가능하고 이 자료로는 못 가른다.

```
1  진화가 항을 뒤에 붙인다 -> 뒤 항이 실제로 더 뒤죽박죽이다  (신호)
2  LLM 이 마지막에 본 것을 지목하는 위치 편향             (잡음)
```

⚠️ **목 Critic(항상 마지막 항을 지목)이 0.79 를 냈다.** 아무 근거 없는
판정도 비슷한 자리에 온다 — 지금 결과를 목과 구별할 근거가 약하다.

## 4. 부수 발견 — 절제가 규칙 자체를 드러낸다

Critic 과 무관하게 성립한다.

```
★ 4/6 규칙에 **빼면 학습 regret 이 좋아지는 항**이 있다
   s4 w[1] -0.0327   s2 w[5] -0.0210   s3 w[1] -0.0185   s1 w[1] -0.0146 …
   ★ 그중 여섯은 Critic 이 "설명 가능" 이라고 한 항이다
w[0] 이 6규칙 중 4규칙에서 가장 중요하다 (손상 0.14~0.23)
제거 불가 항 0/48 — 이번 규칙들은 전부 한 줄에 한 항이었다
```

**"설명 가능한데 있으나 마나 한 항" 이 실제로 있다.** 예산이 8인데
그중 하나가 해가 된다면 그것은 예산 논의(§29.4)로 이어진다.

## 5. 판정 — 정성 산출물로 **아직 안 쓴다**

실험 계획서: `중앙 >= 0.65` 면 안 쓴다, `<= 0.35` 면 쓴다, 그 사이면
구분 불가. **0.50 이므로 구분 불가**이고, 위치 편향 의심이 겹친다.

```
쓰지 않는다   틀린 설명을 붙이는 것이 안 붙이는 것보다 나쁘다
버리지도 않는다  통과 조건의 정의가 틀렸을 가능성이 크다 (3-가)
```

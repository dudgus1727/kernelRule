## 1. 축퇴는 아니다 — 그러나 "가운데" 다

A6000 학습 41형상, 후보 중앙 15,015개.

```
구조     종류   최빈  정적top-1과  hit@1   tau 전구간
s0        11    11        0         3      0.556
s1        16     9        0         5      0.295
s2         9    20        0         3      0.450
s3        14    10        0         3      0.397
s4        16     8        0         3      0.310
s5        15     8        0         3      0.371
★ 무작위  41.0    —        —       0.1     -0.000
```

```
다양성 중앙 14.5종 / 41형상   -> 사전 등록의 "가운데 (6~19)"
정적 top-1(1.1220)과 같은 형상  ★ 6구조 전부 0개 — 정적 축퇴는 아니다
전 구간 tau 0.30~0.56 대 무작위 0.00  ★ 순위 신호가 분명히 있다
```

⚠️ 다만 구조마다 성격이 다르다. `s2` 는 9종에 최빈이 20/41 형상을
덮고, `s4` 는 16종에 최빈 8/41 이다. **"가운데" 안에서도 s2 는
축퇴 쪽에 가깝다.**

## 2. 상위권 순위 능력은 낮다 — ★ 통제 결과는 [top-tau.md](top-tau.md)

```
참 상위 100개의 tau-b 중앙 = 0.141   -> 사전 등록의 "가운데 (0.10~0.30)"
```

⚠️ **정정** 이 절의 제목을 처음에 "상위권에서는 순위를 잘 못 매긴다"
로 썼다. **0.141 은 내가 박은 판정선에서 "가운데"** 이고 "못 매긴다"
(<=0.10)가 아니다. 판정선을 스스로 정해 놓고 그보다 센 말을 했다.

**분해능을 통제하고 다시 쟀다** ([top-tau.md](top-tau.md)): 통제 후
0.096 / 0.084 로 **내려가서** "못 매긴다" 쪽이 되지만, **근거가
처음 생각과 반대다** — 분해능을 걷어내니 좋아진 것이 아니라 나빠졌다.
그리고 구조마다 부호가 갈린다 (s2 -0.181, s4 +0.351).

**그런데 그 전에 볼 것이 있다.**

```
참 상위 100개의 서로 다른 시간값
  중앙 24개   범위 1~89
  ★ 전부 동률인 형상 1/41,  10개 이하인 형상 10/41
  A6000 눈금 1.024 µs — 상위권은 분해능이 지배한다
```

**41형상 중 10개는 상위 100 안에 배울 순위가 사실상 없다.** 원칙 3
(동률은 예외가 아니라 기본 상황)이 상위권에서 더 심하게 나타난다.

⚠️ **정정** 처음 실행에서 이 tau 가 6구조 전부 `nan` 으로 나왔다.
원인은 형상 **하나**(128x4096x1024, 상위 100 시간이 전부 0.023552 ms)
였고, `np.median` 이 `nan` 하나에 통째로 오염됐다. 그 상태로 판정
코드가 **"가운데"** 를 찍었다 — 값을 못 냈는데 판정이 나왔다. 정의
불가 형상을 세어 빼도록 고쳤다.

## 3. ★ 순위 능력은 전이되지 않는다 — top-1 은 되는데

**같은 조건(홀드아웃 20형상)으로 맞춰서 견준다.**

⚠️ 앞선 중간 보고는 A6000 을 **학습 41형상**, 5090 을 **홀드아웃
20형상**에서 재서 나란히 놓았다. **분할이 다르면 못 놓는다** (원칙 4).
아래는 둘 다 홀드아웃이다.

### 진짜 최적이 상위 5% 에 드는 형상 비율 (엄격 지표)

```
                        중앙        무작위 바닥      배수
A6000 홀드아웃 (전이 전)   65%          4%          ★ 16배
5090 (a) 완전 이식        25%          6%             4배
5090 (b) 재적합           28%          6%           4.6배
```

### 정답 집합 원소가 상위 5% 에 드는 형상 비율

```
                        중앙        무작위 바닥      배수
A6000 홀드아웃            72%         34%           2.1배
5090 (a)                 45%         47%          ★ 1.0배
5090 (b)                 52%         47%            1.1배
```

**순위 능력이 전이에서 4분의 1로 떨어지고, 가중치를 다시 맞춰도
돌아오지 않는다** (4배 → 4.6배).

★ 이것이 D-98 과 갈린다.

```
D-98   top-1 regret 은 (b) 재적합으로 (c) 에 닿는다   ✅
여기   ★ 순위 능력은 (b) 로도 안 돌아온다
```

⚠️ 두 표는 눈금(1/64)·정답 집합 크기(중앙 4 대 11)·후보 수(15k 대
20.8k)가 다르다. **그래서 절대값이 아니라 무작위 바닥 대비 배수로
견줬다.** 그래도 완전한 통제는 아니다.

## 4. 판정 — 사전 등록에 적어 둔 두 번째 서술

미리 적어 둔 셋 중 **"다양성 높은데 tau 는 낮다"** 에 가장 가깝다.

```
다양성      중앙 14.5종 (가운데). 정적 축퇴는 아니다
상위권 tau   0.141 (가운데의 아래쪽)
전이 후      ★ 순위 능력이 무작위 대비 16배 -> 4배
```

**→ "성능 모델" 이 아니라 `top-1 선택기` 다.**

미리 적어 둔 대로 **어느 쪽이어도 연구는 무너지지 않는다.**

```
top-1 선택기로서
  벤더와 대등 (9승 11패, p = 0.824)
  µs 안에 돈다
  ★ 구조가 전이된다 — (b) 가 (c) 와 구별 안 되고 LLM 0회다 (D-98)
★ 다만 "물리를 배웠다 / 성능을 모델링한다" 는 서술은 못 쓴다
```

### Critic 의 정성 산출물도 다시 봐야 한다

Critic 은 항마다 **물리적 설명**을 붙인다. 규칙이 성능 모델이 아니라
top-1 선택기라면, 그 설명은 **"이 항이 왜 1등을 가려내는가"** 이지
**"이 항이 실행시간을 어떻게 설명하는가"** 가 아니다. D-92 에서 이미
"가장 잘 변호한 항이 가장 취약했다" 는 관찰이 있었다.

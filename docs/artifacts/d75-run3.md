## 1. 실험 계획서에 적은 판정 — "여전히 눌린다"

실행 단위(원칙 28), 1차 Analyst 만, r0~r3.

```
기준선 6실행   12.5  22.2  20.0  23.5  16.7  21.1 %
새   6실행    0.0   5.6   0.0   0.0   0.0   5.6 %
Mann-Whitney U (단측)  p = 0.0021    (최소 가능 p = 0.00063)
```

**프롬프트는 기준선 문구와 문자 단위로 같다**(D-81, 시험으로 고정).
그러므로 실험 계획서대로라면 "프롬프트 탓이 아니다 — 남은 차이를
의심한다" 가 된다.

## 2. ★ 그런데 남은 차이 중 하나가 **크다**

실험 계획서에 "남은 차이" 로 D-78 과 경로 자체를 적었다. **셋째가
있었고 그것을 안 적었다: 2단계가 만든 씨앗 규칙.**

```
기준선 캠페인 씨앗   8항, f 피처 12/19 사용 (미사용 7)
새 캠페인 씨앗       7항, f 피처  6/19 사용 (미사용 13)
★ run2 와 run3 의 씨앗은 **코드가 완전히 같다** (해시 동일)
```

**한 캠페인의 6실행은 같은 씨앗 하나를 공유한다.** `stage3` 이
`loop.seed(seed_rule…)` 를 6번 똑같이 부른다. 즉 씨앗에서 오는 효과에
대해서는 **실효 표본이 6이 아니라 1 이다.**

### 그리고 씨앗의 피처 수가 요구율과 강하게 붙어 있다

44실행 전부(옛 33 + 새 9)에서:

```
평균 f 피처 수(아카이브 규칙) vs 요구율
스피어만 rho = +0.566   p = 0.0001   n = 44실행
```

**규칙이 많은 피처를 쓸수록 새 축을 더 요구한다.** 그리고 새 캠페인
9실행은 이 축의 **아래쪽 끝**(7.5~9.1)에, 기준선 6실행은 **위쪽
끝**(12.0~13.6)에 몰려 있다.

```
새 캠페인   7.5  7.6  7.9  8.0  8.2  8.3  8.4  8.6  8.8  9.1
기준선      12.0 12.2 12.7 12.7 12.9 13.6
```

**겹치지 않는다.** 요구율 차이와 같은 모양이다.

## 3. ★ 결론 — 판정을 내릴 수 없다

```
실험 계획서 판정   p = 0.0021 -> "여전히 눌린다"
★ 그러나        씨앗 규칙이 캠페인 단위 교락이고, 그 축이 결과와
                rho = +0.566 (p = 0.0001) 로 붙어 있다
                씨앗에 대해서는 실효 n 이 1 대 1 이다
```

**"프롬프트가 아니라 다른 것이 눌렀다" 까지는 맞다. 그러나 그 '다른
것' 이 D-78 인지 경로인지 씨앗인지 이 자료로는 못 가른다.**

실험 계획서의 판정 문장을 그대로 쓰면 **틀린 결론을 내리게 된다** —
"남은 차이(D-78/경로)를 의심한다" 고 적었는데, 실제로 가장 큰 차이는
**적어 두지 않은 씨앗**이었다.

### 원칙 28 을 한 단계 올려야 한다

```
표본 단위는 실행이 아니라 **캠페인**일 수 있다.
한 캠페인의 6실행은 2단계가 만든 씨앗 하나를 공유한다.
씨앗에서 오는 성질은 캠페인당 한 번만 뽑힌다.
```

제안 단위(D-79) -> 실행 단위(D-80) -> **캠페인 단위**. 두 번 틀렸다.

## 4. 가르는 방법 — 씨앗을 고정한다

```
기준선 캠페인의 chosen.json 을 새 캠페인의 2단계 산출물로 넣고
3단계만 6시드로 돌린다.

씨앗      같다  ★ 교락 제거
프롬프트   복원됨 (기준선과 동일)
D-78      켜짐  <- 이것만 남는다
경로       켜짐  <- 이것만 남는다
```

**그러면 남은 차이가 둘로 좁혀진다.** 약 320호출.
**아직 안 했다 — 사람이 정한다.**

## 5. D-78 은 이번에도 확인된다

```
리터럴 비교를 쓴 실행   옛 1/6  ->  새 6/6      Fisher p = 0.0152
실행별 비율           옛 0 0 0 0 0 2 %
                     새 25 19 69 17 25 19 %     ★ 겹치지 않는다
```

**6 대 6 으로 처음 제대로 쟀고 유지된다.** 씨앗에는 리터럴 비교가
없으므로(양쪽 캠페인 모두) 이것은 진화가 만든 것이다.

우회(`np.isfinite`/`np.sign`)는 옛 4/6 -> 새 1/6, **p = 0.24 — 여전히
못 가린다.** 옛 4실행 중 셋이 1~2건뿐이고 하나만 25건이었다.

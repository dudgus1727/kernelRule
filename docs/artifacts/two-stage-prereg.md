# A. 두 단계 목적함수 — (1) 재적합만

## 왜 이 방향인가

```
λ 를 섞는다   ★ 연속 하이퍼파라미터. 튜닝을 부른다
단계로 나눈다  ★ "언제 바꾸나" 하나. 이산이고 근거를 댈 수 있다
```

그리고 §29.5 가 이미 그 분업을 보였다 — **구조는 옮겨가고 가중치는
재적합으로 맞춰진다** (D-98).

## 재는 것 — LLM 0회

순위 진화 3실행의 **최종 구조를 그대로** 쓰고 가중치만
`objective="regret"` 으로 다시 맞춘다. **홀드아웃에서** 잰다.

```
                              regret   상위100 tau   전구간 tau
순위 진화 구조 + 순위 가중치        ?         ?            ?
★ 순위 진화 구조 + regret 가중치    ?         ?            ?
regret 진화 구조 + regret 가중치    ?         ?            ?
★ 무작위 바닥 (20뽑기)              —         ?            ?
```

⚠️ D-101 의 tau 값(0.389 등)은 **학습 41형상**에서 잰 것이다. 여기서는
홀드아웃이므로 **그 숫자와 나란히 못 놓는다** (원칙 4). 세 줄을 전부
같은 홀드아웃에서 새로 낸다.

## ★ 판정선 — 지금 박는다

```
regret <= 1.10  이면서  상위100 tau >= 0.30
  ★ 성공. "구조는 순위로, 가중치는 regret 으로" 가 답이다
regret <= 1.10  인데   tau <= 0.15
  가중치가 tau 를 다 지운다 — 구조만으로는 부족하다
regret >= 1.30
  구조가 regret 에 안 맞는다 -> (2) 이어서 진화가 필요하다
그 사이
  구분 불가. 그대로 적는다
```

## (2) 이어서 진화 — ★ (1) 결과를 보고 판단한다

셋째 갈래일 때만 한다.

```
순위 손실로 N 라운드 -> regret 으로 12-N 라운드
```

**전환 시점을 하이퍼파라미터로 두지 않는다.** 중단 조건으로 쓴다.

```
직전 3라운드에서 순위 손실 개선이 ★ 1% 미만이면 전환한다
근거(실측): s2 가 r5~r9 에서 0.2945 -> 0.2915 (1.0%)
           s0 은 r0 0.4429 -> r11 0.2850 이고 후반이 평평하다
-> r5~r6 근처가 자연스러운 전환점이 된다
★ 1% 는 고정값이다. 정하고 나면 안 바꾼다
```

### 아카이브 — ★ (b) regret 으로 재정렬

```
(a) 비우고 최고 하나만 씨앗으로   (3) 씨앗 방식과 같아진다
★ (b) regret 으로 재정렬          셀 축이 이미 목적함수를 따라가므로
                                 전환하면 자동으로 재정렬된다
⚠️ 대가: 순위 기준으로 보존된 다양성이 사라진다
```

# B. 순위 진화 규칙의 전이 — §29.5 확장

## 왜

§29.5 는 **`regret` 진화 규칙으로만** 했다. 거기서 이것이 미해결로
남았다 (D-100).

```
순위 능력이 전이 안 된다   A6000 16배 -> 5090 (b) 4.6배
★ 그런데 그것은 regret 진화 규칙 얘기다
```

## 재는 것

```
(a) 완전 이식   구조 + A6000 가중치 그대로 5090 에서 채점    ★ LLM 0회
(b) 재적합      구조 고정 + ★ 순위 손실로 5090 재적합         ★ LLM 0회
(c) 재생성      5090 에서 순위 진화 3시드                     약 500호출
```

**(a)(b) 를 먼저 하고 (c) 는 그 결과를 보고 판단한다.**

## ★ 판정선 — 지금 박는다

주 지표는 **5090 홀드아웃의 상위100 tau** 다. **무작위 바닥과 함께**
낸다 (원칙 7).

```
(b) 의 tau 가 무작위 바닥 대비 A6000 수준으로 돌아온다
  ★ 순위 능력도 구조에 실린다 -> "구조가 물리를 담는다" 가 강해진다
안 돌아온다
  구조가 아니라 표에 붙어 있다
```

## ⚠️ 실패해도 원인을 단정하지 않는다 — 미리 적는다

```
5090 상위 100 의 시간 폭      ★ 1.2%   (A6000 은 6.6%)
5090 상위 100 의 고유 시간값  ★ 5개    (A6000 은 24개)
-> 배울 순위가 원래 적다
```

**"못 배운다" 와 "배울 게 없다" 를 이 자료로 못 가른다.**
그러므로 실패 시 서술은 **"돌아오지 않았다. 다만 5090 상위권은 폭
1.2% 에 고유값 5개라 배울 것 자체가 적다"** 까지다.

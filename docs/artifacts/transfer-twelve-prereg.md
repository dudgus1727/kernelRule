## 2. 판정선 — **0.0516 을 그대로 쓰되, 여유를 적는다**

원칙 7: 여기서 새로 정하지 않는다.

```
delta = 0.0516   (n=6 두 팔, 양측 0.05, 검정력 0.8, 비대응, σ 상한 0.0319)
```

⚠️ **D-140 이 그 σ 상한을 흔들었다** — 실측 σ 가 캠페인마다 0.0124 ~ 0.0364
로 3배 움직인다. 0.0364 를 그대로 넣으면 delta 는 0.0589 가 된다.

```
★ 판정 규칙: |차| < 0.0516        구분 불가
             0.0516 ~ 0.0589      ★ "판정선 근처" 로만 적는다. 판정 안 한다
             > 0.0589             차이가 있다
```

**이 완충대를 계산 전에 박는다.** 결과를 보고 만든 것이 아니다.

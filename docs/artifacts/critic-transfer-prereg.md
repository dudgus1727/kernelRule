# 실험 계획서 — Critic 전이 검증 (5090) (2026-08-29)

> **★ 5090 표를 보지 않고 썼다.**
> **선행** `transfer_check.py` 겹침 보고, 그리고 §29.5 (a) 팔
> **재현** `python3 experiments/critic.py gate --other <5090-번들>`
> (구현 예정) · **LLM 0회** — 심사는 `critic.json` 을 재사용한다
> **표** A6000 + 5090. 성능 수치를 인용하지 않는다

## ★ 이것은 "세 번째 통과 조건 정의" 가 아니다

D-87 에서 **"통과 조건 정의를 또 고쳐 다시 돌리지 않는다"** 고 적었다.
그 규율은 **같은 표에서 기준을 바꾸는 것**을 막는 것이다.

```
같은 표에서 기준을 바꾼다   ★ 맞을 때까지 고르는 것. 금지
다른 표에서 처음 잰다       ★ 새 자료. 다른 문제다
```

그리고 이것은 **§11.5 가 처음부터 지목한 방어선**이다 —
"심사는 예선일 뿐이다. 진짜 방어선은 아키텍처 홀드아웃이다.
물리적으로 타당한 피처는 전이되고, 우연히 맞은 피처는 무너진다."

**통과 조건 1·2 는 그 대리 지표를 같은 표 안에서 찾으려 한 것**이고 둘 다
안 맞았다. 이번이 원래 하려던 검증이다.

## 가설과 지표

```
설명 가능한 항   물리라서 다른 GPU 에서도 성립한다
                -> 빼면 A6000/5090 이 비슷하게 나빠진다
설명 불가한 항   A6000 에 맞춰진 것
                -> ★ 빼면 A6000 만 크게 나빠지고 5090 은 덜 나빠진다

지표 = (A6000 손상) - (5090 손상)
★ 양수가 클수록 "A6000 전용" = 설명 불가 항이 여기 몰려야 한다
```

**부호가 통과 조건 2 와 같은 모양이고 축만 바뀐다** (검증 분할 -> 다른 GPU).

## 절차

```
심사    D-85 의 `critic.json` 그대로. ★ 재심사 없음 — LLM 0회
        (재심사하면 5090 을 본 뒤의 판정이 된다)
규칙    f1pipe-F3-arch24-s0..s5 의 최종 규칙 6개
절제    각 항을 하나씩 제거 (`ablate.drop_terms`)
채점    A6000: 학습 41 로 적합 -> 학습 41 에서 채점
        5090:  ★ **같은 가중치로** 5090 공통 형상에서 채점 (완전 이식)
        -> 손상 = (제거본 regret) - (원본 regret), 각 표에서
형상    공통 형상만. ★ 바운드 뒤집힌 형상은 포함/제외 양쪽으로 낸다
```

⚠️ **5090 에서 재적합하지 않는다.** 재적합하면 "그 항이 5090 에서
쓸모없다" 가 아니라 "다른 항이 그 자리를 메웠다" 를 재게 된다.

## 판정 — 미리 적는다

```
지표    설명 불가 항의 (A6000손상 - 5090손상) 상대 순위 (1 = 가장 양수)
표본    ★ 규칙 단위 중앙값 (원칙 28)

중앙 >= 0.65   ★ 판정이 맞다 — Critic 이 전이 안 되는 항을 짚는다
중앙 <= 0.35   틀렸다
그 사이        구분 불가
```

## ★ 목 기준선을 이번에도 먼저

```
목 A   마지막 항 하나
목 B   마지막 k개 (수 일치)   ★ 주 대조군
무작위  k개 (시드 고정, 200회 중앙)
```

**목 B 가 0.65 를 넘으면 실제 값이 얼마든 판정 불가다.** 통과 조건 2 에서
목 B 가 0.43 이었으므로 이번에도 낮을 것으로 보이지만 **다시 잰다** —
다른 표에서는 다를 수 있다.

⚠️ **항별 지표는 지목과 무관하게 한 번만 계산한다.** 목이든 실제든
같은 숫자 위에서 순위만 다르게 읽는다.

# 부칙 — 단서 하나. ★ **판정 기준은 안 바꾼다** (2026-09-01)

> **왜 지금 적나** 실패했을 때 붙이면 사후 합리화다. 통과 조건을 돌리기
> **전에** 적어야 정직하다. **그리고 아래 관찰이 판정선에 닿지 않도록
> 위 본문을 한 글자도 안 고쳤다** (§12.3d · D-50).

5090 재적합 실험에서 우연히 Critic 과 겹치는 관찰이 나왔다
([refit-sample.md](refit-sample.md) §2-2). A6000 F3 6구조 중 **s0 의
파국률이 18.5%** 로 나머지(2.5~7.4%)보다 높았는데, 그 s0 의 항을
Critic 이 어떻게 봤나 세어 봤다.

```
s0 항 3   floor(1/smem_pressure)   -> ★ 지목했다 ("설명 불가", 근거도 정확)
s0 항 1   1/(1 - tail_waste)       -> ★ "설명 가능" 으로 통과시켰다
s4 항 3   1/max(waves, log_grid_tiles) -> 지목했다

극 있는 항 2/4 가 설명 불가   극 없는 항 11/44   Fisher p = 0.294
★ 극이 4개뿐이라 못 가른다
```

항 1에 Critic 이 붙인 물리 이야기는 이랬다 — *"마지막 wave 에서 놀게
되는 슬롯 비율 x 에 대해 1/(1-x) 형태의 실행시간 증폭"*. **그럴듯하고,
물리적으로 맞고, `sm_idle_cost` 라는 등록 피처와 같은 식이다.**

```
★ 설명 가능성과 수치 안정성은 **다른 축일 수 있다.**
   Critic 이 가장 잘 변호한 항이 가장 취약할 수 있다.
```

⚠️ **이것은 가설이지 근거가 아니다.** 같은 실험에서 "극이 파국을
만든다" 는 기전을 우리가 세웠다가 **스스로 반증했다** (동적 범위를 재
보니 s0 이 가장 좁았다). 그러므로 여기서 말할 수 있는 것은 **"Critic 이
통과시킨 항이 문제였던 사례가 하나 있다"** 뿐이다.

## 이 부칙의 용도 — ★ 실패했을 때만 꺼낸다

```
통과 조건을 통과하면   이 부칙은 안 쓴다. 통과가 결론이다
통과 조건이 실패하면   ★ "왜 실패했나" 에 이 관찰을 근거로 쓸 수 있다:
                 설명 가능성과 수치 안정성이 다른 축이라면,
                 "설명 불가 항이 먼저 무너진다" 는 예측 자체가 틀린 것이다
                 ★ 그래도 판정은 실패다. 실패를 실패로 기록한다
```

**판정선을 옮기지 않는다.** 위 §"판정 — 미리 적는다" 가 그대로 유효하다.

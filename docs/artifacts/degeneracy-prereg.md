## 무엇을 묻는가

우리는 **한쪽 축퇴만 막았다.**

```
암기   if p.M == 4096          ★ 정적 검사가 막는다 (§8.4)
축퇴   형상과 무관하게 같은 config 를 고른다
       ★ 아무것도 안 막는다
```

**"형상을 보는 척하면서 사실은 상수" 인 규칙이 통과할 수 있다.**

`hit@k` 결과가 그 의심을 낳았다 — 규칙의 상위 5% 커버리지가 무작위와
같았다(45% 대 47%, D-99). 순위를 무작위만큼밖에 못 매기는데 `regret@1`
은 좋다면, 배운 것이 **"물리" 가 아니라 "1등을 찾는 요령"** 일 수 있다.

```
  형상 10% 만 개선해서는 안 나오는 크기다 (0.9 x 0.1088 = 0.098)

```

```
      ★ 형상별 최적과 몇 형상에서 같은가 (hit@1)

(2) A6000 에서의 순위 능력
      Kendall tau (규칙 순위 vs 참 순위, 전 구간)
      hit@1% / 5% / 10% — 정답 집합 기준과 진짜 최적 기준 둘 다
      ★ 무작위 바닥과 나란히 (20번 뽑기 평균 — 바닥도 표본이다, 원칙 7)

(3) ★ 상위권 안에서의 tau
      전 구간 tau 는 15,000등과 16,000등이 지배한다
      ★ 참 상위 100개 안에서만 따로 낸다
```

⚠️ tau 는 후보 2만개 전수 쌍이 2억이라 **표본으로 근사**한다. 표본
크기와 시드를 고정하고 기록한다. 상위 100 은 전수로 낸다.

⚠️ 동률 처리를 명시한다 — 참 순위는 시간 동률이 많다 (D-30, D-41).
`scipy.stats.kendalltau` 의 tau-b 를 쓴다 (동률 보정).

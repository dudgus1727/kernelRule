# ★ 12라운드는 **부족하다** — 그런데 부족한 양이 시드 폭보다 작다

> **재현**: `python3 experiments/rounds_curve.py` (약 1분, **LLM 0회**)
> **실험 계획서**: [rounds-prereg.md](rounds-prereg.md)
> **원자료**: `docs/artifacts/rounds-curve.json`
> 라운드 번호는 파일의 `round` 필드 = **0부터** (r0..r11 이 12라운드)

## 1. 먼저 — 조기 종료는 **한 번도 안 걸렸다**

`patience=10` 으로 12라운드를 돌면 판정 창이 둘뿐이고, 새 셀이 하나만
생겨도 안 멈춘다. 실측:

```
F3rw-p8 6시드의 patience=10 종료 시점   전부 "-" (한 번도 안 걸림)
patience=3 이었다면                     r3 · r6 · r10 · r11 · 없음 · 없음
patience=4 이었다면                     r4 · 나머지 전부 없음
```

**"12를 다 돌았다" 는 "수렴했다" 가 아니라 "멈출 기회가 없었다" 였다.**

## 3. ★ 판정 — (나) 12 가 부족하다

실험 계획서 §2 의 셋 중 둘째다. **곡선을 보고 만든 선이 아니다.**

```
(나) 마지막 3라운드에서 유의하게 개선되는 시드가 있다 -> 12 가 부족하다
    -> 라운드 24 를 n=6 으로 재야 한다 (약 6,000호출 / 15시간)
```

### ⚠️ 그런데 부족한 **양**을 함께 읽어야 한다

```
s0 의 r10 개선   0.0060
s4 의 r11 개선   0.0055
노이즈 문턱       0.0047   <- 이것보다 크다 (그래서 "유의")
시드 폭 σ        0.0124   <- ★ 이것보다 작다
판정선 delta     0.0516   <- ★ 1/9 이다
```

**"유의하다" 는 노이즈 바닥 기준이고, "잴 수 있다" 는 시드 폭 기준이다.**
라운드를 늘려 얻을 것으로 보이는 양(~0.006)은 **시드 하나 바꾸는 것보다
작다.** 24라운드를 6시드로 돌아도 중앙값이 시드 폭 안에서 움직일 수 있다.

★ **판정은 (나) 그대로 둔다** — 결과를 보고 선을 바꾸지 않는다. 다만
**비용(6,000호출/15시간) 대비 기대 효과가 σ 아래**라는 것을 함께 적는다.
돌릴지는 그 두 줄을 나란히 놓고 결정할 일이다.

## 4. 다른 조건도 같다

| 조건 | 마지막 유의 개선 | 마지막 3라운드에 유의 개선 |
|---|---|---|
| F3rw-p8 | r10 r7 r5 r7 r11 r6 | **2/6** |
| F1rw-p8 | r9 r4 r5 r9 r8 r7 | 2/6 |
| F2rw-p8 | r8 r8 r5 r5 r9 r8 | 1/6 |

⚠️ F1/F2 의 문턱은 **근사다.** 그 실행의 규칙이 루프 안에서 만든 피처를
참조해서 기본 레지스트리로 다시 채점할 수 없다. F3 6시드가 전부 같은
문턱(0.0047)을 냈으므로 — 문턱은 규칙이 아니라 홀드아웃 형상이 정한다 —
그 값을 빌렸고 표에 `(근사)` 로 찍었다. **판정은 F3 로만 했다.**

## 5. 새 셀은 끝까지 생긴다

```
마지막 새 셀 라운드  F3: r9 r8 r9 r11 r7 r8   F1: r11 r7 r10 r9 r11 r8
```

`should_stop` 의 둘째 조건(`new_cell_recent`)이 **거의 항상 참**이다.
그래서 patience 를 줄여도 그것만으로는 안 멈춘다 — 셀 축이 4분위라
칸이 계속 재정렬된다.

★ patience 를 바꾸는 것은 **조건 변경**이라 별도 실험 계획서가 필요하다.
여기서 바꾸지 않았다.

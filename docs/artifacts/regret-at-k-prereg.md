# 사전 등록 — `regret@k`: 벽이 **지표**가 만든 것인가

**LLM 호출 0회.** 계산 전에 쓴다.

## 1. 확인부터 — 지금 `tau` 는 노이즈를 안 본다

`kendalltau` 를 부르는 자리를 전수 확인했다 (`two_stage._measure`,
`rank_evo_report`, `top_tau`, `degeneracy`). **전부 `time_ms` 를 그대로
넘긴다.** `variant="b"` 는 **시간이 정확히 같을 때만** 동률로 본다.

```
순위 손실   ★ 노이즈로 못 가르는 쌍을 **뺀다** (NoiseModel.resolvable)
tau        ★ 안 뺀다. 노이즈 안의 순서도 "맞다/틀리다" 로 센다
```

홀드아웃 20형상에서 재 봤다:

```
상위 100 안의 쌍 99,000
  노이즈로 못 가르는 쌍   46,679 (47.2%)
  tau-b 가 동률로 보는 쌍 14,628 (14.8%)   ← 시간이 정확히 같은 것만
★ 차이 32.4% 가 "없는 순서를 채점당하고 있다"

상위 10 안에서는 못 가르는 쌍이 67.2%
```

⚠️ 지시문의 "143,550 중 101,046 (70%)" 은 **학습 41형상** 값이다.
홀드아웃 20형상에서는 47.2% 다. 나란히 놓지 않는다 (원칙 4).

**§1-1 의 의심은 사실이다.** 그것을 먼저 적는다.

## 2. 재는 것 — `regret@k`

```
regret@k = (규칙이 고른 상위 k 의 참 시간 **평균**)
         / (참 상위 k 의 시간 **평균**)

k = 1, 3, 5, 10, 20, 50, 100
```

평균이라 노이즈에 강하고, 38등을 36등으로 예측해도 거의 안 벌받는다.
형상별로 계산해 **기하평균**으로 모은다 (regret 과 같은 집계).

## 3. 대상 — 전부 홀드아웃 20형상, 시드별로 내고 중앙과 범위

```
regret 구조 + regret 가중치   arch24 s0..5      (6)
순위 구조 + 순위 가중치        rankevo s0..2     (3)
★ D-103 의 2x2 나머지 두 칸 — 같은 구조에 다른 가중치
곱 항 (prod) · λ (lam03/10/30) · k (k010/020/050) · 예산 (b08/b16b)
★ 무작위 바닥 (20뽑기) · 정적 top-1 · 벤더
```

## 4. 함께 낼 것 둘

```
(a) 형상별 regret@1 분포
    20형상 각각 · 파국(>1.15)이 몇 형상인가
    ★ 그 형상이 규칙마다 **같은가** (같으면 형상의 성질, 다르면 규칙의 성질)

(b) 노이즈 인식 tau
    참 순위에서 노이즈 바닥 이내를 **동률로 묶고** tau-b
    ★ 묶는 법: 시간 오름차순으로 훑으며 `NoiseModel.resolvable(그룹 첫 원소, t)`
      가 True 가 되면 새 그룹 (단일 연결). **바닥을 새로 정의하지 않는다** —
      `resolvable` 을 그대로 쓴다 (원칙 2)
    옛 tau 와 **나란히** 낸다. 둘의 차이가 §1 의 직접 증거다
```

## 5. 판정선 — ★ 계산 전에 박는다

"겹친다" 의 기준은 **시드 범위**다 (3·6시드라 유의성이 안 나온다).

```
(가) 두 계열의 regret@k 곡선이 k>=10 에서 시드 범위가 겹친다
     ★ 벽은 tau 가 만든 것이다
     다른 것은 k=1 뿐이고, 그것이 노이즈 안 차이인지는 (a) 로 본다

(나) 순위 규칙의 regret@1 파국(>1.15)이 **몇 형상에 몰려 있다**
     ★ "순위 규칙은 파국 형상이 있다" 가 문제이고 그 형상이 다음 질문

(다) 두 곡선이 k>=10 에서도 갈린다 (범위가 안 겹친다)
     ★ 벽이 실재한다. 지금 결론 유지
```

(가)와 (나)는 **동시에 참일 수 있다** — 그러면 둘 다 적는다.

## 6. 무엇이 바뀌나

(가)면 여섯 방향 실험의 결론이 "벽" 에서 **"지표 선택"** 으로 옮겨간다.

```
tau 로 보면 벽, regret@k 로 보면 없다
★ 어느 지표가 맞는가 — 노이즈 안 순서에는 정보가 없으므로 regret@k
```

그리고 산출물이 "top-1 선택기" 에서 **"top-1 을 맞추면서 성능 경향도
보여준다"** 로 넓어진다.

⚠️ **(가)가 나와도 여섯 방향 실험을 "틀렸다" 로 쓰지 않는다.**
"tau 가 안 움직였다" 는 사실이고, **지표가 질문과 안 맞았던 것**이다.

## 7. 예상

**(가)와 (나)가 같이 나올 것으로 본다.** 순위 규칙의 regret 1.47~1.64 는
20형상 기하평균이라 몇 형상의 파국에 끌리기 쉽고, k>=10 이면 평균이
노이즈를 눌러 두 계열이 가까워질 것이다. 다만 k=1 의 격차(1.07 vs 1.6)는
너무 커서 (나) 없이 (가)만 나오기는 어렵다.

## 8. 기록할 것

지표를 `tau` 로 고른 것은 순위 손실 실험 설계 때다. 사용자가 처음 물은
것은 **"regret 규칙이 성능 경향을 보여주나"** 였는데 그것이 **"순서를
정확히 맞추나"** 로 바뀌었다. **무엇을 알고 싶은가로 돌아가지 않고 있는
지표를 썼다** — 그 사실을 `decisions` 에 적는다.

# 실험 계획서 — 적합기가 **과적합을 만드나** (CMA vs Nelder-Mead)

**LLM 호출 0회.** 계산 전에 쓴다.

## 0. 무엇이 걸렸나

§3 에서 기준선을 다시 뽑았더니 방향이 반대였다.

```
옛 기준선 (Nelder-Mead 200/600, 6시드)   1.0762
새 기준선 (CMA-ES 300/600, 3시드)        1.0987   ★ 0.0225 나쁘다
```

**절차가 셋 다르다** (적합기·적합 예산·시드 수). 그래서 D-124 는 이것을
판정에 안 썼다. 그러나 방향이 걱정스럽다:

```
CMA 는 학습 regret 을 더 잘 맞춘다 (16차원 도달률 100%, D-123)
★ 그런데 홀드아웃이 나빠 보인다
-> 더 깊은 국소해가 더 잘 일반화하지 않는다?
```

D-123 의 "도달한 점이 같지 않다"(같은 값인 칸 0~2/12, cos 최소 0.160)와
이어진다 — 적합기가 세면 학습 41형상에 더 맞춰지고 그것이 과적합일 수 있다.

## 1. 가르는 법 — **변수를 적합기 하나로**

같은 규칙을 두 적합기로 다시 맞춘다. 구조도 씨앗도 예산도 같다.

```
대상    regret 진화 6실행(`f1pipe-F3-arch24-s0..s5`)의 최종 규칙
        ★ D-77·D-123 이 쓴 것과 같은 여섯이다
절차    최종 채점 — 체제별로 학습 41형상에 재적합 -> 홀드아웃 20형상
        (`two_stage._fit` / `regret_at_k._measure`)
팔      NM   nelder-mead · 재시작 4 · 적합 300 · 다듬기 600  ← 지금까지의 측정 절차
        CMA  cma         · 재시작 1 · 적합 300 · 다듬기 600  ← §3 이 쓴 것
★ 다른 것은 하나도 없다. 목적함수 regret, k=1, 같은 분할
```

**부차**: §3 의 예산 8 팔(`rb08`, CMA 로 진화한 3구조)도 같은 두 적합기로
잰다. 구조가 CMA 에 맞춰져 있는지 본다 — 6구조와 **따로** 보고한다
(구조가 다르므로 섞으면 안 된다).

## 2. 재는 것

```
주      홀드아웃 regret@1 — 구조별로 두 팔의 **짝지은 차이**
같이    학습 regret (CMA 가 실제로 더 잘 맞추나 — 기전 확인)
        격차 = 홀드아웃 - 학습
        regret@k (k=10/50/100) — 영역에서도 같은 방향인가
```

## 3. 판정선 — 미리 박는다

n=6 의 **짝지은** 비교다. §29.5 가 쓴 것과 같은 틀을 쓴다 (원칙 7).

```
주 판정   짝지은 Wilcoxon 단측 (6구조) p <= 0.05
          ★ 6/6 이 한쪽이면 p = 0.0156
크기      중앙 차이를 σ(A6000 시드 폭 0.0124) 와 함께 읽는다
참고선    비대응 판정선 0.0516 — **여기서 새로 정하지 않는다**

CMA 홀드아웃이 유의하게 나쁘다   ★ 적합기가 과적합을 만든다
                              -> 예산 8 에서는 NM, 16차원이 필요할 때만 CMA
                              -> 4090 전이의 (b) 재적합도 NM
구분 불가                      1.0762 -> 1.0987 은 적합기 탓이 아니다
                              -> 남는 후보: 적합 예산(200 vs 300) · 시드 수(6 vs 3)
                                 · 다듬기 수정(D-122)
CMA 가 유의하게 좋다            ★ 예상 밖. 그때 다시 쓴다
```

⚠️ **학습 regret 은 판정에 안 쓴다.** CMA 가 학습을 더 잘 맞추는 것은
설계상 당연하고(그러라고 고른 팔이다), 그것이 과적합의 **기전**이지
판정이 아니다.

## 4. 예상

```
격차(홀드아웃-학습)는 CMA 가 더 크다   기전 가설이 맞으면
```

# 정답 집합 크기가 극단적이다 — `hit@k` 를 읽는 법 (2026-09-01)

> **근거** [hit-at-k.json](hit-at-k.json) ·
> [config-sampling-gate.md](config-sampling-gate.md) (D-99)
> **재현** `python3 experiments/hit_at_k.py` · LLM 0회

## 관측

5090 홀드아웃 20형상. 후보 중앙 20,790개. **정답 집합** = 최적 시간의
노이즈 바닥 2σ 이내인 config 들 (`PerfTable.answer_mask`).

```
[1, 1, 1, 1, 2, 4, 5, 6, 9, 10, 13, 14, 14, 28, 34, 47, 77, 92, 228, 464]
      ★ 4형상은 2만 후보 중 정답이 **1개**    ★ 한 형상은 464개
```

A6000 학습 41형상: 중앙 5, 범위 1~522, 1개인 형상 1개.

## ★ 그래서 두 지표가 갈린다

```
"정답 집합 원소가 상위 k% 에 드나"
  464개짜리 형상은 아무렇게나 뽑아도 맞는다 -> ★ 큰 형상에서 우연이 지배
  실제로 무작위가 상위 5% 에서 47% 를 낸다

"진짜 최적이 상위 k% 에 드나"
  ★ 작은 형상에서만 갈린다
  무작위 6% 대 규칙 15~40%  ->  규칙이 3~7배
```

**같은 규칙이 한 지표에서는 무작위와 같고 다른 지표에서는 3~7배다.**
지표를 고르는 것이 결론을 고르는 것이 된다.

```
지표를 하나만 내지 마라. 그리고 ★ 무작위 바닥을 함께 내라 (원칙 7).
```

## 난이도와 이어진다

정답이 1개인 형상은 **어려운 형상**이다 — 2만 후보 중 하나를 정확히
집어야 한다. 정답이 464개인 형상은 그 반대다. `difficulty`(중앙/최적)와
**다른 축**이고, 둘을 함께 봐야 "어느 형상에서 못 하나" 가 보인다.

⚠️ 정답 집합 크기는 **노이즈 바닥에 의존한다.** 5090 눈금은 A6000 의
1/64 라 같은 형상이라도 정답 집합이 좁아진다 — **표 사이에 나란히
놓을 때 그 사실을 적어야 한다** (원칙 4).
